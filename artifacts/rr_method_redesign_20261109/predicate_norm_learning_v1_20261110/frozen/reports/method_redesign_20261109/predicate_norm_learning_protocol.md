# Predicate-governed source acquisition prototype

This records a new algorithmic prototype within the current Goal, not a new
Goal, data authorization, call cap or acceptance rule. Current authority stays
in docs/CURRENT_GOAL.md and docs/METHOD_REDESIGN_CURRENT.md.

Question: can TRAIN feedback learn a small typed semantic transducer that
generates source norm/consequence nodes from source predicates, while preserving
the predicate owning negation and embedded conduct? The source parser emits no
permission/prohibition/obligation labels. The learned objects are a lexical
head-to-operator map, negation map, type-guarded modal composition and an
exception-binding decision. A finite consistency learner retains all programs
that satisfy the existing15/20 source feedback and111 native positive witnesses
plus the existing archival binding constraint. No source IDs occur in prediction.

For example, the same acquired shall may map a conduct to O(A) and preserve a
negated breach consequence unchanged. This distinction is learned from different
existing TRAIN feedback. With source-local negation, the conduct composition
can transfer to O(NOT(A)); negating a breach does not become prohibition of its
conditional disclosure. Unknown predicates/modal types stay unresolved.

Elementary operators, the existing public action catalogue, literal span
checking, unique information-reference resolution and syntax data are public
components for every arm. They are not core learning successes. Predicate graph
parsing and graph-to-norm composition have precedents in Recski et al.2021 and
Humphreys et al.2020; this representation and finite program induction are not
claimed new algorithms merely by name. The scientific claim, if any, must come
from source fidelity or acquisition/repair costs against independent controls.

The first real availability readings use only the existing author-checked
source units of TRAIN15/20/111. Constructed syntax software fixtures are labelled
as such and never counted as model outputs. Every raw response and failure is
retained, thinking OFF and unchanged model configuration. No semantic rule is
filled by a format adapter. Literal adaptation, if needed, is only uniquely
supported case/whitespace rendering.

Strong control: independently obtain an unrestricted ordinary programme from
the same original sources, eight authorized native TRAIN annotations and three
source constraints, with the same syntax and common operations available. It
may use the source text, syntax, ordinary dictionaries, rules, typed composition
or any permitted Python. Baseline can adopt the same composition; equivalent
reparameterization is not itself a reason to reject a domain/cost contribution.
Charge all real acquisition/repair/parser costs, including failures. The older
independent raw-source programme remains an additional preserved control, not
silently downgraded. No native accuracy claim from these source slices.

Original TRAIN121/122 are pre-fixed as potential source-only reuse, not new
mothers or new native pairs. Their text is read only after method/control/scorer
freeze and only if the TRAIN prototype warrants continuation. A fixed lexical
selection takes the first paragraph containing a public conduct anchor and its
adjacent paragraph; no selection by model outcomes/labels. Freeze and record
the actual selection before generation. No DEV/TEST or full build is started.

If the strong controls absorb the effect, report it without expanding this
candidate indefinitely. A working transducer, sparse TRAIN fit or a few new
source frames do not establish the first contribution or complete the Goal.

# 方法一：内容寻址的共享片段差分获取——NormBench 原生第一版

2026-11-10。**本版锁定为 NormBench-only 训练；SARA 外部测试，不训练参数绑定头，不要求额外人工标注。** 下文替代本文件早先的多数据辅助训练和具名参数映射设想。研究任务是从目标法律原文获取遗漏的规范头、条件内容及其结构角色，再由 M2 学习条件归属和父子作用域。

## 1. 确定的职责与方法

M1 学习“同一源内容只获取一次，后续文本使它具有哪些新增结构角色”，输出共享内容及角色集合的开放差分。内容槽与角色槽分开，避免把同一文本的不同角色当作互相排斥的分类。M2 使用这些片段学习**原生 gold 实际提供的 condition→branch assignment、AND/OR 父节点和 condition-tree scope**。两者都不假定已经提供独立的 gold defeats 图。

相比旧固定候选重排，M1 可以生成原先根本不存在的条件内容、规范类型和源锚点；其学习对象是由原生结构导出的源差分过渡。相同条件文本可能在一般分支承担排除角色、在另一个分支承担正条件角色，M1 允许产生这两种 typed fragment，M2 再决定它们的分支和父子关系。

新增机制是**共享内容与多角色视图分解＋联合角色差分学习**，不是只加覆盖率正则。增量解析、普通程序编辑、显式排除本身是已有组件；本版不把标准监督学习或原生 SG-DT 表示另起名字算创新。

## 2. 当前失败与第一版边界

服务器最新 `2a9eeeb` 的固定解析森林、hard-EM 和词项模板重组没有带来新的附着，且 111 跨规则变量绑定尚不能学习，见 `SERVER_EVIDENCE.md`。

本版先解决其中有独立监督的源获取与条件范围问题，**不宣称已经解决完整跨规则变量绑定**。NormBench 未核到逐变量端口 gold，因此删除该训练头、相应 loss 与必跑指标。SARA 中的绑定 gold 只用于后续外部诊断；不能暗中拿来训练后仍叫 external-only。

## 3. 输入、预测目标与原生字段

- `input.rule_text` 是唯一预测目标域；所有计分的目标分支、条件树和规范效果均以该字段对应的 gold 为准。
- `input.full_article_text` 只作为上下文，不能擅自把上下文全部抽成额外目标分支，也不能用它覆盖或重定义 rule_text 的标注。
- 原生 `gold.units[].unit_text` 提供单元化监督；每个分支的 `anchor/norm_kind/effects` 提供规范头与效果监督。
- 原生 `conditions` 内部的 `op/items` 提供 M2 的树操作和父子监督；叶子的 `tag/text` 提供 M1 的内容与类型监督，叶子的分支归属提供 M2 的 assignment 监督。
- `depends_on_units/depends_on_article_ref/unresolved_reference` 只按实际存在且含义明确的字段使用，不扩展成 gold defeats 或参数映射。

原 ID 中 `B1.E1` 的 B1 直接暴露 branch assignment。**这种 ID 只保留在评测适配器，不能放进 M1 输出库存或 M2 输入特征。** 输入节点改用与 gold 分支无关的源位置/内容哈希；assignment 和父节点只作为训练目标。

相同 `(source_text, tag)` 的条件片段可在库存中合并，M2 允许实例化到多个分支。相同文本但 tag 不同（例如前置条件和排除）保留不同 typed fragment。不能通过保留原 branch_id 或层次路径把应学习的附着提前编码进去。

## 4. 第一版状态和动作

状态为 `S=(B,L,U,M)`：B 是已获取的规范头及效果；L 是不带 gold 分支归属/父节点的 typed condition fragment 库；U 是通用开放条件接口及原文明确出现的未决引用；M 是已暴露目标文本。

最小动作语言固定为：

```text
EMIT_UNIT(target_start, target_end)
EMIT_BRANCH_HEAD(anchor, norm_kind, effect_text)
UPSERT_PAYLOAD(content_key, text, source_occurrences, support_kind)
ADD_ROLE_VIEW(content_key, native_tag, occurrence_support, local_version)
REVISE_VIEW(view_id, new_role_or_support, supersedes_version)
OPEN_CONDITIONS(branch_local_id)
EMIT_REFERENCE(reference_text, unresolved_flag)
END_DELTA
```

`support_kind` 只是适配器确定的 `literal / native_inferred / unresolved`，不是新增人工标签。原生 leaf 若不在原文中逐字出现（例如注记明确为 inferred_subject 的主体），保留原生生成目标和该来源标记；无法确定源支持的项移到单独未决/需筛查集合，不把它伪装成逐字 span。

本版没有 `BIND_PORT`、任意一阶谓词参数头、`SUSPEND_NORM` 或 `RESTRICT_EXCEPTION` 的独立动作标签。后两种只是解释最终语义的概念，不假称 NormBench 原生提供了对应标签。M1 生成原生 typed leaf 和开放条件接口，M2 学习其真实分支与树位置，随后使用固定 SG-DT 编译语义获得排除效果。

M1 的确定性 Apply 只更新库存、类型和开放状态；不替 M2 硬编码分支归属，不用一条正则推断完整例外树。这样仍可获取以前不存在的节点，但不会把另一项方法的组合任务藏进 M1。

## 5. 源暴露监督与可用性边界，不新增法律 gold

训练数据为 NormBench 原生 `(rule_text, context, G)`。从已有单元化/结构标注构造至多两条源暴露路径，并从 G 提取每步开放状态及库存变化。它们是**展示同一法律的部分原文**，不是宣称删句后得到另一部真实法律。

约束如下：

1. 未暴露内容不产生节点、类型、ID 或孔洞；只有已见明确引用才产生引用槽。
2. 每个已见但未读完整的规范单元只保留通用 `OpenConditions`，不预告未来例外的数量、标签或目标。
3. 条件文本虽可先被抽取，其语义 tag 若依赖尚未出现的同单元文字，则先保持未定；保守原生方案在整个标注单元暴露后才发布最终 tag/效果。不得为了造更长的差分轨迹使用不可见信息。
4. 全文上下文包含目标文本副本时，暴露训练中同步遮住尚未暴露的 rule_text 范围，避免通过 full_article_text 偷看未来片段。上下文的其他内容仍只作上下文。
5. 原生单元边界在训练中可作标签。冻结测试不提供 gold unitization：先由同一 M1 预测单元再产生片段；另报 gold-unitization 诊断以分离分段错误。所有对照获得同样的单元监督。
6. 投影首先去除 gold branch assignment 和 parent 路径。M2 所需标签另存；绝不作为状态的一部分传入。
7. 最终仍未解析的引用不补造定义，不凭答案标签制造连接。

本次重新检查冻结候选 TRAIN：881 个 branch 的 `depends_on_units` 全为空。因此，不能将其传递闭包说成首版有实质作用的创新。首版保守按原生单元暴露，依赖闭合只是一条“不偷看未来、不捏造部分法律”的安全约束；单单元且无可用过渡的样本只参加获取监督。实质可学习机制改为下节的共享内容与角色集合差分，不把普通单元级增量抽取包装成依赖学习。

记上述投影为 `Π_M(G)`，其差分标签 `δ*` 满足 `Apply(Π_M(G),δ*)=Π_M'(G)`。这里重建的是**开放片段状态**，不是提前重建完整条件树。既有分支有效 guard 必须在 M2 的树组装完成后按真实排除叶变化，不能把增加一个叶子就宣称完整例外已处理。

第一版完全不需要新增“删条款后法律如何变化”的人工标注。源/标注不一致项依照事先固定筛查规则排除或单列；不把必须补标才能开跑作为本方案前置条件。

## 6. 内容寻址的共享片段更新：确切学习机制

### 6.1 确定性监督构造及实测可用量

对一条 TRAIN 来源，以完全相同的原生 leaf.text 建立内容类 k；以 `(item_id, exact_text)` 的中性哈希命名，保存原文实际出现位置集合，但不含 branch/parent/leaf ID。它表示**可复用的文字内容槽**，不宣称相同文字在各分支是同一真值原子或同一法律实体。M2 仍能在不同 branch 创建不同实例。不同位置的相同文本只共享词面载荷，必须保留独立的 occurrence-specific source links 与 role views；只有确切同一原文出现或明确引用才允许合并来源身份。无唯一匹配的内容保留候选位置集合并标 unresolved，不能凭相同字符串合并法律谓词。主体也可共享，但机制覆盖另报非主体条件，防止只凭“行为人”重复夸大作用。

按完整原生单元暴露顺序，构造 `R_t(k)={截至t已暴露单元中，该内容具有的原生 tag}`；训练差分为 `ΔR_t(k)=R_(t+1)(k)\R_t(k)`。新内容生成一次；已有内容获得新角色时产生 `EXTEND_ROLESET(k, ΔR)`，而不是重新生成另一份文字或覆盖旧角色。一次单元有多个角色时联合发布角色视图集合。实际状态保存 `V_t(k)={(tag, occurrence_support, local_version)}`；下文 R_t(k) 是其角色标签投影，用于简洁写公式，不替代来源视图。新增视图保持旧视图；真正纠错时以 supersedes 版本链接更新有效视图，并保留历史记录，不因新角色出现而擦掉旧角色。该操作不输出角色属于哪个 branch；那是 M2 的目标。

已执行 `probe_shared_fragments.py`，只读 manifest 的 256 TRAIN：2301 次条件叶出现可分为1549个内容类、1610个带类型内容类；109来源有跨分支共享非主体内容，47来源有同一内容多个tag（59内容类）。真正跨单元角色增量只有10来源、13次，且13次均有rule_text中的逐字支持。**这说明共享内容机制可训练，但不能将跨单元修订说成覆盖所有数据；主要监督仍包括同单元的联合角色集合。** 统计仅证明监督存在，不是模型效果。

### 6.2 模型及更新

用一个内容解码头生成新内容/源指针，另一个角色集合头对现有和新增内容联合预测各原生角色是否新增。令 h_k 为内容槽，c_t 为本次新文本，v_(t,k)=Attention(h_k,c_t)。对角色 r：

`p_t(k,r)=sigmoid(W_r [h_k;v_(t,k);embed(R_t(k))])`。

`R_(t+1)(k)=R_t(k) ∪ {r:p_t(k,r)>τ_r}`，h_k 的源内容身份保持，局部表征可用新文本更新；在被读到的当前 source 上生成新增内容集 K⁺。训练目标：

`Lcontent=−Σ_(k∈K⁺) log pθ(text_k,source_support_k|c_t,S_t)`；

`Lrole=−Σ_(k,r) [1_(r∈ΔR*) log p_t(k,r)+1_(r∉ΔR*) log(1−p_t(k,r))]`；

`L=Lcontent+λrole Lrole+λhead Lhead+λunit Lunit`，`θ←θ−η∇θL`。

每个内容类只计一次 content loss；role loss 对实际新增角色计分，不因一般支和例外支复制了同一段文字而重复施加相互矛盾的单标签监督。所有已获取槽都可被当前片段查询，不以 gold 指定回指目标；用全槽注意力即可首版实现，不为“小检索器”另增架构。阈值只用 DEV 选择。推断读自身状态；在共同提供给各对照的 TRAIN 自身预测前缀上，可用显式 `REVISE_ROLESET`纠正错误角色，不能因 gold 增量单调便禁止纠错。

新增机制是**把源内容身份与多重法律结构角色分解，按内容槽进行角色集合差分更新，并将一次源获取共享给后续不同语义实例**。它不是跨条款优先级算法，也不预测树父节点。一般内容共享、multi-label loss、注意力本身均已有；本文待验证的是这一组合是否降低重复生成与角色覆盖错误，使新法源的获取更可靠。

### 6.3 真实原生例与非冗余性边界

破产法第三十八条的“但是，本法另有规定的除外”在一般branch是“排除”，在另一个branch是“前置条件”。M1应生成一个内容槽、角色集合 `{排除,前置条件}`，而非把它单分类为一个tag或两次不一致地抄写；M2再分配这两个角色实例。保险法第十六条“足以影响保险人决定是否同意承保或者提高保险费率的”先在U1为“结果”，后在U3为“前置条件”；后续获取只增加角色，不把早先角色覆盖。

普通 AST 编辑器也能表达相同结果，所以“可被通用编辑表达”不构成否决或优势证据。强对照必须包括：展开的 AST 编辑、**同一共享内容表示上的通用 AST 编辑**。共享内容但每步重写完整角色视图集合可作为既有 Edit 控制的固定配置/消融，不额外扩张正式实验矩阵。只有在这些同材料对照下仍改善角色完整性/重复内容一致性或训练/生成成本，才支持此专门差分机制的独立贡献。M1不靠比对照多得到 role 集合监督获胜；所有确定性目标与状态都给对照。

**`Lbind=0`。M1 不计算 condition→branch/parent/op 的loss；这些归M2。** 不再将空的外部依赖闭包或没有原生标注的参数绑定列作M1创新。

## 7. 三层例子与原生实现对应

说明例：b=收到书面删除请求；一般规则应删除项目资料；e=履行约定审计必需的一份归档副本，不受前述删除义务约束；r=含第三方保密信息，前项归档例外不适用于此类资料。完整语义是：

`DeletionObligation = b ∧ ¬(e ∧ ¬r)`。

M1 首先获取删除义务的规范头、效果和 b 条件。读到归档句时，它新增 e 对应的原生条件内容/类型及开放条件接口；读到第三句时获取 r 及其原生 typed fragment。**它不输出假造的 gold defeats 边或角色参数 σ。** 如果原生 G 将一个触发条件在不同分支标成前置条件与排除，M1 的目标库保留两种 typed fragment，M2 必须学会把它们放到实际标注的分支和条件树位置。

这里的公式是机制说明，不能声称 NormBench 恰好有该例。真实训练只按实际原生 tree 生成目标；无法从某条样本 gold 表达出此嵌套时，不用该样本验证这种嵌套能力。

| b | e | r | 删除义务 | 判别作用 |
|---:|---:|---:|---:|---|
| 1 | 0 | 0 | 1 | 一般规则 |
| 1 | 1 | 0 | 0 | e 改变原范围 |
| 1 | 1 | 1 | 1 | r 修饰 e |
| 0 | 1 | 1 | 0 | 不得脱离 b 凭 r 新建义务 |

“归档副本不受删除义务约束”只改变这项义务的范围，不能自动生成一般保留许可。第一行会掩盖 e/r 的遗漏，因此主指标必须包含原生结构，不能只看案件答案。

## 8. 锁定的数据安排

**训练/开发只用 NormBench。** 主预测是 rule_text；full_article_text 只作上下文。实读发布文件有 2290 个语言—条款项目、1790 个底层条款和 193 种 law_title，具体可用量以固定源一致性筛查后冻结，双语/近重复必须同组。计分 gold 是原生 unit/branch/condition tree，不要求另造 defeats graph、端口标注或反事实案件答案。

首个有限实现包可固定 64 个经筛查的 NormBench 条款，每源最多两条暴露路径，按结构覆盖选取而不按模型输赢选取。它是开发包建议而非已完成划分；正式规模由总协议统一设定。按母法源、双语关系及明确跨单元依赖成组划分。

SARA、ContractNLI/ACE 和审核通过的 Catala 子集仅用于后续外部迁移/诊断。**SARA gold 不参与本版训练、差分目标生成、模型选择或阈值调节。** 原生绑定可用于外部测量当前能力缺口，但本版未训练绑定头，不能把这一项写成已经解决。将来若要加入 SARA 监督，须另立训练版本并重新划分，不能追溯修改当前 external-only 声明。

## 9. 最近邻差异：承认现成部件，锁定新增机制

| 工作与已读部分 | 已经做到什么 | 本方案的具体差别及不可声称事项 |
|---|---|---|
| [FUBL, EMNLP 2011](https://homepages.inf.ed.ac.uk/sgwater/papers/emnlp11-fubl.pdf)，§5–7 | 分解 lexeme/template，并能借模板引入隐含语义常量。 | 不能说 FUBL 不能长新节点。M1 用原生源图的暴露过渡监督规范头、typed leaf 及开放条件接口的变化，不把整句 LF 再分成既有词项组合；应与同监督的 factored parser 比。 |
| [SketchAX, POPL 2020](https://www.cs.purdue.edu/homes/roopsha/papers/sketchax_popl20.pdf)，§4–5 | 利用关系扰动属性增广输入/输出约束，并推断相关属性。 | M1 训练一个从自然语言新增片段生成语义差分的解析器，目标是新增规范头、条件节点及待组装接口，不只是合成满足额外真假关系的候选程序。如果只把过渡变成更多问答约束，差别消失。 |
| [Xpose](https://arxiv.org/html/2504.10898v1)，§3、§6 | 文本与黑盒响应结合，修正查询，并在嵌套骨架中做组合搜索。 | M1 不要求测试法源有黑盒 gold；独立结构只在训练监督中使用，测试由原文生成语义状态。不能声称首次结构分解或首次用反馈。 |
| [RuleChef](https://arxiv.org/html/2607.01293v1)，§3 | 依据案例失败与反馈生成/修改规则，按开发表现接纳补丁。 | M1 的差分是读到新原文的语义获取动作，不是案例错分后的规则补丁；输出改变由原生源图监督，不以涨分才接纳节点。 |
| [NormBench / SG-DT](https://arxiv.org/html/2606.08932v1)，§3.2–3.4、§4 | 源锚定规范树、显式例外排除和完整结构评分已存在。 | 采用其语义而不重新命名为新 IR；拟新增节点获取与开放条件片段的差分生成，最终范围由 M2 学习原生条件树组装。必须有同信息 SG-DT 全图解析强对照。 |
| [CoE-SQL, NAACL 2024](https://aclanthology.org/2024.naacl-long.361.pdf)，§3 | 已定义编辑操作、比较 AST 得最短编辑链，并用它提示多轮 SQL 生成。 | 程序差分不新。M1 的具体增量必须是内容槽与多角色集合分解、按共享内容回指更新的差分解码，不能只替换 SQL 词汇。通用 AST 编辑模型是必需对照。 |
| [De Jure](https://arxiv.org/html/2604.02276v1)，§3 | 分层抽取、19 维 judge、先修上游再修规则。 | M1 更新可训练参数，监督来自独立源结构；不把 coverage/judge/retry 称创新，也不依赖 judge 为漏节点打 gold。 |

目前查到的直接邻近工作没有把上述训练状态、投影监督和联合差分更新作为同一个方法交付；这是具体的区别，不是“证明世界上无人做过”。所有组件可由通用程序表达也不构成否决，真正需要比较的是监督、预测单元和状态更新是否相同。

## 10. 同信息对照与独立评价

固定同一模型、NormBench 源/结构材料、训练 token/步数、单元监督和后端：

1. 全文→完整原生 SG-DT 的监督解析器；
2. 相同暴露路径的普通增量片段生成器；
3. 相同 `(S,e,S')` 的通用 AST 编辑器，允许任意新增、删除、改标签和重连；
4. M1 源差分模型；
5. De Jure/RuleChef 风格抽取修复作系统参考，其额外调用成本另列。

M1 独立指标：unitization、规范头/效果、typed fragment 内容与类型、源支持一致性、遗漏率；M2 指标：实际 condition→branch assignment、parent/op/scope 和完整条件树。完整系统再报告原生整树与能获得原生答案的外部任务。第一版不报告训练出的参数绑定能力或不存在的 gold defeats-edge 指标。

最小 2×2 消融是普通获取/M1 × 普通树组装/M2；每格使用同样原生监督。若普通 AST 编辑器获得同样差分材料便达到相同表现和成本，则 M1 的专门分解没有显示独立必要性；如实报告，不新增标签来偏袒本法。

关键 M1 消融：展开内容而不共享、共享内容但使用单标签角色、共享内容且每步重写完整角色集合而不预测差分。源暴露合法性作为所有方法共同约束，不以故意泄漏未来的对照充当消融。不存在 gold 的 σ/defeats 模块不作“开关”消融——第一版根本不实现。

## 11. 实现与对方法二的接口

实现模块：`normbench_native_adapter.py`（rule_text/context 分离、ID 去目标泄漏）、`source_projection.py`（保守单元暴露及未定状态）、`delta_gold.py`（共享内容类与角色集合差分）、`delta_decoder.py`（unit/head/leaf/reference）、`native_metrics.py`。保留原生 G 的 branch/parent 关系作为 M2 监督侧文件，不能混进输入。

导出接口最少为：`target_source_hash, predicted_units, branch_heads, content_payloads, provenance_role_views, native_tags, source_support, open_condition_ports, visible_reference_text`。不带 gold branch_id/leaf_path、defeats、typed argument bindings。模型预测的局部 ID 可使用，评测 ID 映射只在评分器中运行。

先完成 source/context 边界、原 ID 泄漏、投影与 Apply 重建等确定性检查，再一次固定的小规模训练；不需要先取得所有模型指标才承认方案可实施，也不启动无限补实验。

本版职责明确：**M1 从源原文获取此前缺失的开放片段；M2 学习这些片段属于哪个真实分支、在条件树中怎样组合。** M2 不以重新预测源节点冒充组合改进；M1 不靠已知 gold 父子关系制造正确范围。原生第一版已经选定，不再将缺失端口标注作为阻塞前置条件。

# 法律规则语义学习：共享语义获取与作用域交互组合

日期：2026-11-10。方案标识：LSG-LSL-20261110。状态：推荐进入实现及首轮真实训练验证。

本方案替代旧 A/B、旧 M1/M2 及固定候选森林重排的研究主线。保留旧代码和实验作为可复用资产与失败证据；新的数据、训练和完成条件以本文件及 protocol.json 为准。详细方法文件是技术展开，首轮范围以本文件为准。

## 1. 研究问题和论文主张

**从法律文字获取规则时，既要学全每项条件和法律效果，也要学对这些条件约束哪个结论、处于哪个作用域。** 一次案件回答正确并不能区分这两种能力：漏掉的条件可能未被当前案件触发，挂错的条件也可能碰巧给出同一答案。

服务器截至 `2a9eeeb05e9da6d46ebb69a7dbd5679df102ba63` 的探索表明，固定解析候选重排、少量产生式组合和事后接口修复未能解决缺失节点及语义范围获取。新方案据此改变学习对象：直接学习原文到规则的获取和组合过程，而不是继续扩充无法补出缺失语义的候选排序器。旧八来源“没有新增成功”是那组机制诊断结果，不是新任务的基准准确率。

建议论文工作题目：**面向法律规则学习的共享语义获取与作用域交互组合**。

两项贡献分别是：

1. **共享语义差分获取（M1）**：将条件内容和它在不同规则中的法律结构角色分开学习，一次获取内容，联合保留其多种角色，并随新原文增加角色视图，减少遗漏、重复生成及角色覆盖。
2. **语义交互组合（M2）**：固定局部语义内容，学习条件归属、条件树作用域与分支组合；用确实改变分支行为的组合分歧训练上下文交互模型，区分“条件都抽到了”和“法律逻辑组合正确”。

本轮的研究增量是上述两个学习机制，不将 SG-DT 表示、AND/OR 求值、LoRA、一般程序编辑或对比损失本身称作原创。

## 2. 一个贯穿例子

以下为构造的合同例子，用于解释机制。

1. 收到书面请求后，应删除项目资料。记收到请求为 `b`。
2. 履行约定审计所必需的一份归档副本，免于前述删除义务。记符合这一例外为 `e`。
3. 前项归档例外不适用于含第三方保密信息的资料。记含此类信息为 `r`。

正确删除条件为 `b ∧ ¬(e ∧ ¬r)`。

- M1 要获取 `b、e、r` 及其原文依据，保留同一条件在一般规则、例外分支中的不同角色，不能只留下第一句或让一种角色覆盖另一种。
- M2 要把第三句接到第二句的例外范围，而不是当作另一个并列排除或无条件删除授权。
- `b ∧ ¬e ∧ ¬r` 在 `(b,e,r)=(1,1,1)` 时错误；`(b∧¬e)∨r` 在 `(0,1,1)` 时错误。

这解释了两个独立问题：**内容遗漏需要获取机制解决；内容齐全但组合错误需要组合机制解决。** 豁免某项义务不自动产生相反许可。

上述三层例子已穷举八种布尔赋值核验，见配套脚本及结果。原生主数据的实际覆盖见第5节，不把这个例子当成已训练成功的样本。

## 3. M1：共享内容与多角色视图的差分获取

### 输入、学习对象和输出

输入为新暴露的文本片段、已经读过的文本、已获取的局部状态。输出为新条件/效果内容、来源位置、该内容的角色视图及开放接口。它可以生成先前状态中不存在的内容，也可为已有内容增加新的角色。

法律中的同一条件可能既是一般规则的排除项，又是例外规则的前提。M1将文字内容放在共享内容槽，另存带来源的多个角色视图。后续原文补充角色时，回指原槽、增加视图，而不是覆盖原角色或重新生成不一致的文字。相同文字在不同位置不自动视为同一法律谓词；各自来源位置和角色实例仍保留。

首版直接采用 NormBench 实际提供的规范类别、条件叶、AND/OR、分支和效果字段。没有标注的实体端口、远程调用绑定和显式 defeat 边不加入首轮训练头。

### 监督构造

以 `rule_text` 为待转换目标，`full_article_text` 只提供上下文。沿源文本顺序逐步暴露句段；依据已有 gold 结构形成可见投影 `Π_t(G)`。保留已暴露节点及有可见依据的局部关系，未完成范围统一用通用开放状态表示。不能把尚未出现的 gold 节点数量、类别或 ID 放入输入。

一次差分是 `Π_t(G) → Π_(t+1)(G)` 的内容及角色视图更新包。新内容监督一次，已有内容的角色新增联合监督；具体分支归属和条件树位置留给M2。源文本暴露是训练视图，不冒充真实法规修订。

实际256条TRAIN中，109条含跨分支共享的非主体内容，47条存在同内容多角色；跨单元新增角色为10条、13次。因此主要研究对象是共享内容及多角色获取，跨单元修订是其中一个可测子类。单元间依赖字段在本批数据为空；虽有24条包含跨条引用，但缺少完整可执行绑定监督，因此不把依赖闭包作为主要创新。

源跨度无法唯一对齐的 gold 内容保留在最终整图监督和评测中，但不伪造精确的差分跨度标签。记录实际可投影比例。

### 首版算法

使用 Qwen3-8B 的 LoRA 内容解码器与角色集合头。内容头生成新增文字/源指针，角色头查询已有及新增内容槽，预测带来源的角色视图增量；训练结合内容生成、角色集合、规范头与单元监督。训练用已知前缀状态，推断使用自身生成状态。TRAIN自身预测前缀用于学习纠错，对照获得相同状态和材料。

**新增机制的落点**是把源内容身份与多重法律结构角色分解，再按共享内容进行联合角色差分学习。它既不同于重复生成展开的规则树，也不把一个条件强制单分类。普通增量/编辑对照同样允许多角色，并获得相同共享表示和监督；两者比较验证专门学习机制的增量。具体概率、损失和版本动作见 `method1_design.md`。

## 4. M2：上下文语义交互驱动的组合

### 首轮任务

接收局部条件、规范/效果及源跨度，预测每个条件属于哪个 branch、条件树父节点以及 AND/OR 嵌套。首轮不依赖额外的深层例外关系标注。

普通全局图解析器作为基础：节点和源文本表示 → 关系评分 → 受结构约束的 beam。M2 在此加入读取祖先上下文的交互评分头，联合处理会改变法律分支适用范围的组合决策。

### 训练信号

对同一个 TRAIN gold 图保留全部局部节点，构造条件错归属、同类型目标交换及作用域重接的可执行候选。对共享原子条件的候选，求出使其激活分支/效果不同的布尔赋值；只将确有行为差异的候选作为语义错误。证明等价的组合进入同一正确等价类。

学习目标包括 gold 关系监督、上下文交互监督和语义错误组合的结构化间隔。更新聚焦产生行为差异的组合决策，不把所有正确抽取节点一起判错。

核心交互头固定为：取两个归属/父边决策，各有两种选择，构成同节点的四张合法图；分别计算分支激活 `Y00,Y01,Y10,Y11`。其交互为 `I=Y11−Y10−Y01+Y00`，训练gold定向后得到错误交互 `J=(1−2y*)I`。对四格负错误表做双重中心化，去掉两个单独决定的主效应，训练模型预测剩下的联合能量。这样明确教模型学习“两个决定一起做时”的错误作用，而不只是重复学习两个单边分数。测试时预测交互方向，不提供 `y*`。

这个训练目标的64次形式恒等式检查已通过。对实际256条TRAIN的有限搜索，还在29条找到合法四格的非零交互见证，说明现有数据能产生该监督。它们是数据/算法可行性证据，不是模型准确率。具体交互头、归一化和四格构造见 `method2_design.md`。

首版见证指“给条件叶赋真值时，激活哪些规范分支/效果”的**抽象结构语义**。它能检验组合逻辑，不等于已标注的真实案件事实。排除叶采用官方结构的规范化约定，不通过关键词额外反转两次。

推断阶段从文本和预测的局部语义生成组合，由已学习的组合器选择；不读取 gold。求解器能区分不同/等价候选，不能自行判定哪一张图符合原文。

### 两项如何接起来

`原文 → M1 获得局部语义差分 → M2 组成完整规则图 → 固定验证器/解释器 → 规则结构及其分支行为`。

学习成果是可迁移的模型参数与有来源的训练记录。可以继续沿用 LegalSkillGuard 仓库，但本论文不必维持旧“教师不断往技能库写模板”的形式。教师帮助核查少量疑难记录，日常训练依靠已有结构 gold 和确定性监督构造。

## 7. 首轮实验：获得真正的指标，不止工程完成

使用固定256条训练、64条开发。先在 TRAIN 子集检查解码和学习流程，流程可训练后继续完整训练；不以小试涨分为进入条件。TEST 的128条留给冻结后的下一阶段。

评测七个系统：

| 系统 | 获取 | 组合 | 主要比较 |
|---|---|---|---|
| B0 | 同模型直接整图 SFT | 整图输出 | 排除“只是微调收益” |
| B1 | 普通局部抽取 | 普通全局图解析 | 可组合基础系统 |
| M1 | 源差分获取 | 普通全局图解析 | M1 的独立作用 |
| M2 | 普通局部抽取 | 语义交互组合 | M2 的独立作用 |
| Joint | 源差分获取 | 语义交互组合 | 联合作用 |
| Edit | 通用 AST 编辑获取 | 普通全局图解析 | M1 的最近强对照 |
| Contrast | 普通局部抽取 | SQLoom 风格同信息对比组合 | M2 的最近强对照 |

共享可以严格复用的抽取模型、训练缓存和组合头，避免七套重复全量训练。所有系统可获得相同原文、gold、源暴露状态和语义见证，披露优化 token、训练步数、调用和时间；对照不因人为少给数据而变弱。SQLoom 适配版须按原方法实现相应集合目标，明确为适配而不是声称原论文官方法律实验。

主要指标：原生节点跨度 F1、条件归属/作用域边 F1、规范化整图正确率；补充分支行为等价率、未解析率、每来源时间与费用。按法源家族宏平均，并给出法源分组区间；开发集的区间用于诊断，不冒充最终确认性结论。

M1 必须观察完整条件/分支获取，M2 同时报告 **给定 gold 局部节点的组合诊断** 和 **预测局部节点的端到端结果**，前者定位机制，后者决定实际收益。缺失节点、非法图或未完成记录计入总体分母。布尔结构等价率与真实法律问答准确率分别报告。

每个 epoch 记录训练损失与固定 DEV 指标，给出真正的学习曲线。对新法源的提升是本阶段的迁移证据；SARA/Catala 的跨数据集迁移属于后续原生应用验证，不提前认领。

## 8. 实现和资源路线

沿用 Qwen3-8B，thinking OFF；首版采用 LoRA 获取器及轻量组合头。服务器已有 Qwen 权重快照的历史证据，路径及当前 GPU 状态由服务器核实。优先使用既有模型、依赖和可用资源，合理排队/恢复，不下载另一套大模型来绕开问题。

默认实现：LoRA rank16、3个训练 epoch、固定种子45；组合头为256维隐藏层、祖先上下文最多3层、beam8。它们是首轮默认值，不是额外停工门槛。batch、精度、累积步数、序列长度由实际显存和原文长度确定，固定后记录；不得截断关键法律条件后继续计为有效训练。详细数值配置在训练开始前形成运行快照。

允许重写不合适的旧接口，优先独立实现 `data/projection/acquisition/composition/semantic_witness/evaluation` 六个清晰模块；语义一致的解码、账本、持久化和评分组件直接复用。旧格式兼容、全仓框架重构与更多候选选题不作为任务。

教师沿用既有 Codex CLI 配置；是否显式暴露 temperature 只需如实记录，不是阻断。教师不是本任务训练标签的唯一来源。调用持续记账，不恢复过去96/100次或按修复轮数授权的限制。

## 9. 推进阶段与本次 Goal 完成线

**本次 Goal：实现 + 完整首轮训练 + 同信息强对照开发验证。**

顺序：同步服务器最新有效进度 → 核对并冻结主数据 → 实现两个模型及对照 → 小规模训练排错 → 完整256来源训练 → 64来源七系统开发评测 → 针对明确实现/训练失配作有证据的修正 → 提交可复现实证包。

常规错误自主处理并接着跑；同一实现和输入的重复结果复用。研究主线固定，首轮不搜索其他任务，不增添第三方法，不为涨分不断加数据、种子或换模型。需要改进时优先修正明确的监督投影、目标函数或训练失配，并向全部相关对照应用等价修正。

交付必须包括：代码和权重/组合模型、数据/配置哈希、七系统逐来源预测及指标、学习曲线、两个独立增量与强对照比较、未解决错误归因、成本时间账本、复现命令，以及进入冻结测试阶段的明确建议。以报告、单元检查或少数成功样例结束，均不算完成。

完成本次实证不等于宣布论文两项贡献已经获证。结果支持哪些贡献，按真实比较决定；若一项仍弱，应交付其已实现、已完成比较的事实及具体改进结论，而不是带着未跑实验的诊断结束，也不以无限跑到正结果作为完成条件。

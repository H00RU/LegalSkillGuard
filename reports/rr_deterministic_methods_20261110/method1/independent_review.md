# 方法 1 独立实现审查

日期：2026-11-10。审查者未修改 `direct_recovery.py` 或 `run_validation.py`；反馈后由实现代理修复。独立检查程序为 `independent_review_checks.py`，结果见 `independent_review_checks.json`。

## 结论

**没有发现探测器读取隐藏分组、运算次序或参考 AST。外层封顶隔离在明确限定的 DSL 与合法域条件下成立。** 使用独立的精确有理数解释器，检查 1,088 个隐藏模型、43,520 个额外多记录输入，未发现恢复函数与参考函数不一致。

独立检查发现并反馈了两个具体实现问题：中间有界域会触发非法探测；不同方法的耗时计量包含了不同评分开销。前者已确认修复为无非法调用的 `unsupported_domain`；后者已静态核对修复为统一的学习器返回截止点。运行时间须引用与修复后代码 hash 一致的新结果，不能沿用旧速度比。

本审查支持受限问题内的信息公平与代数正确性，不证明该方法的新颖性、不证明原生法律任务效果，也不将有限压力测试当作任意记录数量的形式证明。

## 1. 接口是否泄漏真值

恢复函数只接收公开 `PublicSpec` 与 `.query(...)` 接口。其代码不接收候选模型表、隐藏模型编号或参考程序。随后选择探测，依据的是：

- 公开的金额上限 `C`、可选外层上限的数值 `B`；
- 公开记录的特征列及可用取值；
- 是否允许非零排除额；
- 已取得的 oracle 输出。

因此“已知 C/B”必须写为任务的信息假设，不能描述成算法从未知法条自动发现阈值。候选语言只允许按公开 key 子集分组或按 record ID 分组；不允许任意隐藏分组谓词。

公共查询池根据全部允许候选和公开常数建立，不根据当前隐藏真值选择。枚举候选模拟输出用于通用对照，是公开模型类的计算，并不等于提前告知哪个候选是真值。

`same_probe_constraints` 复用直接法产生的自适应输入序列，是“同探测、不同结构恢复”的消融对照。它不是无需直接法参与就能生成该序列的独立主动策略，不能把这项实验解释成另一个完整独立学习器。

## 2. 外层封顶隔离的数学核查

记各组金额、排除额之和为 `T_g,E_g`，公开域要求每条记录 `0≤E_i≤T_i`，所以 `T_g-E_g≥0`。

### 2.1 先识别次序

选择 `q=min(C,B)/2`，单条记录为 `(T,E)=(2C-q,C-q)`。

- cap 后扣除：`max(0,min(C,T)-E)=q`，因 `q<B`，外 cap 不改变结果。
- 扣除后 cap：内结果为 `C`；最终结果为 `C` 或 `min(C,B)`，均严格大于 `q`。

单记录不依赖分组。因此这个探测不需要事先知道 scope、order 或 outer 开关；只要金额域允许这个输入，它就能区分两种次序。

### 2.2 cap 后扣除时恢复分组

选择 `q=min(C,B)/4`，两条活跃记录都取 `(C,C-q)`。

- 同组：`max(0,C-2(C-q))=0`，因为 `2q≤C/2`。
- 不同组：每组得到 `q`，总值 `2q≤B/2<B`。

所以外 cap 严格不活跃；0 与 `2q` 可以区分共享/分离组。该式确实解决了“外 cap 会掩盖双记录试验”的一部分情形。

### 2.3 扣除后 cap 时恢复分组

若 `B>C`，选择两条 `(a,0)`，其中 `a=(C+min(B,2C))/4`。于是 `C<2a<B`：同组得到 `C`，不同组得到 `2a`，外 cap 不影响区分。

若 `B<C` 且外 cap 已确认为开启，则不能恢复一般分组。代码使用的恒等式有效：

\[
\min(B,\sum_g\min(C,T_g-E_g))
=\min(B,\sum_i(T_i-E_i)).
\]

证明：总净额不超过 B 时，每组净额均不超过 C，内 cap 全不活跃；总净额超过 B 时，若某组超过 C，则其 C 已不少于 B，否则内和就是总净额，均被外 cap 截为 B。

`B=C` 同样存在整类行为等价。代码将它们保留为不可观察的 scope/outer 歧义，而不是宣称识别了隐藏真实结构，这是正确处理。

### 2.4 外 cap 永不活跃的证书

若当前记录宇宙中至多 r 组，每组结果不超过 C，且 `rC≤B`，则外 cap 对此固定宇宙确实不活跃。此结论不自动扩展到增加新记录、出现新组的情形。

## 3. 独立验证覆盖

独立脚本不调用原实现的 `evaluate`。它用另一份按组收集记录、直接有理数计算的解释器，避免相同整数编码错误同时污染参考与预测。

覆盖：

- 5 类特征结构，包括重复特征、完整两键组合、相关特征、无单键干预对的三键特征、单记录；
- `C=7` 与 `C=1/3`；
- `B/C` 为 `1/2,1,3/2,10`；
- 有/无排除额；
- 允许的全部可观察分组、两种次序、两种外 cap 开关；
- 独立生成的金额和排除比例，包含大于阈值、非原验证网格的有理数。

结果：1,088 个隐藏模型、43,520 个预测比较、4,574 次学习查询，零不一致。输入随机数种子固定、结果可复现。这是有限额外证据；上节代数推导才说明某些保证为何超出所测金额网格。

## 4. 发现、反馈与修复

### 4.1 中间有界域：已修复安全性，未增加识别能力

旧实现只特判 `total_bound≤min(C,B)`。但接口还接受其他有限上界。例如 `C=7,B=12,sum(T)≤8`，首探测需要 `T=10.5`，违反输入域。

已反馈并确认修复：探测提交前检查域；该例返回 `unsupported_domain`，oracle ledger 长度为 0。方法没有在这个域上完成恢复；不能把安全拒绝算成识别成功。

### 4.2 运行时间边界：必须使用修复后结果

发现时，direct 的计时在学习器返回后结束，max-disagreement 与 optimal-tree 的计时却包含随后 512 个 holdout 输入的评分。此时速度比较不公平。

实现代理已把各方法的学习耗时都在学习器返回后立即截断；独立审查确认 `greedy_active` 与 `follow_optimal` 返回后立即保存 `learner_seconds`，随后才进行评分。旧结果中的速度比不可引用。本审查不靠这些时间差作正面结论。

### 4.3 返回可迁移 key 表达式

旧输出只有当前记录的 partition。实现代理已增加 `reusable_key_expression`：独立单键探测充分时返回 key indices，record-ID 情形返回相应标识；相关特征或被外 cap 完全掩蔽时保持未知。

这项修复允许明确表达已识别到哪个层次。固定记录 partition 的成功仍不能替代新记录上的 key 迁移检验。

## 5. Oracle 与计算账本

原 `QueryOracle.query` 没有缓存：每次调用都执行一次隐藏参考函数并写一条记录，所以 learner query 数包括重复请求。探测输入的代数构造本身不调用 oracle。

但 learner ledger 不是整个验证作业的全部参考/DSL 求值数。候选输出表、512 个隐藏压力输入的评分、恢复结果评分、隔离审计和同探测候选过滤都有额外求值。它们应与学习查询区别报告。

实现代理已加入阶段计数，至少区分：`learner_acquisition_truth`、`candidate_precomputation`、`reference_stress_scoring`、`isolation_audit_candidate_simulation`、`same_probe_candidate_filtering` 与其他评估。查询池构造、候选枚举、DP 预处理也不能在端到端复杂度或总运行时间中被描述为不存在。

`complete_programs_enumerated=0` 正确描述的是直接恢复器内部，不是整个比较脚本；比较脚本确实枚举完整候选语言来运行强对照和检查。

`local_decisions` 只计部分探测与判断，不是所有 Python 算术/特征配对操作的精确计数。不能直接当作完整操作复杂度。

## 6. 数学与实验范围

- 直接恢复使用精确 Fraction；原验证 harness 用 `SCALE=8` 编码，主表只覆盖兼容 1/8 格点的公开常数与探测。不能据此声称 harness 支持任意有理数；独立检查补充了 `C=1/3` 的直接算法验证。
- 金额非负，且单条排除额不得超过金额。负数、跨年结转、负税额、任意异常排除、未知 cap 数值、舍入/ceil、多层嵌套 cap 等均不在已检验的 DSL 中。
- 特征宇宙和记录数固定。相关特征时只恢复可观察 partition，不能猜唯一 source-level key 表达式。
- 主结果的行为类由有限查询池定义，额外 512 个输入也是有限压力检查。`tests_are_finite=True` 是正确标记。
- 上述代数证明可支持固定记录宇宙、合法非负输入域内的一些一般结论；不等于无界记录数量、任意法律计算的等价定理。
- `query_mean` 是对语法模型逐一运行的均值；DP 的 `expected_queries_uniform_class` 是行为类均匀权重。二者加权不同，不能直接拿两个数当作同一平均查询指标。

## 7. 对研究结论的影响

受限 DSL 内，直接恢复器确实可以不枚举完整候选程序而恢复行为所需结构，外 cap 隔离并非偷偷利用隐藏次序得到的结果。

但现有结果不支持“查询数优于强主动合成”：例如原始 12 模型测试，直接法平均约 3.33 次，max-disagreement 约 1.50 次，执行最优树约 1.42 次（后三者按相同语法模型测试统计）。直接法的潜在优势是有明确代数前提的直接计算；是否构成相对最近算法的新增贡献，需要另外的查新与复杂度分析。

本次无需为这些已明确边界启动模型训练。应该保留确定性代码和原始账本，将数学适用范围与运行代价口径写准确。

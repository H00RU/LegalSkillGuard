# Partial source-attachment learning diagnostic

This is an experiment record under the same Goal and two current documents.
It does not revive a request/round cap or add an acceptance condition.

Learning object: shared parameters on grounded source interpretation and
cross-norm attachment/binding features. Update: exact marginal likelihood of
all type-valid assignments compatible with native TRAIN labels and three
author-checked partial source constraints. The third constraint on original111
couples retention exception, return obligation, subject and information object;
it is not independent label correction on each norm. Unit Gaussian shrinkage
and optimizer defaults are fixed once; no hyperparameter/seed scan. This is an
ordinary conditional log-linear model. Rewriting it as a same-feature linear
model is mathematically equivalent and cannot be claimed as a second mechanism
or new CRF mathematics.

Common source forests come from the existing Qwen/OFF model, full originals and
existing claim/action/receiver anchors. Original predicted effects, native
labels and corrective feedback are withheld from this common proposal step.
Source spans and semantic operator/type information are shared by all controls;
their acquisition cost is charged in every arm. They are not ground truth.
Do not invent distractors when only one reading is plausible. If the real
forests leave no learning ambiguity, preserve that result instead of corrupting
the prior to manufacture an update benefit.

Author supervision refines existing TRAIN15/20 source feedback into head/polarity/
condition/reference constraints; original111 adds the actual archival retention
exception and common subject/information binding. Both sides get every span and
constraint. No native hypothesis/label pair or dataset source is added. Record
three annotated mothers/constraints, the underlying spans and author effort;
do not charge them as zero-cost model-discovered knowledge.

First obtain actual TRAIN15/20 forests to check compact IR availability, source
grounding and ambiguity, then complete the existing four supervised TRAIN
mothers if warranted. Invalid output requires exact offline localization before
a changed retry; no unchanged reruns. No first-error/round authorization rule.
Any failed generation/retry remains physically charged.

Controls must include the frozen actual proposal prior, hard-EM on exactly the
same forests/features/feedback, same-material correction retrieval, and an
independently learned unrestricted ordinary selector using the same compact
interface. Same-feature log-linear equivalence is reported explicitly. Before
reserved source execution freeze methods, controls and source scoring. Original
TRAIN114/116/117/118 are fixed before generation as source-only reuse;112 is
development evidence. No new native questions/labels for these sources.

What could justify continuation is an actual learned attachment/binding update
that corrects source meaning on unannotated combinations, or a supported cost
effect against these controls at comparable correctness. Source-only correctness,
native TRAIN fit, correct operator priors and overall Goal completion are
different evidence. Non-conduct/negative-norm residuals cannot become a grant
or default native absence; all fallbacks and unsupported bindings stay explicit.
If the prior or strong ordinary controls absorb the effect, do not expand this
candidate or buy DEV calls to rescue it. No main training/full matrix/TEST/paper.

Tools adopted rather than claimed new: factored lexical/template induction
(Kwiatkowski et al.2011), latent structured alignments/abstract programs
(Wang et al.2019), legal negation-scope learning, and SG-DT's typed
core-predicate/condition/effect decomposition. Their gap here is not missing
notation: it is whether partial legal source feedback teaches reusable
attachments under strong same-information controls.

Observed interface revision, preserved as v1/v2 within the same Goal: the first
Qwen request ended normally (369 output tokens, thinking OFF) but returned only
one of four claim IDs, used the action category `share` instead of a source
verb, and used an empty exception target. These are not truncation or learning
success. Version2 requires each actual claim as a separate schema property,
uses only literal action words from that claim's existing support as the shared
anchor menu, and permits only existing target IDs or null. No missing reading
or semantic rule is deterministically manufactured. The real failed response
is the offline regression, and its physical request remains charged.

Version2 covered all four IDs without truncation, but rephrased a qualification
and encoded lexical prohibition together with head negation, which would double
negate its meaning. These outputs are preserved, not repaired from expected
answers. Version3 expresses meaning once as unary operator code (e.g.F(A),
O(NOT(A)), NOT(BREACH(A))). Shared elementary semantics and source evidence
remain public to every control. The15/20 availability probes request only the
single existing claim addressed by their source feedback; unrelated records
are not an additional whole-source gate. This does not count as complete-source
acquisition or restore the old0/89 executor-IR numerator.

The next deterministic compiler binds an expanded action operand only when its
literal action, receiver domain and object already agree uniquely with the
same response/claim. It never changes F versus NOT(P). Qualification role
assignments are explicit latent hypotheses over the observed source fragments,
with the original assignment as their prior; they are not silent repairs from
gold feedback. Context fragments remain recorded. A raw response is reused
only when its exact full model payload is unchanged, including schema/config.

Do not manufacture learning gains from an undeclared strong/weak-permission
distinction. In particular F(A) versus NOT(P(A)) may be dual formulations under
ordinary deontic semantics. The15 partial constraint therefore rules out a new
positive grant and constrains the reference attachment; it does not train an
artificial distinction between those formulations.20's NOT(BREACH(A)) remains
a distinct legal-consequence target. The existence of a compatible candidate
is acquisition coverage, not proof that a learned selector improved semantics.

TRAIN111's actual new-model forest omitted any retention permission and used
bare action operands. Do not turn its O(retain) into P(retain). The preserved,
previously paid ordinary compiler already supplies the O/P heads, so include
those as separately identified seed proposals, equally for every control.
They are old learned results, not new core successes. Bind a bare operand only
when it is exactly the claim's declared action. Reject destroy/copy as aliases
for the different return-or-destroy/retain actions.

The common reference resolver can identify the same underlying information
under an explicit `such` reference only when one owned Confidential Information
antecedent occurs in that same existing support unit. It preserves all-versus-
one-copy phrases; it never declares those physical objects identical. Ambiguous
or other objects remain unresolved. Same-support exception edges are grammar
hypotheses, not asserted new rules; their direction and bindings are learned/
checked. These common components and seed results belong in the strong controls.

# Matched-knowledge contrastive procedure diagnostic

Frozen before its one teacher call or any new native generation, and before the
operator reads the completed final-assessment endpoint metrics. This is a bounded
development diagnostic, not another formal training run or independent repeat.

## Question

Does preserving the relationship between alternative legal conditions in a
coherent procedure improve execution relative to mechanically flattened copies
of the **same newly compiled knowledge**? Earlier atomic records sometimes
acquired an exception's relation without establishing its condition. This is a
testable hypothesis, not a finding that grouping necessarily fixes the problem.

- One existing authorized gpt-5.6-sol/high compiler receives the actual last
  published M4 library, all 24 original training documents/annotations, grouped

- No B1 retention answers, endpoint texts/answers/annotations/metrics, other

  fixed number of skills, branches, outcomes, skill families or deletion quota.
  Grounding case IDs/rationales remain provenance, never runtime lookup tables.

## Two encodings, one knowledge bank

`coherent_branches` contains a common inspection and its source-grounded
alternative branches. Each branch has its exact public hypothesis, condition,
inspection, conditional relation and evidence requirement. Common relation is
null, not a NotMentioned verdict. Generic inspection-only records can have no
branches. No requirement to invent an opposite outcome or default to NM.

`flattened_branches` is a deterministic, no-LLM projection: each branch becomes
one original four-field atomic record, repeating verbatim its common and branch
condition/inspection/evidence text and retaining its relation and exact public
scope. Generic records retain the same four fields. IDs are deterministic and
reported. No semantic rewriting or additional knowledge in either arm.

Both full compact-JSON libraries must fit the existing **4096 live-token** cap.
Failure terminates with actual costs; no pruning, retry, fallback, bank selection
or score-based admission. Repeated common text and differing IDs/lengths are
reported; this is an organization/serialization contrast, not token-matched.
Every valid compiled bank is evaluated unconditionally. Host never chooses a
branch, legal relation, source citation or repaired answer.

# 两个经验学习方法的四批法律适配比较

在读取当前六条件后续八来源结果之前冻结；是有限开发比较，不是官方测试或独立学习重复。
不因结果选择是否执行，不按本轮分数选择旧库，不热改已经运行的候选。

## 为什么需要这项比较

已有真实轨迹包含“教师拿到Gold但技能没有稳定改善新案”“查询有原文命中但律师漏用”以及
“补全依据和破坏正确答案并存”。只有强空库/静态/同源无轨迹及示例消融，还不能证明我们
优于现有经验学习算法。本项实现其关键更新/执行机制，检查同一8B和8份训练来源下是否能更好学习。

## 适配及不能冒称的部分

### ACE-legal

固定[作者commit](https://github.com/ace-agent/ace/tree/82709de050e1db6e6ef2f07bcb0393560b94992a)。
保留原生Generator提示前缀、逐案Reflector、helpful/harmful计数、单组Curator ADD及原生ID分配；
相同批内重复tag沿用作者最后值语义，不私改成累计票。每批2个反思、1个curator，共12次教师。
一组curator覆盖本批两案，所以不添加不存在的多组reducer。
沿用已恢复的原作者三角色模板和确定性编辑实现；修正批量从4改为2案后进度显示的计数，
使curator看到实际已处理案数，而不是4×batch。
法律适配：一次回答原17命题和原SPAN，采用共同公共输出Schema；只给公开回答、不提供私有思考；
反思只在训练后进教师，不把当前Gold反思喂回当前律师进行oracle重试。保留全部原文，不剪裁输入。
因此是明确的法律任务适配，不是逐字运行原数学/交互环境的完整复现。
另跑ACE自有Generator+空playbook的8案终点，区分其提示模板收益和学习收益。

### ExpeL-derived-legal

固定[作者commit](https://github.com/LeapLabTHU/ExpeL/blob/e41ec9a24823e7b560c561ab191441b56d9bcefc/agent/expel.py)
`e41ec9a24823e7b560c561ab191441b56d9bcefc`，实际源码743行，SHA256
`7db4e1be3c16dfca589eb2e194cfb4604be224dab32a04f7f03c4529b1dfcf74`。
三个原生计数函数与实际下载的固定源码逐AST一致：REMOVE/AGREE/EDIT/ADD顺序，ADD支持2，
AGREE/EDIT+1，REMOVE-1（软列表满时-3），支持不正者移除，再按支持排序。
软目标20条，不强制凑数或增长；全部运行时规则、示例合计8192 token上限。

同时保留两个定义性部分：从实际成功/失败经验批判并编辑规则，以及检索真实成功组件示例。
只用本方法自己的真实before/after和原TRAIN Gold，不复用对方技能/轨迹。
当同一来源/命题确有成功和失败记录时提供实际配对ID；没有配对时不伪造。
所有失败仍供教师查看，不用成功筛选删除负反馈。
每批一次累计label-augmented critic，共4教师；原方法的多次轨迹批判合并成一次明确批处理，
不是宣称canonical reward-only/多次反射学习复现。相同任务的原Gold对所有方法同样可用。

成功记忆只含真实联合完全正确的公开回答组件；同源组件无损归并，逐组件保留raw provenance，
不把多个局部成功拼成“实际有一次整份17题全对”。按过去来源拟合的TF-IDF替代作者MPNet，
不下载新模型或依赖新API；最多3个来源示例，单例4096 token，规则+示例8192，整例超长按预定规则跳过，
不截断、填空或合成示例。排除当前来源，无当前Gold参与检索。编号为短rule1等，不要求重复长哈希。
历史示例中的used_skill_ids属于历史库，不假改为当前规则身份；律师只报告当前合法ID。
结构化操作Schema表达操作类型/父编号/原文的对应关系，保留原计数规则，不启用作者错误修补。

## 来源、预算与时间边界

沿用四批训练 `[490,334],[88,331],[238,245],[262,588]`；每组各自从空库开始，
每批先对两案回答，再教师更新，再两案重答。新增数据不能在本批第二次首遇前通过示例目录泄漏：
before阶段目录只由前批完成记录构建；after阶段目录仅增本批已完成before；本批after全完成才留入下批。
禁止同源示例回显，所以同案拟合也不直接拿该案自己的正确回答作答案。
只在B4对B1两案做保留检测，不给教师、不作准入/择库。

后续来源固定 `[325,206,204,375,388,322,163,104]`，与本轮教师训练分离，
三条件ACE-legal、ExpeL-derived-legal、ACE-empty，全部24个终点回答完成才打开对应Gold及父后续结果。
官方DEV/TEST及24保护来源不打开；这些八案仍是有历史开发暴露可能的开发来源，不冒称盲测。

原冻结8B服务/PID不变，seed45、T0.6、top_p0.95、top_k20、max8192/context32768。
既有gpt-5.6-sol/high，0重试、0工具、0缓存命中。相同8个独立训练来源、原监督和律师模型；
教师调用/累计内容重读次数按算法不同，**不声称等教师token或相同信息使用方式**，完整报真实成本。
ACE12教师、ExpeL4教师，共16；逻辑律师60次，ExpeL空库B1两答只在实际消息和生成参数完全一致时
共享已保存的强直接空库回答，因此 **58次新增物理律师＋2次明确共享**，不把共享算新生成。
若不相同则停止，不悄悄再生成或换弱空库。ExpeL空记忆接口与共同强直接空库相同。

背景worker等待当前确切PID终止，再取得同一GPU互斥锁。要求其六条件主阶段完整：B4后4答、
保留4答、后续48答及main_completion齐全；只验存在/哈希，不读取成绩。
若其独立probe失败但主阶段已完整，仍按本预定协议执行，不替换任何算法或答案。
若主阶段未完整或共同8B改变，则保留失败并停止，不假定成功或因观察超时重启。

## 分析

分类、原Gold非中性依据二元成员P/R/micro-F1、联合完全正确、无效/截断、逐来源变化、
训练首遇/同案拟合和B1保留分别报告。所有真实不利与无效回答在原分母，不做答案修复。
全部新输出以独立评分复核实际raw ID/内容；父六条件只使用已经存下的实际回答，不重复冒充新调用。
主机制比较：grounded相对强直接/同接口空库、静态、source-only、ACE、ExpeL；以及各学习器相对其自身空接口。
单次8个来源/每法一个学习工件，报告来源配对的10000次bootstrap百分位95%区间（seed20261015），
重采样来源而非136个命题；F1/P/R都重新合计TP/FP/FN，不平均比例。
这些是条件于现有学习工件的探索性、非同时校正区间，不宣称算法稳定或显著优于全部基线。
正式推断/多重比较/独立学习重复与未调优官方测试，必须在后续协议另行冻结，不能拿本轮补造。
本项不通过成绩决定技能发布、增删、回滚或兜底；所有方法均使用末次库。

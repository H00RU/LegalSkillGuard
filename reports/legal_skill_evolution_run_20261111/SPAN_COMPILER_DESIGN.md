# 学习可复用的源编译技能

具体问题：角色在法律文本中的出现，不等于该角色得到某动作的许可。原读器把信息主体、定义、禁止联系和禁止复制混入披露许可；完整原文可见仍不能由全局角色列表解决。现有小试提供了结构化方向的真实信号，但没有通过历史保持。

本原型学习**源文本到法律关系记录的编译技能**，将源识别本身变成可执行、可更新和复用的对象。教师获取带逐字源依据的局部示例、主体/对象/条件的对齐、词汇类型及法律后果程序；host归纳带捕获槽的源转换规则。推理程序仅接收实际匹配出的局部记录，既不能看到完整源全文，也不能把全局答案当读字段。新合同直接执行所学转换规则，不再逐合同请求模型先完成整个法律判断。

## 状态与更新算法

状态为`(lexicons, aligned_examples, grammar, consequence_program, versions, evidence)`。

1. 从相同七份原TRAIN的原文、原生标签/证据和已有实际错误独立获取示例；source与slot必须匹配真实文本，适配仅忽略空白变化，词、大小写和标点保持。
2. 将每个示例编译为局部文字上下文加具名源捕获；角色词典只作用于捕获内部。无识别值保留未知，不能变成False、空集或法律上的缺席。
3. 对相同关系、常量和槽类型的示例做有限anti-unification，保留学出的极性/作用域词以及未显式参数化的数字；生成可以覆盖新表述的上下文规则。该步骤产生新的转换规则，不只是从已有字段中选一个。
4. 逐候选在固定TRAIN母来源上执行整个法律程序，检查原生分数；在不使任何当前来源退化时接纳更紧凑的规则。原始示例、合并提议、完整前后分数和拒绝理由持久化。候选只能合并初始规则，数量有限，不做无界泛化搜索。
5. 冻结编译技能，执行评分前固定的两份剩余原TRAIN合同。最终技能更新仍需三触发合同均值严格改善、四历史合同逐项保持。复用正确率和成本与模型读取分开报告。

推理程序、规则语义、词典和例外关系由教师获得，host只提供文本匹配、词法类型识别、通用执行、归纳与原生反馈。源引用存在本身不能证明新关系真实，实际匹配/推理还需对应源语义审查。

## 研究定位

[NQG](https://aclanthology.org/2021.acl-long.75/)已有语法归纳与神经模型结合；[PATOIS](https://arxiv.org/abs/1906.10816)已有可复用代码idiom学习。anti-unification、MDL和程序表达能力不作为新颖性依据。[法律元数据代码生成](https://link.springer.com/article/10.1007/s00766-026-00468-7)已有结构/语义关系和分解式ICL，[法律证明携带推理](https://www.mdpi.com/2504-2289/10/9/295)已有源链接规则与优先级图。这里的具体候选作用是：在仅有原生任务监督、教师源对齐并不保证正确的条件下，学习并更新可执行的源编译技能，将跨合同的源绑定与规则应用积累到外部库，在同信息强对照下验证可靠性/成本。它与旧固定字段选择不同，也不恢复已淘汰的确定片段投影或词项重组。

若形成优势，第一项贡献必须由真实源获取、原生准入、跨源执行和消融支持；第二项围绕独立瓶颈另行建立。当前是有实现的候选，不预写贡献已成立。实现难度不作为否定理由，有限真实比较负责决定下一步。

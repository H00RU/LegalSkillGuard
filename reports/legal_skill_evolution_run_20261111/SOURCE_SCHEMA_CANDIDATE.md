# 源语义接口学习：有限候选，不是已成立贡献

保留Astra原方案、所有实现与否定证据。固定五库、原划分、模型和评分。本次只检验首项候选，不宣布两个新创新，也不启动完整研究。

## 问题与已有证据

原合同程序在完整原文可见时仍把三份新合同的六个目标判断全部判错。原四合同的真实字段读取又产生4对兼容的部分记录：问题相同、共同已知值相同、原生TRAIN标签不同；未知不是False、空集或独立类别。只使用当前已知输入且不观察缺失状态的确定性程序，成功执行对补全不变，因此不能同时正确回答一对兼容记录。共同补全只是逻辑证据，不是可写回的字段值。模型已知值也可能错，故不能把冲突等同于真语义不可分。

## 学习对象和更新

学习对象为源编码器与规则程序的版本：字段及局部法律含义、有限概念词汇、源读取问题和原生判断程序。更新输入是原文、原生TRAIN反馈、实际旧读和冲突证书；教师独立提出新读器/谓词与程序，编译检查后从完整当前合同重新获取字段，在固定触发集上检验改善、历史集上检验非回归；接纳状态、候选状态与未知/回退分开保存。未知只可短路避开，不能补造。

实现：[源接口与部分记录冲突](../../legal_skill_guard/skill_evolution/source_schema.py)、[有限真实比较入口](../../experiments/legal_skill_evolution_schema_induction.py)、[相关回归](../../tests/test_skill_evolution_source_schema.py)。这是实现后的研究假设，非新增语义正确性保证。

## 差异与最近邻

- 旧B只在已有抽取字段中选择接口；本候选必须实际改变源问题或取得新谓词，不能重标固定字段选择。旧M1/M2的消歧/误读通道反证继续有效。
- [SYNGAR](https://arxiv.org/abs/1710.07740)已有抽象与反例引导合成，通用CEGAR不是本工作的创新。这里的输入读器会错且不完备；证书只排除当前观测上的程序修补，修读器和扩展语义仍需源证据。
- [Binder](https://arxiv.org/abs/2210.02875)已有程序内神经接口；“语义抽取加程序”和选择模型调用位置不算新贡献。
- [Legal2LogicICL](https://arxiv.org/abs/2604.11699)与[CLARE](https://aclanthology.org/2026.nllp-1.27/)覆盖法律形式化、示例检索及可复用法律DSL；法律包装或固定字段结构本身不足以形成差异。
- [KDASO](https://arxiv.org/abs/2611.06972)涉及执行对齐的技能优化与路由；教师修技能本身不新。

待证的实质是：不把未知误当负例，以部分冲突约束源信息获取位置，能否获得比同信息自由获取更可靠或更省成本的复用技能。当前不能声称成立，也不能声称上述工作不具备该能力；真实强对照决定是否继续。

## 固定比较和后续决定

两臂都看到同样的7个原TRAIN母合同、原生监督、旧读和全部冲突证书；分别独立获取，保持相同教师、执行器和一次提议。候选限制源值进入程序前必须语义化；自由强对照可学完全相同的对象，也可选原文程序或联合文本技能。后者是独立学出的强对照，不是NoSkill回退。

7个校准来源由4个历史保持项和3个已固定触发项组成。额外2个原TRAIN母合同按既有公开文件顺序先固定，教师不接触它们；候选与接纳状态在读取其标签/执行前冻结。仍属有限TRAIN诊断，不能称新盲测。每臂每源最多一次字段生成或联合策略执行，全部获取与执行成本计入；原历史获取费用不抹去。

先核对两次真实提议的字段/程序是否将最终判断藏入读取问题，再执行固定比较。逐项审查真实字段与源依据，核心与回退分开；原生标签偶合不算字段学习正确。若类型成立但语义错误，定位具体读器/程序原因，不无限改同题追正例。若强对照吸收收益，本候选不计贡献；若有优势，再按同一Goal要求推进独立消融和有限复用验证。没有结果之前不扩大完整训练，也不声称Goal完成。

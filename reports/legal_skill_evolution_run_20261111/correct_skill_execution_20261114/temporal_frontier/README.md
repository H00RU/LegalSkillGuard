## 本轮具体学习对象与更新

学习对象是版本化`观察schema＋观察问题＋事实到法律输入的纯转换程序`。教师获得不变的法源核、两个开发母例及真实付费字段错误；更新事实观察形式与转换，法律程序不在这项学习中改写。例如原事实“have been married since Feb 3rd, 2017”，8B原读取将开始与结束都填为2017-02-03。ProgramGuided学到`ongoing_since`，由程序构造开放的案件状态视图，不让8B猜结束日。

更新采用一次同信息独立获取：ProgramGuided与FreeHistory具有相同源文、原生TRAIN反馈、正确性修复、代码/观察容量、上下文选择和程序相关读取能力。Free允许同样事件表示、程序投影、旧正确修复及查询规划。二者都实际返回四份契约并用于8B事实读取及同核执行。没有参数训练、换模型或扫描thinking。

当前host可以先运行纯事实编译，必要时才读取；所有相容参数视图都执行同一核，相关未覆盖未知或结论不一致仍未解决。新增有限绑定读取规划器提供最坏声明成本最小的读取树，6项相关单元检查通过；**两位教师此次都返回0个refinement，真实主路径未使用该规划器**。声明成本不是实际费用。不能把它的离线存在记成第二贡献核心成功。

## 实现缺陷与模型错误分开

**共享接口增加了额外条件。** 源核教师将itemization要求解释为必须另有实际选择声明。只读[SARA官方原始资源](https://nlp.jhu.edu/law/sara_v2/)的法条Prolog（不读取任何case或TEST成员）后，发现原生§63(c)(6)(A)以给定deduction事件为条件。公共端口说明据此改正；P字节保持，所有臂共享。这个修复在两臂契约获取和正式四母执行之前给到，不算学习收益。[原定义、修改依据和记录](legal_skill_evolution_grounding_frontier_20261114/native_semantics_audit/interface_change.json)。

**共享核对分居额外加了持续区间条件。** 官方§7703(a)(2)实现的当前路径检查法令时间在查询年度终结之前，并不要求额外ongoing/end谓词。旧核使正确`effective_only`观察无法执行。四母真实调用结束后，在保持原输出和转换不变的条件下，对三臂公共修复并零调用重放：ProgramGuided **2→3/4**，Free **1→1/4**，Direct **3→3/4**。它纠正的是公共核的过度条件，不计方法增益，不改写原冻结成绩。[原核、修复核和逐项重放](legal_skill_evolution_temporal_contract_learning_20261114/unbound_native_separation_fix/replay.json)。这也说明仅看“未解决”不能全归为模型能力不足。

**仍有真实观察错误。** 8175中ProgramGuided已正确读到持续婚姻，但对法令通道返回null；Free和Direct还将明确since弱化为仅有起始日期。Free在a519没有消费明确§152(c)(1)给定；在a308生成了有效时间值，却把三条通道全标unknown，转换器因此正确保留未读取状态。没有把这些unknown强行变为[]，没有删除全局未覆盖检查制造通过。

ProgramGuided此前学得的持续状态转换这时确实支撑了执行；另两者的`onset_only`/`open_ended=false`仍不足。没有手动清除unresolved，已学转换自己在重新输入后重建状态。该项是**单个共享观察的控制干预**，不是三次独立读取，也不是让另外两种完整方法自由规划后续读取的比较，不能用它把四母主表改成4/4或认定独立优势。[原始问题/响应、三臂前后观察及实际执行](legal_skill_evolution_missing_event_read_20261114/result.json)。

这给出了明确的后续机制问题：将学习从“一次输出全套字段和自评unknown”推进到**根据不变程序的残余，选择足以决定结果的源文事实观察**。强简单控制必须包括同资源的按端口补读/联合补读，且应自由选择其缺口，不能只给它们我们的一个固定问题。先补这条路径及一项独立消融，不再扩大完整训练或反复重跑已关闭四母。

## 与近邻的具体边界

[Holzenberger与Van Durme，NLLP2023](https://aclanthology.org/2023.nllp-1.12/)已用案件事件/参数抽取连接正确的法条程序，并明确指出start/end接口难表达进行状态；其[作者代码](https://github.com/SgfdDttt/sara-ie)将抽取KB送入Prolog。故“提取事实＋执行正确规则”及“改用事件表示”本身不新。当前要检验的是从真实绑定反馈学习源文观察到固定规则端口的转换，并使程序相关的残余读取在同信息强对照下产生独立作用；尚未证明。

[Know Your Limits](https://arxiv.org/abs/2606.16118)进一步区分基准准确与形式忠实，本项目沿用原native评分，不据其严格FOL标签重标当前合同。[SkillSentry](https://arxiv.org/abs/2608.09253)已有轨迹学习的执行指导；一般监督检查清单不作为新贡献。

C的四条既有消费者差异也已核清：固定程序的覆盖/解释不是弱律师事实读取。a5b原规范存在但接收者标签未分类，de42/8fb是相同法律项的不同保持解释，不把它们强行当作第二机制的四条错误机会。[已有精确根及变化](../real_observation_pilot/C_existing_consumer_frontier.json)。

## 当前问题与候选机制

C负责从法律材料取得正确、可复用的规则；第二方向关注规则取得后，如何将案件事实、主体、时间和例外准确绑定到技能调用并执行。候选学习对象是**技能条件下的案件绑定与执行规程**：从真实执行错误学习联合事实绑定、缺失证据核查及必要调用约束，保护已验证正确的法律规则。现已实现一次案件观察契约学习并完成三母真实小试，结果及算法见下方；强对照吸收当前具体实现，尚非独立贡献。

历史原32源诊断已有具体症状：技能规定金额不超过资产价值，实际仍有18元袜子填600；上下文变化减少漏项却增加错误金额。这些旧记录支持问题存在，但不是当前五库新增结果。旧执行示范、程序数值技能、算术执行器、位置/编码及源绑定试验均须复用，不重跑已成立的等价检查或明确反证，也不恢复旧thinking、预算和停止规则。

## 直接近邻已经核查

- [SkillSentry](https://arxiv.org/html/2608.09253v1)从技能规范与成功/失败轨迹形成DSL，按步骤监控执行，并更新运行指导。因此“从轨迹学执行约束”本身不够新。
- [SkillAligner](https://arxiv.org/abs/2608.06880)在执行前联合适配技能、接口及依赖。需要区别已验证正确规则的案件绑定与一般技能草稿改写。
- [Faithful CoT](https://arxiv.org/abs/2301.13379)、[SatLM](https://arxiv.org/abs/2305.09656)、[BINDER](https://github.com/xlang-ai/Binder)已有符号/程序执行与神经调用。外部程序执行属于可复用底座，不单列为第二创新。

当前要探索的具体增量是：围绕法律任务中的主体所属、时间、事实值与例外条件，学习如何在新案件中可靠实例化正确技能；在同一正确技能、事实和资源下，比直接事实抽取、普通程序/声明式执行、同预算反馈修复获得可解释的额外作用。尚未证明无人做过或已有优势。

## 学习对象、算法与真实使用

外部学习对象是每个固定法律核的案件观察契约：`observation_schema + observation_prompt + binding_program`。教师从正确法源/程序、实际错误和合法TRAIN反馈取得事实表示及纯事实投影；不修改法律条件、阈值、答案策略或模型权重。当前只完成一次取得，不声称已验证持续多轮进化。

运行时先用当前案件的正向字面事实与角色调用适配程序；可直接构造相容参数时不调用8B，否则8B只读事实观察，不判法律结论。适配器返回带当前facts/question原文见证的参数备选及未覆盖未知。共享host对**每个**备选执行同一法律程序；有相关未知、未覆盖或结论分歧则不输出选中的有利答案。程序结果一致可保留不影响结论的歧义。本轮真实使用了子女两种视图的一致执行；输出分歧驱动的后续事实澄清没有触发，尚非真实覆盖证据。

两个教师独立生成三份契约。FreeHistory获得相同原文、正确核、历史、反馈、运行接口和全部观察/程序容量，也允许关系抽取、缓存修复、程序行为分析和歧义处理；没有限制其使用我们的能力。DirectRead为普通“固定正确程序＋事实参数抽取”低成本控制，同样得到错误反馈。普通静态亲属反向投影也足以恢复首母，因此本次学习不能解释为发现新的亲属推理算法。

## 数据、冻结与公共修复

三母全部属于原128 TRAIN，历史上已经暴露，不是新盲测。只有3e226母的案件错误提供两位教师获取反馈；d9d6与5c29只提供各自法源和正确核定义，案件事实和原生标签在契约冻结后进入运行/评分。由后两核的定义学会各自事实接口，不等于从首母错误迁移取得新法律规则。同母视图不增来源。评分仅在所有真实输出不可变保存后打开原TRAIN标注；无DEV/TEST调用。

共同核最初获取发现了具体问题：验证器未开放worker已存在的日历原语；`type(value)`检查未接通；原程序错误地把相邻两年工资合计后比较20k；过度要求案件显式声明事件全集/完整全年居住，超出SARA原生有限案件语义。先离线定位，再一次源/接口修复。修复后逐年分别累计；未知提取不会被当作负事实，原坏程序、反例及成功回归均保存。这些是共享正确性工程，不计新方法收益。坏核未发送给8B，公共核及修复成本对所有臂开放并单列计入。

## 当前研究决定

本轮足以确认：正确技能交给8B之后仍可因事实参数方向而失败；把源关系作为观察并由程序投影可以真实修复。它不支持独立第二贡献：ProgramGuided与FreeHistory均3/3，普通关系投影也吸收首母修复；工资和时间两母没有产生新增相对收益。不会继续反复重跑这三母或宣称简单编译适配器就是创新。

继续围绕同一执行瓶颈研究：将本轮可用观察/适配底座复用到C当前真实源程序的案件/查询绑定，先从保留的同库不同消费者记录中隔离“法律项正确但实例化错误”，而非把遗漏法源再误算成执行问题。需要证明的是由真实绑定反馈学得的规程在后续原TRAIN及C联合路径产生同信息强对照不能吸收的作用；未证明前不扩大为完整训练。当前没有该联合收益、独立组件消融或分歧澄清的实证，不把它们冒记为成功。已零调用索引出既有同库消费者的4条变化（de42/nda-20、a5b/nda-5及7、8fb/nda-20）；a5b原消费者未覆盖，另两条涉及自定义处置规范/保持语义，尚不能当成已核验的正确技能事实绑定错误。[既有消费者差异与精确根](C_existing_consumer_frontier.json)。

直接近邻：[SkillSentry](https://arxiv.org/html/2608.09253v1)已覆盖从技能和轨迹学习步骤化运行指导；其[论文链接的官方匿名代码](https://anonymous.4open.science/r/skillsentry-865C)本次API访问403，未冒称复现。[SkillAligner](https://arxiv.org/abs/2608.06880)研究执行前技能联合适配；[Faithful CoT](https://arxiv.org/abs/2301.13379)、[SatLM](https://arxiv.org/abs/2305.09656)与[BINDER作者代码](https://github.com/xlang-ai/Binder)已有程序/符号执行和神经接口。故不以“执行监督”“编译”“schema”这些泛称宣布差异；候选增量须落到法律程序条件下的观察学习及实际控制使用，并由强比较支持。

Add their already-available nominal program operators, then consume the actual repair as subsequent feedback. The before/after collision is resolved offline; neither the paired result nor its source cohort is rerun or relabeled as independent validation.

The model reuses exact finite DNF/set-cover with positive witnessed predicates. Node/source IDs, raw source values and native answers are not features. Current nominal program operators are input structure. Missing graph edges are not legal counterevidence. Predictions still need current source support and actual execution; a co-change pattern is not proof of causal necessity. Source-valid old values can lose protection when explicit new counterevidence requires a recheck.

Graphs and source-validity judgments are offline annotations of preserved actual TRAIN evidence, available to all strong controls. Their annotation origin is disclosed; they are not claimed as free model acquisition or independently generated source graphs. Initial code/model versions, including the variant that could use absence of a path, remain preserved. Latest V3 has not been consumed by a new real editor.

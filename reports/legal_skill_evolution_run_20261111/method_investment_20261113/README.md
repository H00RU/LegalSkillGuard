# 两项贡献的投入决定

2026-11-13。同一Goal，研究问题、数据、模型和累计账本不变。按用户最新要求，先基于论文及作者代码选定理论上有力度的两项贡献，再连续实现与验证；不再用一次临时提示、三题成绩决定换方向。本页是主要执行者的选择，后面三份文档是算法、代码阅读及任务反证依据，不是多个待选方向。

## 固定的问题与两项贡献

**问题：怎样从法律原文和实际错误中持续学到可复用规则，并使修订经验真正改善下一份法律材料的获取，而不是反复生成一份当前题程序。** 原文中的主体归属、动作、跨条限定和例外可能分散；错误程序可能碰巧答对，修好新材料又可能损害旧材料。当前原TRAIN中均有真实记录，不需要换任务或构造新来源。

### 一、区分表示缺口与组合缺口，驱动开放规则学习

学习的是两层状态：可执行的源语义概念库φ，以及将这些观察组合成当前法源规则的共享程序G。不是只学一个问题的答案，也不是每份合同各写一组正则。

核心操作：先检查“给任何足够自由的组合，现有观察能不能满足已知TRAIN约束”。若完全相同的可见观察要求不相容的结果，得到表示不足证据，教师需要学出能实际读到新法律区别的概念；若观察足够而当前规则语言不能表达正确组合，则改组合，不继续索取无必要的精确字段。随后用成熟LAS/约束归纳共同约束历史上下文，学G。新合同的规则留在其自身来源中，不把一份合同的权限变成通用法律。

例如，同样出现employees，许可对象可能是接收方员工，也可能只是关联方定义中的员工。若现表示丢掉所属/法律功能，换推理链无法恢复；若所属已读对，就应修连接规则，而不是再改读取器。

**为什么值得做。** 当前缺少的不是再拆几个谓词，而是有依据地决定学习哪一层，并使所学区别进入后续生产规则。理论上可以给出现表示下的经验误差下界/不可满足证书，以及保留旧观察后可达误差不增的结论；它们不假装证明法律语义或留出收益。

最近邻各有相关能力：[SkillWrapper](https://arxiv.org/abs/2511.18203)已做不可分状态触发谓词发明；[LLM2LAS](https://arxiv.org/abs/2509.16590)已做文本结构到逻辑规则学习；[SCOPE](https://arxiv.org/abs/2610.31062)已做谓词、提取与组合的联合修订。这里采用成熟核心，研究源条件化、部分法律监督下的可计算诊断与开放概念/规则联合学习，不宣称首次谓词发明、首次LAS或首次教师编译。

[完整算法、有限命题、作者源码与内部消融](acquisition_design.md)。

### 二、把法源与代码修改共同学成可调用的更新程序

学习对象是更新算子U，不是补丁文本或错误摘要。由真实“当前法源见证、旧程序、新程序”归纳共同参数：源中的主体、例外、法律数值，与代码中要修改的位置共用同一替换。到新来源时，U用当前来源的对象和值实例化编辑；再由明确的适用/不适用证据学边界，避免将旧合同参数或错误适用范围移植过去。

例如，一次修订确认某个保留例外只限定返还义务。下次复用不能仅找到相似代码就把例外挂到所有义务上；应同时匹配当前法源的“例外→效果”关系与代码目标，并把当前例外绑定到对应效果。

**为什么值得做。** 这把“教师每次重新修程序”变为“系统逐步学会如何修”，可减少跨源误改、旧能力损失及重复获取。U同时可修改φ和G，是学习到的编辑构造及条件先验；仅给同一个完整LAS搜索热启动、最终仍得同一解，不算第二项精度作用。

[Refazer](https://www.microsoft.com/en-us/research/publication/learning-syntactic-program-transformations-from-examples/)和Getafix已会从代码编辑学变换；[EviSkill](https://arxiv.org/abs/2610.05030)已会保留/重放编辑证据；SCOPE已会定位本次修订。本项采用PBE等成熟算法，新增要落实的是**法源关系与代码编辑的联合绑定、可学习适用边界及跨来源直接实例化**。若通用PBE加入相同联合输入后与U等价，应明确采用它，不能造一个等价算法当弱对照。

[完整更新算法、旧CoRev差异、理论及真正删除消融](update_design.md)。

## 为什么两项不重合

第一项学“需要什么法律概念、怎样形成源规则”；第二项学“以前怎样改程序，可以怎样作用于当前来源”。U关闭时第一项仍能学习，由教师普通修订；第一项关闭时U仍可作用于公共/自由获取程序。实现中分别有实际开关，不能只换system提示。

|系统|规则获取|更新经验|
|---|---|---|
|完整ours|第一项|第二项U|
|−第一项|同信息开放自由获取/固定池优化|保留U|
|−第二项|保留第一项|完整历史检索＋普通自由修订|
|强基础|开放自由获取|完整历史检索＋普通自由修订|

相关方法比较以真实实现/明确适配为准，FreeReflect不能改名充当SCOPE、LSP或EviSkill。SCOPE原方法生成额外训练案情，本项目不新增这些数据；采用固定池优化器时明确标注该适配，并保留完整谓词/组合修改能力。仅赢固定facts或不会修订的弱臂不足以支持主张。

## 任务与实施决定

主场先放在原ContractNLI和MAUD的规则组合/作用域，SARA、OpenExempt、Airline保留原生任务作为数值、引用、保持与边界检验；五库和来源不变，不要求两项五库全胜。具体原文依据、已被控制吸收的部分和多视图边界见[任务适配复核](task_fit.md)。这是适用需求的证据，不冒充已证明新方法能涨分。

**本轮选择投入这两项，不再扩候选列表。** 先做完整的第一项，再接入U；正常实现故障和个别模型错误在该设计内修复。只有发现实质等价的先行方法、任务确无所需机会，或完成固定的实际比较仍无额外作用，才集中作下一次研究决定，不按每三题成绩换方向。不要求实现前保证提升。

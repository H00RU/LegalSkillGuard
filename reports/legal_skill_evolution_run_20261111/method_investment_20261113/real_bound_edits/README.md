The fixed original TRAIN study uses two actual repair mothers plus one supported old-capability case, with another five already exposed original TRAIN mothers executed after policy freezing. No new source or model request is introduced. All results and prior failures remain preserved.

203 automatically proposed current-source/program bindings yield two retirement policies. Native correctness stays25/32, five explicitly reviewed wrong Norms and five answer paths using them disappear. Both ordinary exact-clause overwrite controls match25/32 and zero reviewed wrong Norms. Learned policies fire on none of the five subsequent mothers. This prototype is retained as maintenance infrastructure, not an independent U contribution.

The first prototype used a nonadditive footprint-union secondary cost with a DP state that did not justify that secondary optimum. Its source is preserved in `source_snapshot/fit_implementation_original`; the corrected additive cost is exhaustively checked on software fixtures.

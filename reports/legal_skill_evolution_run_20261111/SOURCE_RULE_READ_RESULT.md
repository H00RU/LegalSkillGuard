# 源规则读取修复与CoRev实现缺口

Goal保持active、未完成。本轮用既有四个TRAIN合同和同一份真实教师提议，修复公共读取路径并完成一次固定版本表验证；没有教师调用、扩源、完整训练或DEV/TEST。两项贡献仍未得到独立实证。

## 实际修复与真实验证

规则前提读取现在排除独立提供的原生假设、view ID及`current_question`参数，保留完整源文和其他显式参数；案情读取仍保留问题及明确给定的法律中间事实。四个固定合同已离线证明：同一读取定义在nda-5/7两种问题下的实际请求组成完全相同，因此不会因问卷改变法源参数，也可精确复用同一次响应。

已使用原输入自带的公开句子边界，逐字保存源文片段和偏移，非空间隙保留；没有使用原生证据标签。旧模型可把整份合同作为一个引用的路径已改为较细片段。先前模型混淆本地证据ID和原生句子编号；现只向模型展示一套本地ID，原生编号留在主机证据中。原失败的support ID 149超过146上限，随后只对这一读取请求验证一次，类型及引用范围通过，读得一般披露禁令True；该结果不覆盖原版本表。

91项相关回归通过。模型仍Qwen3-8B、thinking OFF，采样和8192输出上限未变。全部臂共享公共读取修复，不将它计作Lift/CoRev的独立贡献。

## 同一真实联合提议的结果

沿用Free在354合同上的两项原修订，冻结原文、批初库、三个当前/历史母来源和原准入。完整4格结果：

| 修订状态 | 当前354 | 历史8af | 历史d50 |
|---|---:|---:|---:|
| 全旧 | .50 | 1.00 | .75 |
| 仅生产者新 | .50 | .75 | .50 |
| 仅消费者新 | .50 | .75 | .75 |
| 两者新 | .75 | .75 | .50 |

当前合同的nda-5/7都由真实程序答对，核心原生正确视图从0到2；但联合修订损害历史来源，按原规则拒绝，模式仍0。不能把当前来源局部必须联动改称为完整CoRev通过。历史8af还受到上述引用范围失败的影响；最后的一条ID修复没有重跑整表，不能把其历史分数改写为预期值。冻结复用仍.25。

中间表示仍有实际语义错误：354的“接收人/场景”数组混入了材料种类、服务活动、委员会成员等内容；d50将整句“directors, officers and employees ...”作为一个字符串，而程序要求可直接匹配的类别。原生答对不证明这些中间值正确。当前结果支持读取边界修复有作用，不支持方法已成熟。

## 完整编辑及有界职责匹配已实现，真实模式证据仍缺

上一阶段核对原方案METHOD_EVOLUTION第4.6节与实际代码，定位到P-only移植和法律职责上下文两个缺口。本次已实现前者：模式保存实际前后Skill及其READ/前提编辑，生成候选时同时重建程序、读取器、前提类型、字段绑定、局部记录与来源证据，依赖技能ID按目标图重绑定。Full和Generic共用同一个编译路径，原生/历史接受判据保持。

新增或改值的常量前提不会从训练见证复制到目标；不变常量保留目标实际值及证据，其他值通过显式当前源READ获取。新程序字面量仅在已声明端口访问和显式current_question字符串匹配位置支持；未绑定的新数值等法源常量仍拒绝。缺失READ字段、类型或绑定、目标接口/旧作用域不匹配均不猜造。局部变量做防捕获重命名，min/max等操作及inputs/premises命名空间不能被当作可互换变量。

真实被拒Free联合提议的两个技能现均能完整重建，程序AST与READ/前提绑定等同于原响应；在7组去重的实际已观测输入/前提上，隔离执行输出逐项相同。101项回归通过。模式保存到候选生成及不同技能ID重绑定的正向检查只使用单独标明的合成评分fixture，不是研究得分；真实拒绝包仍被拒绝，研究模式仍0。[完整编辑与真实执行回归](source_rule_full_edit_regression.json)。

修复前的上下文只有preliminary/terminal声明、输出类型和USE，不能区分消费者对False由Contradiction改为NotMentioned。[修复前审计](source_rule_CoRev_implementation_audit.json)保留。现已接入有界职责差分：从真实USE/APPLY定位消费者，在其他输入及旧前提固定时分别置上游Boolean为True/False，保存可执行输出、缺失绑定、实际端口访问位置和技能hash；同时记录生产者实际使用的判断输入及其增删。缺失字段保持unknown，短路能确定的代码结果可以记录，但不补齐未读字段，也不把程序输出当独立法律标签。

源关系仅接纳当前材料中可唯一逐字定位的明确例外引用，保存两段引文、段落范围和引用偏移；不将源ID、数据集标签或声明角色作为匹配特征。目前种子引用在4个既有合同中只绑定1个，其他3个unknown；这只是该引用的绑定覆盖，不是法律关系总体覆盖。完整消费者代码效应与源关系均作为证据保留，Full按已核实字段匹配；Generic拥有相同信息和完整编辑能力，仍可尝试已知解释不同的整个编辑，不因法律先验被削弱。

本次离线核对4条实际调用上下文，区分同一联合修订在nda-5中False→NotMentioned与nda-7中False→Contradiction，且真实拒绝表在Full和Generic均产生0模式。正向学习、候选及不同技能ID移植仍仅由隔离合成评分fixture检验；回退分数不能触发模式学习。READ成本按物理来源去重，缺失失败消耗标为不完整而非免费。106项相关回归通过，新增0E/0T。[实际代码、源绑定、成本及拒绝回归](source_rule_responsibility_regression.json)。

当前结论保持：Lift这个实际更新只需一个字段，强对照吸收；CoRev有局部联合原生改善，但未通过历史保留，也未在另一母来源使用学成模式。完整编辑和职责匹配是必要实现补齐，尚无真实效果证据。下一步先解决已有读取中“接收人类别、许可场景与附带条件”混在一个字符串数组的问题，核对源规则表示能否支持原法律计算；仅在明确修正与离线反证后做有限原TRAIN验证，不重复同一错误表示，不扩大为完整重训或用已知答案编规则。

## 两项方法为何尚未得到证实

**Lift**要求从旧来源固定前提形成实际成组提升提议，反馈选中后在另一母来源重新读取并绑定。Full目前的法律条件已声明成当前读取的inputs，固定源前提为0；专门lift修订为0。当前源读取、参数化和普通技能新建均不能倒算为Lift。

**CoRev**要求已有法律技能的完整混合版本表支持修订模式，模式再改变另一母来源的候选生成或排序。当前学得模式为0；原始新建依赖包和格式渲染链不计。版本表出现joint_needed也不能单凭该字符串判为CoRev成功。

固定上下文只覆盖14/20母来源。最差3个当前来源＋最早5个历史来源的选择使一些高基线MAUD来源从未提供给教师。OE三个来源都在B1，之后没有批初新OE来源；不能把20来源逐一初答称作20来源都发生了技能学习。保持原队列，未为制造机制事件补案例、错技能、标签或新种子。

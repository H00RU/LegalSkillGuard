**结论：**C高于本轮普通教师的新版程序，但低于已有直接回答基线；G拟合在开发多对1题、复用少对1题；新源概念程序在这一对冻结来源上没有超过旧NN转换器。该版本没有独立贡献证据，也不具备以此扩大完整实验的依据。

## 实质改动与失败定位

学习对象包括纯源概念程序、其生成的有出处语义概念、非Norm片段和G。程序计算与真实神经读取分别记录；全源缺失判断仍必须来自实际神经审读，程序不能用未匹配到规则代替缺失结论。

首次新程序在开发阶段没有找到源有效G。定位表明，七个读取操作的问题、选项及作用域均未改变，新增演示却使原正确的本方员工被读为关联方员工。编译时恢复原有效操作版本，新增四个程序概念保留；同一规则也检查普通教师，其操作存在真实语义变化，未强行回滚。原模型响应和所有费用保留，没有重新生成开发样本。

新程序重写还丢失旧转换器的部分处置/留存能力。现在将原教师学得的相关转换按其实际操作归属保留，新披露程序继续执行；没有输入旧规范、旧答案或手写缺失事实。六开发源的回放使用原实际读取，0新增模型调用，原部分源检查全部通过后才冻结。

残余失败指向**源信息表示和组合泛化**：

- 新程序要求当前单元自带披露谓词，漏掉由上文生效条款支配的后续人员/条件片段。de42的旧读取和旧转换器原本可组合这些证据，新局部门限丢失了这项能力。
- G删除全局`qualified_retention_permission`组合，修正d936的一次开发误报，却损害442c的真实限定留存判断。当前特征没有充分区分条件的作用范围及处置后的时间关系，不能靠继续删旧规则解决。
- 新普通教师源程序在开发上的高分没有泛化，冻结复用1/8；主要依赖局部词形/句式的程序不是可靠强基线替代品。因此保留更强直接回答记录，并继续检验历史有效程序。

这些结果不支持将当前问题归因于8B“背法条少”：同一模型使用题面规则的直接回答为6/8，当前C为4/8。资料未进入表示、源作用域丢失和G过度概括必须分别处理。所有错误与未执行仍留在原分母。

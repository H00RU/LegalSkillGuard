## 已实际实现的学习与执行路径

教师从真实错误联合生成观察关系、共享来源键、字段的逐字复制要求、向原生事实的正向规则，以及关系拆分方案。宿主的拆分操作复制原有规则的语义字面量，把角色、期间、地点等读取单位分开；各单位靠相同来源键连接。全部字段完整读取且键域一致时保持原转导，部分读取只声明实际完成的事件/属性范围。未读日期不变成无日期，未读家族不变成空集。

同一组正向规则反向映射原生程序的未读事实需求，列出可提供它的观察关系；不把查询人名或期望日期填成事实。两候选在真实冻结8B获取执行后选择，再保存版本、进入预先固定复用。普通教师使用同一模型、同等原文/反馈/架构和候选数，独立提出自己的两个契约；它也主动选择了拆分结构。这里的“两位教师”是比较臂，不是双教师协作或新机制。

实际错误还表明，模型会在声明逐字复制的有限枚举中生成原文没有的亲属词。后续公共修正把这些既有复制约束编入生成schema：保留原文出现的候选及合法null/unread，不指定任何人的角色或关系，也不生成缺失事实。实际30条旧关系输出中，3条包含无源亲属词的输出在生成约束下不再可表达；原始输出完整保留。该修正同时用于方法、未拆分及普通教师，不能单算方法贡献。无可支持当前需求的关系不再被当成无关补读队列。

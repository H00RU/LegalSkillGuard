## 第二项：复核消除了原表面优势

前一轮四母两臂共8次真实紧凑观察均完整输出。原生分数曾为ProgramGuided4/4、FreeHistory3/4。复核发现：

- Free在已有真实事实正确时，转换程序给原生执行器额外加了“婚姻开始不足以执行、须先证明持续”的门槛。原生程序本身接受开始事件且无需补结束日期。双方只删除这个额外门槛，保持实际观察、事实、日期及其余检查不变，离线重放为**4/4对4/4**。
- 方法侧死亡案例把问题“Bob在2015适用该条”当成Bob在2015死亡的事实，还重复两次。即使原生答对也不算核心语义成功；原记录没有被删去或借标签修正。
- 学校服务新原语来自新法源，父组件和错误列表为空，不能说它由旧错误学得。其余有真实父组件与错误引用，仍需用后续实际调用证明复用。

因此，旧四母差值不支持第二项独立收益。四次原生图诊断读取中的角色/类型失败与一次8192截断全部保留，不继续按相同高负担接口批量调用。

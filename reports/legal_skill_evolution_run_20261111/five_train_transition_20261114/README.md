## 第二项：错误怎样改变了可复用对象

当前真实学习对象是累计观察组件、纯规划器、事实→原生输入的转换程序。三者围绕不可变作者法条程序更新；组件有实际父版本/错误引用，主读记录实际选中组件、原始JSON、转换事实、引文和执行。记录字段本身不是学习证据。

B1共同lowering错误把正确扣除观察转成`itemize_deductions_`，作者程序要求`deduction_`；方法侧还因耦合观察的returns/itemizations为null而保持未知。B1教师任务漏送实际P正文的问题在B2公平补齐，B1原失败不重跑。B2两臂都拆分部分观察、修转换，均达3/3，普通教师吸收了这部分作用。

B3两臂从真实工资误路由中修正规划：普通付款不再强制请求termination/disability组件，付款观察保留媒介，显式151(d)另行表示，不伪称151(b)/(c)。方法侧后续真实生成仍将问题句子标成facts，严格拒绝；另一个151案保持未解决，不能以正确金额或native极性填事实。第三批原生1/3对2/3尚无独立优势。

部分方法组件声称不存在的父版本；报告`lineage_issues`保留原字段，错误引用不计迁移或从错误学习的证据。历史error ID只从真正旧任务解析。原生评分仍测实际程序行为，schema、类型、引文、源语义和执行检查未放宽；不把元数据纠正成研究成功。

## 与近邻的实质差异：当前能说到哪里

[ACL2021](https://aclanthology.org/2021.acl-long.213/)已借助Prolog结构分解法条语言理解。[NLLP2023 §3—5](https://aclanthology.org/2023.nllp-1.12.pdf)已学习法条相关事件/论元表示并将预测事实送入固定Prolog；还直接报告EMPTY知识库及负例效应。因此，固定核、语言到事实、紧凑表示或“答对但无事实”诊断本身均非我们的新增贡献。

[SymBa §3.2](https://aclanthology.org/2025.naacl-long.124.pdf)已由失败证明目标触发事实/规则检索、翻译及符号校验。我们的转换残余不是另一份SymBa证明完备性，也不能凭“阻断后读一下”建立创新。

需要被完整实验支持的增量是：**真实错误怎样共同修订外部观察表示和转换，哪些修订在后续不同案件/法条实际复用，以及同一学得契约下残余是否进一步改善读取。** 当前普通教师已吸收部分更新；两臂大框架相同，仅提示策略与版本字段尚不足以证明新的学习算法。完整比较继续，须说明实际新增操作和独立作用；两项比较有效也不自动等于创新成立。

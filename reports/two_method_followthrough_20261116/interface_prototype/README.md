# 有限接口合成原型

已实现从固定有限 F(u,c) 自动构建完整语义残差、求最粗的合法局部状态分区 H(u)、并生成 D(H(u),c) 查表消费程序。既保持多问题输出，也保持合法域；不允许非法世界与合法输出 None 混淆。提供任意候选分组的具体不足见证。

这不是对手写两套接口做等价检查：分区和消费表由输入函数自动生成。函数式压缩、等价类与残差本身是已有概念，不主张这些为新算法理论。

运行：在本目录执行 `python -m unittest -v`。

11 项测试覆盖阈值分区、上下文变化、多问题输出、未知状态、非法域、共同合法上下文相容关系非传递、拒绝以全世界为键的答案编码、缺失上下文及不足分组见证。测试是确定性构造，不是五库实验或模型收益。

## 精确边界

- 正确性只针对调用方声明并完整枚举的有限域，不是英文法条正确性证明。F 与 valid_domain 本身须另行审核。
- 编码只接收局部 u，消费程序才接收 c；接口拒绝世界 (u,c) 键。**代码无法阻止调用者把整个世界伪装成一个局部 u**，真实法律适配器仍须审核局部输入边界。
- 如果 F 不区分 unknown 和 no，最粗商会合并它们；需要保持该区别时，必须将相应来源语义纳入输出向量。该约束不能只写在论文中。
- 保持完整合法域是保守约束；不求忽略非法组合时可能更小的图着色编码。
- 尚未实现自然语言读取提示语法、法律任务适配器、模型候选执行和模型损失选择；也没有伪造读取缓存或模型分数。该部分需在实际实施时完成，不能把本原型报作完整第一方法。
- 未加入通道概率/跨规则风险拟合，故与第二项原型边界分明。

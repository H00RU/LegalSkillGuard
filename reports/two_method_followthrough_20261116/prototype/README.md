# Empirical structural-channel offline prototype

Run `python test_channel.py` in this directory. Requires NumPy and SciPy. `results.json` is regenerated. No model, teacher, network, or server calls occur. Old mechanism-check files are unchanged.

This implements a new **sample-input software prototype**, not an empirical model-efficacy experiment. Fixtures are deliberately synthetic finite lists of paired records, not real legal data or supplied population channel probabilities. Eight tests exercise implementation failure boundaries. It does not establish originality.

## Implemented contract

`Pair` stores source ID, complete TRAIN reference graph, observed graph, exact plan version, context, split, and provenance. The finite graph has two typed person roles and two anchored event identities; a Boolean eligibility property belongs to each person, and an exception attaches to an event. Anchors survive edits. The dictionary includes identity, role swap, exception reattachment, and their correlated joint composition. Matching retains every compatible edit and returns unmatched observations explicitly.

`fit_channel` accepts empirical pairs only. For each reference stratum it averages repeated observations within a mother source, then averages sources equally. Replicating the same rows does not shrink uncertainty. Simultaneous two-sided Hoeffding bounds use the count of distinct sources, with a union bound over fixed dictionary-output categories plus OTHER. Independent source clusters, a frozen dictionary and schema chosen on disjoint development sources, and a common context-conditional edit mixture across reference strata are assumptions. Dependence across strata is permitted by the union bound. Sources within a stratum must represent the intended source population; convenience fixtures cannot establish statistical coverage. Shared-mixture infeasibility is rejected. Version, context, split, and development-source overlap are checked. Reference weights describe a specified TRAIN-world distribution and have no claim to estimate a future case distribution.

Unknown edits are a substantive identification limit. Default `unrestricted` mode allows unknown operations to mimic known outputs during calibration; its unknown mass can remain one and its new-rule risk upper bound is one. The alternative `detectable_residual` mode assumes every unknown operation yields an output outside the known edit images on **every calibrated reference**. Only under that explicit restrictive assumption can unmatched frequencies constrain unknown mass. Unknown loss remains [0, 1], never zeroed or renormalized away. Unknown operations that are observationally aliased violate this conditional mode. No real data currently establishes this assumption.

`risk` evaluates a fixed illustrative legal Boolean program on supported TRAIN worlds and edited worlds, then minimizes/maximizes the consequence vector over the empirical channel polytope. It accepts no target case, target reference graph, or target label. By default unsupported reference worlds, program contexts, and plan versions return unsupported. Explicit `allow_stationary_transfer=True` permits unobserved reference worlds within the same typed schema, anchor, and context, conditional on the identical edit mixture and the selected unknown-error assumptions continuing to hold there. This assumption is not established by calibration. The output flags extrapolated worlds; it does not claim observed transfer accuracy.

`robust_select` defaults to `selection_mode="minimax"`: it selects the minimum risk upper bound plus a caller-specified fixed cost, even when intervals overlap, and separately reports `certified_separation`. Overlap does not imply efficacy or a reliably superior plan. Optional `selection_mode="strict"` switches only when that plan's upper bound plus cost is strictly below every competitor's lower bound plus cost; otherwise it reports unsupported and returns the prespecified baseline. Missing comparable support still returns the baseline in either mode. Per-plan confidence levels are summed for a selection-family error bound. Use smaller per-plan alpha to meet a desired family confidence level. Costs must be in the same scale as decision loss.

## Strong baseline and checks

Full paired-trace replay executes the new program on every cached reference/observed pair, retaining joint errors and mother-source grouping. It uses the same supported reference distribution. Tests establish exact equality between empirical joint-edit plug-in risk and complete replay in the identifiable fixture; interval widths can differ because the constraints differ. There is **no demonstrated advantage over full replay on these same supported worlds**. Replay is already sufficient to evaluate a new deterministic rule on cached complete graphs.

Checks cover identity/swap ambiguity; joint role/attachment errors versus a false independent-field approximation; unmatched anchors; unrestricted unknown mass; nonzero uncertainty after clean finite calibration; duplicate-source invariance; version/domain/support/split rejection; small-sample abstention; and conditional plan selection with separated empirical records. The paired graph outcomes and counts are synthetic implementation fixtures, not a rebranding of the earlier exact-distribution toy experiment.

## What remains necessary

This is not an adapter for incomplete natural-language records. Partial graphs, unknown payment dates, inferred labels, and unversioned observations must not be filled with guesses to enter calibration. The actual-data audit is separate. Real use needs audited source-grounded complete graphs, comparable paired reads from at least two frozen plans, disjoint dictionary-development/calibration source groups, and genuinely held-out legal rule groups. This package does not implement or claim held-out-rule prediction error, plan regret, native benchmark score, direct same-budget pipeline evaluation, or real calibration cost. No empirical confidence coverage experiment or real-data efficacy result is reported. Program correctness and source-fidelity loss are also outside these decision-loss checks.

## Added sample-size and transfer diagnostics

At 24, 128, and 256 independently identified synthetic sources, the clean conditional fixture gives interval widths 0.3322, 0.1439, and 0.1017. Triplicating each source's views leaves these widths unchanged. These are design calculations under independent source-cluster assumptions, not coverage or accuracy evidence. The 800-source demonstration is likewise synthetic, not a substitute for the available 24 real sources.

An explicitly enabled stationary-channel calculation produces a conditional interval for a reference world absent from calibration, where full paired replay returns unsupported for lack of coverage. This illustrates the extra modeling assumption required for beyond-replay use, not a measured gain. Default strict support continues to reject it. A negative schema test reads the actual partial SARA audit artifact when present and verifies rejection; no reference payment dates, missing facts, or model versions are fabricated.

# 法律技能进化：两项方法的收敛方案

2026-11-17。决策：**将后续方法投入收敛到“法律消费者约束的关系接口学习”和“共享语义约束的对照监督合成”**。冻结执行模型，教师更新外部技能库。本文件替代旧方案中尚待执行的方法选择与旧 M2 风险通道路线；历史代码、结果、账本、暴露记录继续保留。核心接续基线为用户指定的 `354bece66fd9a0b1e7bc8dab1a6d7159ee141345`，具体复用边界见 CURRENT_CODE_AUDIT.md。它没有恢复服务器或启动任何真实模型实验。

这是一项具体神经符号技能学习研究，不以发明通用抽象解释、SMT、主动学习或蜕变测试为主张。推荐投入的依据是可区分的学习对象、具体算法、现有失败动机和已复算的确定性实现。真实模型收益尚未测得，不将“检索未发现同一完整机制”写成“全球无人做过”。

## 一、从现有证据收敛出的核心问题

核心问题是：**法律技能的规则、事实表示和更新监督之间不匹配，使冻结弱模型既难以执行正确技能，又可能把偶然答对写成错误经验。** 两项方法分别改变“执行时需要读出什么”和“训练时凭什么更新”，共享一套来源语义约束，独立可消融。

现有工程必须先修的共同问题：原始任务的默认条件不能在读者提示中遗漏；未知属性不得直接断言为真；输入截断与消费者覆盖不全不能冒充方法失败或方法收益。此前 OpenExempt 的联合财产默认条件遗漏是共同契约问题，应修到全部对照里。

历史结果不能用来声称两个旧核心已成功：用户补充的最新核心代码已含 residual.py 的有限域关系合成骨架，不能说仓库完全没有这项能力；实际生产主要接入 Airline 单字段分桶、OE 常量代入/分支裁剪及固定布局选择，尚未形成跨真实模块的关系/分组技能学习闭环；旧 M2 在未知结构风险下退化，已经停止。此前整体方法好于某基线但相关新操作触发为零，也不算核心证据。具体证据见 [原始复核](../research_audit_20261117/AUDIT.md) 和研究分支提交 `1f132108fa326d46118c3c708458fbbafec7bfb2` 的报告。

## 二、方法一：法律消费者约束的关系接口学习

### 问题与直观解释

弱模型不一定需要恢复一张完整案件事实表。某条规则只需要“同一笔付款是否晚于同一服务结束”，强迫它输出所有日期再连接容易出错；但直接删掉日期又可能破坏另一条依赖服务时长的规则。应当学习一种**对当前法律消费者足够、同时实际容易读取**的表示。

### 具体算法

输入：审核后的法律消费者族 F、适用上下文 c、来源事实约束 W、冻结读者 R、固定局部操作语法。输出外部库项 `(H, reader_prompt, D, scope, proof_receipt)`。

1. 从消费者的比较、聚合、连接键、作用域和源文锚点自动提出关系及分组候选。语法包括精确原子值、相对次序、联合阈值、同实体配对、局部例外归属；禁止把整题最终答案作为读取字段。
2. 为 H 联合合成 D，检查 `D(H(w),c)=F(w,c)`。相同编码导致任一声明消费者输出不同，即返回碰撞反例并排除该候选。有限域可穷举；扩展使用约束求解。未被编码的上下文不获得保证。
3. 在语义合法候选之间，用同一个冻结模型和同源训练材料实际读取，按原生任务损失、来源忠实性及实际成本选择；不以更短、更少字段或教师主观评价代替真实读取效果。
4. 教师将成功读法归纳为可跨来源实例化的接口技能。只保存操作、锚点模式、解码器和适用域，不保存本题答案。消费者变化时重验接口。

H 不必可逆：两个不同的日期/数值组合可映为相同关系，但所声明的法律消费者必须无法区分。部分信息按同一组允许世界整体映射，不能将每个字段的可能值独立组合。

### 实现证据

`prototype_m1.py` 已枚举 63 个接口、检查 1600 个双事件世界，自动拒绝缺失时长信息及事件身份的表示。

`airline_real_relation.py` 使用一个已有真实 TRAIN 来源，自动从原生程序读出阈值，枚举 31 类特征及三类分组，检查 14800 个有限状态；合成解码器与原生总价均为 1433。独立尺寸/重量边际相同的反例，因同袋配对改变，总价变为 1363。原型的复杂度排序是示例成本，尚未实现真实读者条件选择。

### 实质差异

PARSE 的 RELAY 恢复原 schema；这里可以丢掉消费者不需要的信息。普通部分求值消去已知值；这里可将仍未知的多个输入改为关系。SCOPE 可以表达类似最终程序，但这里在固定消费者语义约束下合成接口/消费者变换，再学习读者可执行性。函数压缩、Atlas、Pix2Pred、WebQA 已覆盖充分表示或下游驱动抽象等基础思想，故贡献是这个具体接口学习算法，不能仅归于“压缩”“分桶”或“反例”。详见 METHOD_1.md。

## 三、方法二：共享语义约束的对照监督合成

### 问题与直观解释

训练标签告诉我们答案错了，通常不能告诉我们该改案件读取还是法律规则；中间语义审核又不总完整。让教师随意补齐事实、生成一个唯一反事实标签，可能奖励错误更新。

即使不知道两个案例各自完整答案，也可能知道它们应满足的关系。**相同、未修改的事实不能在两个衍生案例里各取一套有利解释。** 本方法自动生成合法源变化及其共同语义下的允许输出关系，用它形成更新监督。

### 具体算法

输入：TRAIN 原文及证据位置、已审核的局部语义约束 K、尚未消解的解释/事实变量、有限源编辑语法、候选外部技能更新。K 来自原文/官方任务假设/独立审核，不来自待验证技能本身。

1. 对可编辑的基本事实计算依赖闭包，生成保持非目标内容的源案例组 Q。只允许明确位置替换或结构化渲染；派生值随基本事实变化。无原文对应物的内部标签翻转不可作为训练证据。
2. 将不确定性区分为法规版本/定义作用域变量 λ，以及母来源事实变量 η。λ 只在同一法律作用域共享；η 只在同一母来源的衍生组内共享，独立案件不可错误共享未知所有权等事实。
3. 自动计算允许关系 `S_K(Q)={(F_ω(x1),...,F_ω(xk)): ω满足K}`。同一个 ω 贯穿整组；禁止先逐例补全再取笛卡尔积，禁止挑一个便利解释伪造唯一标签。输出可以是原生答案关系，也可以是有依据的局部事实/规则投影。
4. 在源编辑成本和真实调用成本内选择能排除候选错误更新的案例组。通用覆盖/SMT仅是求解工具；若候选真实输出不属于允许关系，才形成负证据。符号缺陷模型可选例，不能冒充模型真实响应。
5. 教师据“源变化—违反关系—相关技能位置”修改外部技能。用原生训练标签锚定正向学习，以关系约束排除错误经验，再做来源隔离的 DEV 选择。通过关系仅表示尚未证伪；全部输出 unknown、保留不更新或恒定输出不能算成功训练。

关系可能无法区分两个更新。此时保留行为等价类；不能通过追加终答测试强行定位。需要来源忠实投影时明确记入标注成本。对同一作用域持续保持解释一致，不允许每组临时换解释。

### 实现证据

`legal_distinguishing_pairs.py` 检查依赖闭包、单一解释产生的错误标签、独立补全掩盖错误、作用域共享边界，以及终答相同的双重组件错误不可识别。其 SARA 金额文本来自真实 TRAIN，但阈值例是合成机制例，不能计入原生效果。

`airline_partial_relation.py` 补充真实规则闭环：从同一 Airline 来源自动枚举 5 个合法重量交换；不给关系生成器完整基础费用/最终答案，只给审核后的局部收费函数，自动推出一个变更的总费用差应为 -70。独立原生执行复核为 1433→1363。它能排除“超重超尺寸相加”和“丢掉同袋配对”的候选错误。此处是受控的中间标注缺失，不声称原文未给票价；没有模型调用或真实涨分。

### 实质差异

SCOPE 已有反推谓词错误和对抗样本；DAAF 已有干预更新信用；SkillEvoReg 已有候选更新驱动的源攻击；Synedrion 已有法律高阶蜕变测试；NormWorlds-CF 已有已知完整规范世界的成对监督。因此不把上述部件单独当创新。

本项新增对象是：**不完备源语义下，带来源变更可实现性、法规/母来源共享约束的关系监督自动合成，并用于外部技能更新。** 既不要求完整反事实金标，也不由教师直接猜一条关系。一般关系监督、保留多解释、SMT 与测试生成不归为首创。具体边界和最强对照见 METHOD_2.md、RELATED_WORK.md。

## 四、训练路线与两项独立价值

共同底座：冻结 Qwen3-8B，thinking 保持关闭；教师沿服务器实际配置（已使用 Codex CLI）读取失败证据、提出/修订技能；模型名与实际暴露配置完整记录，未暴露的温度记 not_exposed。训练更新的是外部表示/规则/读取技能，不是模型参数。

每批：公共修复后的执行→教师提出有限技能候选→方法一生成并试读合法表示→方法二生成关系监督并指出错误经验→按原生标签与独立 DEV 选择→记录库快照。方法一可在普通监督更新下单独用；方法二可在固定原始接口下单独用。规则更新后重验所依赖的接口。

主消融为共同底座、仅方法一、仅方法二、两项全开。主要收益路径分别是读取/绑定错误下降，以及有效更新增加、错误更新和跨批退化减少。不能仅报告合法率、少调用或少出错；最终都要落到分库原生指标和固定 DEV 学习曲线。

## 五、数据计划

保留至少五个独立源数据集混合训练、分别测试。推荐正式五库为 **OpenExempt、ContractNLI、MAUD、RuleArena Airline、Housing**。SARA 继续作为已有训练/机制回归资源，不把已暴露库存重新标成盲测。Housing 是独立住房法规来源，不能用 SARA 的改名/变体替代独立性。住房任务来源可经 DeonticBench 追溯原 Housing Statute QA。

依据用户最新核心提交 `354bece66fd9a0b1e7bc8dab1a6d7159ee141345` 的库存安排，首轮正式训练采用 **OpenExempt 32，其余四库各 24，共 128 母来源，8 批×16**，优先复用原训练资产、用 Housing 替换正式队列中的 SARA。各库目标 DEV16、全新 TEST32。DEV可从已暴露且不属于本次TRAIN的历史开发材料中固定；不要求它也是新盲测。尤其 MAUD 未暴露库存仅39，不能再承诺新DEV16＋新TEST32；优先保留其中32个合格母来源作新TEST，开发使用另列的历史材料。全部旧测试暴露需明示，不能重新包装为未见。**这是配额计划，不是已经完成的新划分。** 正式队列前按服务器所有历史暴露、文档/案件/模板族与近重复去重并锁定清单；39只是候选上限，若去重后不足32则如实报告。Housing须核实独立库存；LegalBench diversity 已有服务器元数据方案，保留为后备，不能擅自同时扩成第六库。首轮不自动扩到256或追加新数据追涨分。

## 六、强对照和固定验证

方法一至少比较：已有正确固定接口（包括逐袋桶+ID）；PARSE式 schema 优化+转换；部分求值/裁剪；同候选池不测读者的最短接口；同候选池普通搜索；SCOPE式弱执行程序学习。不得通过让对照读取截断文本或巨大无用schema制造优势。

方法二至少比较：普通原生标签更新；SCOPE式对抗生成；SkillEvoReg式候选驱动验证；Synedrion式高阶关系；同一源候选池的逐例独立补全、单解释补全和共享解释关系合成。DAAF作为更新信用近邻，若实现诊断对照应给相同候选与关系。完整语义信息和同等教师预算公平提供。

“把本方法合成的关系交给 SCOPE/SkillEvoReg 后也涨分”支持关系生成器的可迁移贡献，并不自动否定它；但这时不能再声称下游归因器本身是新增算法。相同语义输入下，现有生成器若完整复现所有新关系和成本优势，才意味着本方法生成机制未显示独立价值。

执行顺序：

1. 复用当前工程和审核资产，修共同契约；实现两个生产模块及上面明确的语义检查。保留历史账本，隔离入口，删除仅为旧路线存在的无用兼容，不做大重构。
2. 固定五库各 4 个 TRAIN 母来源（共 20）做同源真实比较；按任务结构预选而不按结果换题。报告接口实际变换、读者错误、关系自动生成、排除/保留更新及原生分数。首先实现强对照，不追加方向。真实请求按已有资源权限执行，完整记账，不设置每轮修复都需用户授权的流程。
3. 两个机制实现真实执行且关键差异未被对照完全吸收后，按锁定清单完成一次 128 来源完整训练、固定 DEV 对照和学习曲线。小试不要求统计显著；若核心操作根本没触发/全 unknown/独立监督不存在，先修具体原因，不能无证据扩大训练。
4. 冻结库、选择规则和配置，再进行五库分别 TEST。报告来源级预测、原生指标、按母来源的置信区间、成本、适用覆盖、两项独立消融以及跨库迁移。旧暴露测试只作开发/历史结果，不混入盲测结论。
5. 核验后形成论文方法与实验初稿。完成标准是实际实现、完整训练/测试与两项贡献的据实评估；不靠报告、toy或流水账完成目标。

## 七、锁定边界

锁定的是核心问题、两个学习对象、输入条件、强对照与数据原则。实现中的字段名、求解器、提示模板和缓存属于工程选择，可自主修正。检索到某个通用组件早有研究、一次小试不显著、个别库不适配，都不构成重开选题理由。

只有出现相同对象/假设下的高度重复、形式反例否定核心机制，或正确实现后核心被同信息强对照完整吸收，才重新评估这项贡献；必须给出具体证据。固定研究矩阵完成后停止扩展，不通过连续换任务、测试或种子追涨分。若贡献不成立，明确指出哪一项、依据何在，不能改名掩盖或虚报完成。

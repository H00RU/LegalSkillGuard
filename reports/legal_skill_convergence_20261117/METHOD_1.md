# M1 扩展查新、实际贡献边界与真实 TRAIN 关系原型

2026-11-17。本轮问题固定为：现有 M1 能否成为一个有明确新增机制的神经符号接口学习方法，以及是否能落到已有真实来源，而不是把函数压缩换到法律场景。

## 判断

**可以继续作为一项具体方法投入，但应该实现“受消费者约束的关系接口与解码器联合学习”，不能把目前的阈值分桶原型本身当作独立创新。** 有限原型已证明这种合成可运行，真实 Airline 来源已完成原生程序一致回放；它没有证明弱读者更容易读取新接口。

本方法可承担的贡献是：在固定法律程序不能被训练标签任意改写的条件下，自动选择局部事实表示、对象分组及消费者变换，使同一个冻结模型更可靠地完成读取。这里有一个具体优化对象和实现算法。数学上的充分表示、商划分、抽象精化、编译正确性和一般性的下游任务优化均已有直接先例，不归为本项目首次提出。

## 新增机制必须完整落到算法

输入包括审核后的消费者程序族 F、已声明可变化的法律上下文 c、训练原文 x、来源事实及未知边界 W(x)，以及固定读者 R。输出是可复用外部技能 `(H, prompt_H, D, domain, certificates)`，不更新 R 参数。

1. **从消费者生成候选语法。** 抽取比较、聚合、连接键、事件作用域及它们的依赖；自动生成原子取值、相对比较、联合阈值、角色绑定等局部读法。组装时枚举同对象联合读取、带身份锚点读取与独立读取。原子范围来自程序及源文结构，不允许“最终答案”或覆盖整道题的黑盒字段。
2. **成对合成接口 H 和消费者 D。** 候选需要满足 `D(H(w), c) = F(w, c)`，覆盖预先声明的世界和消费者族。相同编码而答案不同的见证直接淘汰候选；不是只检验 JSON 可解析。必要身份或耦合信息由反例约束决定，不能默认独立数组已足够。
3. **在合法候选中做真实读者选择。** 同一训练原文交给同一冻结模型读取不同候选，使用各自已确定的 D 计算原生输出，并核对事实忠实性。训练损失来自真实的 `(x, R(x,prompt_H), D)`，不能以接口长度、语义商大小或教师偏好代替模型误差。未知事实不能用标签补齐。
4. **保存变化的是接口技能。** 库中存放关系模板、局部证据/身份定位、配套解码器及适用域；新来源只实例化这些模板。跨来源选择应按母来源隔离，避免仅保存本题桶值。扩大消费者或规则上下文时重新验证适用性。

这四步使算法区别于手工换输出格式。第 1、2 步限制了搜索空间并建立可执行语义；第 3 步决定哪个语义正确的表示实际适合弱模型。通用枚举、beam search、CEGIS、经验风险最小化可以作为实现工具，无须包装成新优化理论。

## 最近邻对照，而非只比较 PARSE

| [Atlas: Learning Abstractions for Program Synthesis，Wang 等，CAV 2018](https://web.eecs.umich.edu/~xwangsd/pubs/cav18.pdf) | 根据反例学习抽象谓词模板，并合成抽象变换器 | Atlas 用抽象加速程序搜索；这里输出的是交给冻结自然语言读者执行的局部接口，目标是实际读取准确率。一般反例精化过程不是新增贡献。 |
| [Web Question Answering with Neurosymbolic Program Synthesis，Chen 等，PLDI 2021](https://pldi21.sigplan.org/details/pldi-2021-papers/22/Web-Question-Answering-with-Neurosymbolic-Program-Synthesis) | 冻结 NLP 模块与结构/字符串操作组成 DSL，按标注网页学习可复用抽取程序 | 这里额外联合改变表示与确定性消费者，同时对预先固定的法律程序保持语义。仅“神经模块＋DSL＋数据驱动搜索”并不新。 |
| [Predicate Invention for Bilevel Planning，Silver 等，AAAI 2023](https://ojs.aaai.org/index.php/AAAI/article/view/26429) | 从语法中选择谓词，针对下游规划效用学习抽象 | 因此“根据下游效果选择抽象”早已有之。差异是固定消费者精确等价约束和冻结读者可读性，而非学习新的世界动力学。 |
| [Pix2Pred，Athalye 等，v4 2026](https://arxiv.org/html/2501.00296v4) | VLM 提出并读取物体谓词，优化筛选谓词及规划模型；也处理带噪谓词 | 这是最应加入讨论的感知接口近邻。这里从已知法律消费者生成并验证非可逆关系表示，不从演示联合拟合动作模型。不能声称首次使用固定基础模型读取学习出的谓词。 |

| [PARSE，Shrimal 等，EMNLP Industry 2025](https://aclanthology.org/2025.emnlp-industry.184/) | 数据驱动 schema 优化及恢复原 schema 的转换层 | 可逆/原 schema 恢复要求与“只保留固定消费者充分关系”的目标不同。但候选接口加转换器这个整体架构已有先例。 |
| [ScheMatiQ，Levy 等，ACL Demo 2026](https://aclanthology.org/2026.acl-demo.22.pdf) | 研究问题驱动的观察单位及 schema 发现，带来源证据的表格抽取，也评估法律场景 | 不能把法律场景、来源证据或任务相关 schema 作为新增。这里要求可执行消费者约束与自动联合解码，不只是发现有用列。 |
| [From Weak Task Specifications to Scientific Extraction Agents，Dong 等，2026](https://arxiv.org/html/2609.34829v1) | 同时优化 schema 构造与抽取指令，用失败文档提供文本梯度 | 不能把“训练中不断改 schema 和提示”作为创新；这里的可变空间由消费者语义限定，输出转换有明确等价检查。 |
| [SkillCom，Fu 等，2026](https://arxiv.org/html/2605.02333v1) | 任务相关语义单元、显式类型接口、传输和定点恢复 | 它使用固定六字段接口与通信擦除模型；这里学习接口内容和联合关系，主要噪声来自读者语义误读。仅分模块及局部修复不算本项新增。 |

结论不是“上述工作都不能表达本方法”。WebQA、SCOPE 等通用程序搜索可能表达相同最终程序。应比较固定任务下的候选生成、语义可行域与学习过程，不能利用表达能力与生成算法的混淆制造新颖性。

## 真实 TRAIN 端到端检查

脚本：`airline_real_relation.py`。来源和哈希：`airline_real_relation_fixture.json`。完整结果：`airline_real_relation_results.json`。

使用现有训练清单中 `RuleArena_Airline:e88c2c8f441b03bf1e690f5c49450dc95e2fa39d19e589745164f6786caf47a8`。公开原文是 Karen 从 Phoenix 到 Rio de Janeiro，Basic Economy，五件行李，票价 563。正则仅为此确定性夹具的公开文本解析器；解析的 5 件行李逐项与已有 construction arguments 一致，保留各句证据位置。未使用新的模型读取，也没有把这个解析器说成训练出的能力。

- 原文 SHA256：`5f3bea67c9f5aa771789b8407a701df1ab130d7723923f6ef9005922bd33a3ed`。
- 公开 record 的规范化 JSON SHA256：`626f8b2e8cdf569f3fa60d0c17162ba89ebf6c6cf49ab3bf8e9aa84af06e9f20`。
- 从原生 `compute_answer.py` AST 自动提取尺寸总和阈值 `[62,65]`，重量阈值 `[50,53,70]`。
- 枚举 31 个特征子集，在 14,800 个局部有限状态上自动构造 decoder；21 个合法、10 个不合法。
- 最低示例复杂度的表示是尺寸阈值关系与重量阈值关系，12 个 decoder 状态。它不能恢复精确三边及重量。
- 另外自动枚举三类组合方式：各列独立排序、联合关系但丢失袋身份、带袋身份的联合关系。对逐袋与总额共同消费者，前两者找到语义碰撞，第三者通过。
- 原来源的四件托运行李罚金为 `[100,30,150,30]`；基础费用 `[60,100,200,200]`。合成接口/decoder总价为 **1433**，与原生程序及现有记录一致。
- 一个明确标为构造反例的输入只交换第二与第四袋的重量。独立尺寸/重量边际完全相同，原生总价变成 **1363**。因此同袋属性耦合不能由独立桶数组替代。

这证明：数据确实存在需要保持联合关系的原生消费者，接口候选与消费者可以成对合成。它不证明现有固定接口不能做到相同事情，也不证明新提示更易被 Qwen 读取。为避免把原有 Airline 桶策略重命名，本原型明确保留“固定逐袋桶＋正确 ID”为必须比较的强基线。

## 最小且足够的归因比较

1. **原有正确固定接口/逐袋桶＋相同读者。** 检查学习接口是否真的优于已有人工表示。
2. **PARSE 式 schema 提案＋相同冻结读者＋原 schema 恢复；部分求值/字段裁剪。** 区分原 schema 优化和消费者充分表示。
3. **相同关系候选池，按最短接口/最小语义商选择。** 区分形式压缩和真实读者条件学习。
4. **相同候选池的普通搜索。** 约束合成若不改善合法候选效率，不单独宣称搜索算法增益。

每个候选使用相同来源、参考、模型版本与请求预算；选择收益不能来自读取了更多文本、修复截断或隐藏补全未知字段。最终本项主张应是“具体接口学习机制带来原生任务改善”，而不是“加入验证后程序更安全”或“表更短”。

复现：`python prototypes/airline_real_relation.py`。仅使用已有 TRAIN；0 次模型调用；未读取项目 TEST 样本。

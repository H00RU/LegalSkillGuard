# 耦合法源前提提升：近邻核对与贡献边界

日期：2026-11-11。用途：审查METHOD_ACQUISITION.md的外部技能获取机制。检索与正文检查使用下列primary论文；未进行模型实验，不把未搜到完全同名方法等同于全球无人做过。以下是机制比对，而非发表概率判断。

## 1. 结论先行

“冻结模型＋教师＋外部技能演化”“失败后修技能”“适用条件/证据校验”“法律技能”均已有直接近邻，不能成为本方案的创新。可继续实证检验的具体增量仅为：**从跨来源失败中选择语义耦合的源前提块，将固化内容整体改写为当前源的局部读取与一致绑定程序，持久化可迁移的获取过程。**

目前没有在已读近邻中找到相同的领域更新对象与候选闭包算法；但通用联合程序修复、全部参数化和自由技能编辑能表达同一结果。因此这是一个具有明确归纳偏置的领域方法提案，不是已证明胜过最强通用方法的新范式。算法表达上可涵盖并不等于已有论文实施了同算法；反过来，名称不同也不足以证明新增价值。有限例子已经公开通用联合修复同样成功。

## 2. 直接技能近邻

### KDASO：最接近的法律技能工作

[Knowledge-Data Dual-Driven Automated Skill Optimization for Liability Adjudication Tasks](https://arxiv.org/html/2611.06972v1)，2026。检查方法中的邻域条件归纳、技能验证/冲突处理、执行对齐细化和路由。技能包含前提、裁判逻辑和结构模板；从相似标注案例与人工轨迹归纳，并用经验正确性和执行一致性修订。

**已覆盖：**法律技能生成、教师归纳、技能前提、相似案例支持、冲突修订。不能把本方案写成首个法律技能演化系统。

**本法明确不同之处：**更新对象是技能内部一组源前提到当前文本读取/绑定的结构变换；不是仅扩写裁判步骤或用执行轨迹相似度选技能。**强对照必须允许KDASO式编辑器做同样联合修改**，给同样来源与独立反馈，不能把它限制成固定模板。

### Skill-V：验证契约和边界修订已经有人做

[Skill-V: Verifiable Self-Evolving Skill Library for Interactive Agents](https://arxiv.org/html/2610.11781v1)，2026。正文§3.2–3.4：技能是语义意图、过程、可执行rubric与版本；依据结果与rubric不一致修订，在历史回放中检查保留语义和不退化，并有适用性过滤。

**已覆盖：**版本契约、来源于结果的修订、适用边界与保留旧能力。它也允许过程修订，不能声称只能修guard。

**本法差异：**把原来可能需要拒绝的跨源使用转成“重新读取一组相关前提后继续执行”，具体学习读取/绑定的改写。验证和版本账本只是共用基础。需要同预算过程修订对照才能归因。

### Scope Before You Persist：限制部署范围不是新点

[Scope Before You Persist: Preventing Cross-Family Interference in Agent Memory](https://arxiv.org/html/2609.29144v1)，2026。正文§3.2和§4：冻结模型的外部记忆，按任务family保留技能，配套执行反馈和回归控制；研究只在支持该编辑的family检索所带来的影响。

**已覆盖：**按认证证据限制技能部署范围，防止跨family干扰。

**本法差异：**研究如何改变技能内容，使同一推理程序重新获取新来源前提后可跨源使用，不把“源不匹配就拒绝”计为复用成功。若最后只剩按来源分库存取，与该工作差异不足。

### EvoSkill：自由技能编辑本身足够强，必须公平比较

[EvoSkill: Automated Skill Discovery for Multi-Agent Systems](https://arxiv.org/html/2603.02766v1)，2026。方法由执行、提议、技能构建角色组成；模型权重不变，基于失败和参考答案生成技能/脚本，通过评估保留改进。

**已覆盖：**冻结模型、失败驱动技能生成、教师式角色、可执行脚本和有限候选选择。自由编辑器完全可能自己提出联合源参数化。

**本法差异：**受限但有针对性的Lift操作、耦合块候选和持久绑定程序。应比较相同提议/验证预算下找到有效修改的能力，而非声称自由编辑器不能表达本法。

### ACE、ExpeL、SkillWeaver、SkillRL

- [Agentic Context Engineering](https://arxiv.org/abs/2510.04618)：上下文playbook经生成、反思、整理持续更新。经验规则和增量记忆不是新点。
- [ExpeL: LLM Agents Are Experiential Learners](https://arxiv.org/abs/2308.10144)：从任务经验提炼自然语言知识并用于后续检索/行动。成功与失败总结不是新点。
- [SkillWeaver](https://arxiv.org/abs/2504.07079)：发现、练习与细化可复用API技能，并研究技能迁移。技能作为可执行调用和强弱模型间复用不是新点。
- [SkillRL](https://arxiv.org/html/2602.08234v1)：教师从成功/失败中蒸馏分层技能库，并与策略训练联合演化。其完整系统包含参数训练；冻结设置应明示是适配后的外部库基线，不冒充完整复现。

上述工作分别覆盖经验提炼、库维护、可执行技能和递归演化。我们的差异必须落实在具体源前提抽象操作，不能仅靠法律领域名称。没有必要把四篇都变成新增全量实验臂，保留最强代表和必要的同缓存诊断即可。

## 3. 程序学习与绑定的强近邻

### Binder：自然语言局部读取嵌入程序已经成立

[Binding Language Models in Symbolic Languages](https://arxiv.org/abs/2210.02875)，ICLR 2023；核对原论文摘要及程序/API设计。

**已覆盖：**在符号程序中插入语言模型API处理局部语义任务，结合结构化执行。READ_LOCAL不能单独当作本法创新。

**本法差异：**在技能演化中学习哪里需要读取、哪些字段应共同读取、它们在技能中的所有消费位置如何绑定。最强对照应先参数化全部相关前提，使用同样局部联合读取API。若一次读取全部字段成本低且误差不增加，本法减少端口的价值可能消失；不能预设“全参数化必然差”。

### Refazer：多位置程序变换与抽象也不是新点

[Learning Syntactic Program Transformations from Examples](https://people.eecs.berkeley.edu/~bjoern/papers/rolim-refazer-icse2017.pdf)，ICSE 2017；核对抽象、转换DSL与从前后程序示例学习的设置。

**已覆盖：**从编辑示例归纳变换、抽象变量与上下文、学习可重复应用的修复。它能表达联合变更，不能把它说成只替换常量。

**本法差异：**不要求提供前后技能程序对；从真实不同源上的任务反馈和实际存在的局部字段获得选择依据。归纳的变换专门提升源内容为读取/绑定程序。普通同语言联合修复获得同样信息仍是必要强对照。

### DreamCoder：可复用库与程序参数抽象已经成熟

[DreamCoder: Bootstrapping Inductive Program Synthesis with Wake-Sleep Library Learning](https://arxiv.org/abs/2006.08381)，PLDI 2021；核对library abstraction与程序合成部分。

**已覆盖：**从任务程序中抽象公共子结构、形成库并改善后续合成。库学习或最小描述长度本身不构成新增。

**本法差异：**显式将来源可变的法律前提绑定到运行时当前原文，而非仅压缩已解程序；执行模型权重固定。可迁移性的证据须来自真实新来源结果，不能用代码更短替代。

### SketchAX与CEGIS：反例循环和关系约束不能再包装

[Augmented Example-based Synthesis using Relational Perturbation Properties（SketchAX）](https://popl20.sigplan.org/details/POPL-2020-Research-Papers/31/Augmented-Example-based-Synthesis-using-Relational-Perturbation-Properties)，POPL 2020；核对关系性质/扰动与合成约束设计。

**已覆盖：**用关系性质与扩展约束帮助程序合成；更一般的CEGIS也早已使用候选、反例和修复循环。

**本法差异：**本轮不靠教师制造新法义gold或不受限的反事实法规标签。核心是特定的源绑定提升操作和候选闭包；有限反馈下选该操作的效率是待检验主张。若实现退化为“叫模型自由修＋回放”，就失去该操作差异。

## 4. 具体同信息检验和最强反驳

现有确定性检查固定来源A为 `min(B,100)+A`，来源B为 `min(B+A,60)`。金额与覆盖范围分别提升都只有1/4目标题正确；同时提升为4/4。该例说明一种单前提改进搜索可能卡住，也明确显示通用联合修复与全部相关端口参数化均为4/4。它是构造算法例，不是原生法律数据或执行模型能力结果。

因此，需要比较同一候选材料、同一个读取API、相同原生标签/字段和相同调用预算下：耦合Lift、自由联合编辑、全部参数化；不能只比较单槽替换。教师给出的Coupling提示和源定位信息也给对照，不能把优势来自额外提示误记为算法贡献。

最强反驳是：语义记录闭包只是常见领域DSL设计；与全部参数化或通用联合修复相比没有实际质量/成本优势。当前尚未用真实实验排除这一反驳，也不应该声称已经排除。可研究的正面主张是这种限定的结构先验在小规模、冻结模型、弱中间监督下改善技能获得与迁移效率；它有确切实现和可证伪对照。

## 5. 本轮查新的边界

- 这不是系统综述或“世界上无人重复”的证明。新颖性判断限于已核对的具体机制。
- 搜到SEEM2《Evolving Semantic and Procedural Memory from Shared Experience for LLM Agents》的二手页面，但本轮未确认可访问primary正文，不用二手描述支持排他性结论。源内容/程序分离本身已经按已知通用思路处理，不占创新名额。
- 法律模板slot填充作为强基线设计，不归给一篇未核实论文。固定slots和学习何时将耦合前提提升为slots必须分清。
- 当前方案没有证明M1已优于所有强对照，更没有据此宣布两项创新已通过。它完成的是具体机制与最近冲突的可审查界定；服务器仍暂停，不调用模型。

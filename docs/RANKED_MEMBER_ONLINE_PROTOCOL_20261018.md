## Strong controls and actual cost

Each new contract gets:

- joint_empty: one-call ordinary model trained on the same revealed42/50/58/66 labels.
- factored_empty: equal-two-call empty memory, same growing ordinary model.
- dual_skills: two calls, exact latest skill bank with the fixed42 ordinary model.
- fixed_tool_empty: two-call empty memory with identical fixed42 inputs.

All controls receive full rankings too. Thus distinguish skill effects over an
identical tool from performance against ordinary learning with equal seen labels.
The auxiliary ordinary prefix fits after B1–B3 use the same model/parameters,
only original revealed sources and no skill queries; CPU only, not another LLM.
They do not replace the main method's fixed tool. Alternate main-arm order by
source position without inspecting outcomes.

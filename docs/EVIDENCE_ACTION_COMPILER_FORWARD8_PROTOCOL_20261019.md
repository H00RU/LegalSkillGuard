## New representation and unchanged legal decision

One existing authorized teacher call compiles an initially empty bank of pure Python
`propose_evidence_groups(text,spans,public_hypothesis_key,ordinary_candidate_indices)`
programs from the already revealed chronological last16 sources/annotations/actual
policy and publication feedback. The only latest teacher4 prose candidate is a fallible
reference, not a successful bank selected by utility. It is reconstructed once for a
fixed prose control and is explicitly NOT a publication in the failed original run.

Programs execute through the existing resource-limited pure executor, with no current
Gold, document ID, external model/filesystem/network or legal verdict. They suggest
source-index groups grounded in observable cross-SPAN relations. They do not score
labels or assign final evidence. No fixed program count, neighbor radius, efficacy
gate, selected checkpoint, runtime fallback or silent normalization. All structurally
valid teacher operations are used; explicit NOOP/no-match is valid. Execution/schema
errors stop and remain visible. Target3200/hard4096 serialized target-model tokens.

The same frozen Qwen3-8B receives unchanged full source, original hypotheses and
ordinary candidates, and selects legal labels itself. Four arms on EVERY forward source:

1. Original native format, empty prose bank.
2. Original native format, sole latest fixed prose candidate.
3. Same prose plus program-generated group menus, original flat integer-SPAN output.
4. Identical source/prose/group menus, optional atomic group action output.

In arm4 the model emits reason,choice,actions; every action explicitly emits both its
ASCII identity and the COMPLETE bound list of original integer indices. Any original
index remains selectable through a singleton action, so every original evidence set
is still expressible. The host concatenates ONLY indices literally present in native
action payloads. It adds no inferred member, deduplication, filtering, alignment or
legal answer. Repeated indices and invalid/length-limited responses are retained and
scored under the existing original rules. Native server identity/content stays saved;
the syntax-only metric view is separately marked and never called a native response.

# 原文核查式技能执行：开发干预，不是已验证的性能修复

2026-10-15。当前法律任务、原始Gold/划分/成员评分和冻结Qwen3-8B权重不变。
这是答案复核实验之后的新方法版本，不冒充原来那条链路未变，也不改旧Run输出。

## 为什么改这里

答案复核完整四批中，82个Gold非未提及问题的依据集合与初答82/82相同。
技能和标签确已交付，不能再把原因说成教师没有正确答案。
后续8合同上技能F1与等调用无技能复核均60.07%，仅联合有小幅净收益。
固定四TRAIN来源的10新调用/6引用诊断中，清空初答依据使FP18降至2或3，
但TP33降至32，有无技能的TP相同。不能把去锚定直接包装成解决了完整依据能力。

本版检验：文字规则只是可选建议时，弱律师是否没有把它变成实际的原文检查；
让学习产物成为必须回答的核查问题，能否改善原SPAN依赖、条件绑定和最终联合决策。
这是一项可否定的执行假设，不是保证。生成核查字段仍可能答错，不以字段齐全证明正确执行。

## 唯一方法调用

完整原NDA + 17公开命题 + 当前外部技能问题 → **一次原生核查及完整答案输出**。

每个命题先输出`checks`，其键必须与适用技能ID相同；每个值含原SPAN短引文和实际finding。
随后由同一律师原生输出原任务`choice/spans/reason/used_skill_ids`。
没有适用技能时，只回答公开任务的一条通用原文核查；没有固定技能类型、条数或强制增长。
命题分组限制输出键与ID，不宣称同一上下文中的跨题内容不可见。

不再把独立初答作为方法的推理输入；它仅是单独运行的强空库对照和已见训练行为观察。
不增加planner/binder/reflector/客户/检索器或额外模型调用，不让程序判断法律意义、
合并核查引文、补齐依据、清空答案、在答案间择优或给无效答fallback。
短引文可用于事后核验来源真实性，但不是答案修补或准入条件。

原始评分仍只读取原生`choice/spans`，无效、截断和自相矛盾均如实保留。
原Gold非NotMentioned题的依据F1计分不以预测类别筛选。
核查记录是观察通道，不能代替真实终点收益、消融或因果证据。

## 学习

仍从空库开始、4批各2份TRAIN来源。每批首遇使用前一批库，然后教师看累计原全文、原Gold、
本方法实际核查/答案、过去after、父库与独立空库训练观察，发布一次CREATE/UPDATE/DELETE/MERGE/NOOP。
教师仍gpt-5.6-sol/high；8B参数不更新。运行技能仍只有`id/hypothesis_ids/guidance`，
但guidance要成为简短、可由原文回答的核查问题，而非长篇政策原则。
原子编辑无效果准入，不把同案after当新来源泛化。保持及后续迁移不进入教师。

## 预先的否定条件

必须同时看分类、原SPAN P/R/F1、联合修复/破坏、旧案保持与新合同净收益。
若只减少FP、不增加正确依据，或强空库/无学习核查已达到相同收益，则不能支持技能解决完整依据问题。
若核查照样引用不相干原文，说明强制字段没有解决语义执行，不继续仅改问句赌B1。
不同批次难度不同不要求裸分数学单调；单库8来源区间不等于跨学习稳定性。
不以本有限开发实验宣称超过ACE/ExpeL、显著、SOTA或可投稿；新来源公平对照、独立学习重复、
机制消融和未调优正式测试仍是待完成证据。所有不利结果和真实成本保留。

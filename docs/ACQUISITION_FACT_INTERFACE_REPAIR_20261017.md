# Root repair decision record: factual delivery, not additional retrieval

Written 2026-10-17 before the executable-acquisition run's B3 phase completed.
This is a prospective engineering decision record, not an implemented change,
new experiment result, manuscript claim, or authorization to edit frozen inputs.

## Verified failure and remaining uncertainty

The current complete K2 retention audit covers all 16 B1/B2 contracts, not a
selection of failed questions. It finds 18 newly damaged and 15 repaired labels,
19 gained and 12 lost true evidence memberships, and 19 repaired versus 21
damaged exact-joint answers. Fourteen newly damaged labels are original NM.
Seventy-three omitted Gold memberships were already in the ordinary or
applicable-program lead sets; nine of twelve newly lost true memberships remain
there. These are original author member-set comparisons, not another semantic
judge's preferred labels.

The current interface does not enforce the teacher's intended topical scope at
the delivery level. All query locations have global inline SOURCE_LEADS tags;
the actor must mentally resolve those tags through program IDs and the public
hypothesis map. K2 reduces scope-assigned position memberships but increases
globally tagged physical positions. Its new ordinary evidence candidates have
explicit per-question indices and a literal text catalogue, whereas learned
query outputs have only global tags and ID references.

An earlier complete B1 source339 comparison had zero executed query results,
identical source, ordinary candidates and common system, but different metadata,
used-ID output constraints and native answers. This proves a non-factual input
change exists; it does not uniquely isolate IDs, schema, context or sampling.
The current K2 losses also include errors within applicable query results, so
removing cross-topic tags alone is not an established cure.

## Finish the current decision-relevant observation

Do not hot-edit the current run's 62 frozen inputs. Audit complete B3 first
encounters under K2 against both same-contract controls. A larger bank, better
training-only coverage, or an isolated positive case does not establish gain.
Small mixed effects are not automatic stop criteria. If subsequent transfer
and retention remain systematically harmful, preserve and stop the whole
engineering trial rather than deploy an earlier better bank or gate edits.

## Candidate root-level replacement, if needed

Keep the task, frozen actor, fixed ordinary M2, teacher, source query language,
atomic CRUD, all cumulative supervision and original scoring unchanged.
Change the actor boundary from program-control metadata to canonical source
facts:

1. Keep complete original source with unchanged original SPAN markers. Remove
   global program-ID/query-index tags from that source.
2. For each original hypothesis, pass exact indices returned by its applicable
   queries explicitly. Resolve literal original text through one shared
   catalogue, just as ordinary candidates are resolved. Keep all ordinary
   candidates and their scores verbatim; do not prune or refit them.
3. Canonicalize learned read indices by set identity and remove indices already
   present in that question's ordinary candidates. This removes duplicate
   delivery, not low-scoring facts. It is not an effect gate or fallback.
4. Do not expose skill names, query counts, scope-control maps, program code or
   teacher rationale to the actor. Preserve all program identity, scope,
   execution roles and original-source provenance in the run audit trace.
5. Use one bank-independent native answer schema for every arm: original
   choice, original spans, short public reason. Remove the used-ID field rather
   than retain a dead reporting requirement. All three labels and every
   original span remain available; all answers are made by the same actor.

Required invariant: for the same current source and fixed ordinary candidates,
equivalent per-hypothesis returned original-index sets produce byte-identical
actor messages and schema, regardless of program names, query decomposition,
record count or CRUD history. An empty incremental result has no metadata-only
effect on the actor. No stored legal conclusion, semantic reranker, generated
paraphrase, host answer union or response correction is introduced.

This replacement addresses an actual interface inconsistency. It does not
claim that a frozen 8B will then correctly interpret every relevant clause or
that all label errors are caused by delivery. If the same source facts are
still misinterpreted, record that limit rather than invent more lexical rules.

## A bounded causal check before another full learning run

If this replacement becomes necessary, fix the complete existing B1+B2 set of
16 contracts, published K2 and ordinary M2. Do not select only failures. Compare
the new interface with and without the exact same executed K2 results: 32 new
native calls and zero new teachers, with both arms under the same new schema.
Preserve old complete ordinary/skill outputs as a separate historical-layout
contrast, not new or independent calls. Measure actual costs and all three
original metrics, plus NN/NM errors and true evidence gains/losses.

Freeze source, all inputs, arm order and capacity before the first new call.
Back up the current negative run and its old source before any production edit.
Do not run this concurrently with the max-seqs=1 current study, relabel old
outputs as new, increase the token budget, or select a bank by the result.
This check establishes an interface effect on already-used training contracts,
not different-contract transfer, stable online evolution, repeatability, fair
mature-method superiority or official TEST performance. Those requirements
remain necessary for the active full goal.

## Cohesive v2 correction, not a larger cap or fallback

The skill artifact now contains ONLY id, public hypothesis_ids and named
guidance={inspection,source_queries}. Remove unused condition/verdict slots and
repeated runtime-rendering instructions. The complete named library appears
ONCE; public questions contain ID references to its full records. This is not
positional-table compression or hidden semantic retrieval. All17 tasks and
all published skills stay visible together. Shared-scope semantics are retained
through explicit public IDs, not by repeatedly serializing the same program.

Queries use the existing attributed all/any/none phrase matcher, with a boolean
option for the existing fallible list-introduction links of matched list items.
There is NO before/after neighbour window in the new API. These are retrieval
actions, not legal predicates. Every skill has1..8 queries, no prescribed skill
count/topic quota. Empty query results remain empty, without alternative actions.

Each query executes once per skill on the full original source. Exact arguments,
all direct matches and optional list-introduction locations are retained. Inline
SOURCE_LEADS tags identify skill/query hits immediately before original SPANs;
removing only these added tags restores the exact original marked source. No
contractual words/indices are changed. Literal original clauses stay in factual
traces for replay; the inference input does not duplicate them per question.
Native scope-ID references and all per-query receipts remain explicit. Query
arguments and actual receipts each appear once under named skill IDs, rather
than being copied into every task in a shared scope. Matching,
tagging and layout links NEVER decide a legal label or select final evidence.

Master and actual one-copy named-library-plus-ID-reference payload EACH must
fit the same4096 serving-tokenizer tokens. Full annotated source, all candidates,
skills and receipts must leave8192 output tokens within32768 for EVERY call.
No clipping, result pruning, cap increase, substitute bank or answer repair.
This changes v1's declared representation/resource accounting prospectively,
not its failed budget or artifacts.

## Reporting, stopping and remaining paper requirements

Complete-batch matched fixes AND damage, NN/NM labels/joint, true members gained/
lost, source-search coverage and actual native selection, CRUD/NOOP and real
teacher/native costs are required. Coverage is NOT utility, a performance upper
bound or admission. After-fit also changes the common supervised evidence tool;
it is not pure skill effect or new-source transfer. Do not demand mechanical
raw-score monotonicity across different-difficulty batches.

Whole-trial artifact-safe stop is permitted after complete B2/B3 comparisons
show all target effects nonpositive or clear systematic harm. Preserve in-flight
calls, mark incomplete, do not select an earlier bank. No partial-source score
selection, endpoint peeking, retrying the same Run ID or hiding failed costs.

This is still a hypothesis. Old query-feature/union, dense source-output, generic
checks and single-hypothesis negative results stay. V2 combines direct retrieval
actions with visible named inspection and an acquisition objective; it does not
claim the old primitive is novel or that simple composition guarantees success.
Fair mature experience-learning comparisons, equal-call review, independent
learning repeats, ablations, reproducible model access and untuned formal TEST
remain full unachieved Goal requirements.

# LegalSkillEvolve 当前评估契约

## 谁做什么

- 客户事实路由：冻结gpt-oss-20b只在律师当前问题与完整、排序固定的有限client belief集合之间做闭集匹配；披露历史不进入路由，回答文本由程序绑定事实。它不判断律师好坏。
- 语义评审：另一套权限隔离提示下的冻结gpt-oss-20b按DLawBench兼容rubric给出结构化语义标签；程序确定性换算分数。故“公式确定性”不等于“全部评价不依赖模型”。
- 确定性检查：泄漏、重复、协议、fallback、来源见证、技能文档暴露、候选硬门、哈希和安全指标。
- Luna：只生成候选或`NOOP`，不拥有轨迹评分、技能准入或库维护权。

本地单裁判不等价于DLawBench官方多供应商评审团，因此论文声称“DLawBench兼容指标下的内部比较”，不冒充官方排行榜结果。

## 训练信号与直接准入

训练语义指标包括Fact Coverage、Inquiry、Fact Resolution、Issue Resolution、Fidelity，并派生Elicitation和Resolution。组内奖励差用于发现候选来源，不等于单个技能已经完成独立因果验证。

教师来源首先必须来自同案、合作型人格、同一块首技能库的健康K=4独立探索：正轨迹相对负轨迹有正奖励差，并在唯一新事实、合法外部证据缺口或信息不减的提问效率上形成可观察优势；来源对照及完整轨迹还必须通过泄漏、fallback、状态、矩阵和身份检查，且来源fingerprint未被重复消费。这是教师证据资格，不是技能效果验收。

Luna产出的候选依次通过五类准入硬门：

1. **静态合法性**：schema完整、字段可执行、无案件专有隐藏信息；
2. **来源因果**：声明范围与行为机制能由冻结来源对照确定性重放；
3. **安全**：不引入硬法律安全、权限、泄漏或运行违规；
4. **去重**：与本块兄弟候选及当前工作库不存在实质重复或冲突；
5. **容量**：与工作库合并后的固定提示不超过容量，完整文档不被截断。

五类硬门全部满足即在来源块结束时直接进入工作技能库，下一块自然使用。不存在`provisional`、逐候选16/18案验收、候选有/无技能K4拆臂、`ACCEPT/DEFER/REJECT`或按单候选小样本平均收益设门。硬门可以拒绝不可信文档，但不得把“弱律师当前效果差”误当成轨迹不健康，也不得为保证每块固定产量而放过硬缺陷。

技能JSON不保存逐候选收益统计。来源块的硬门结论属于准入报告，下一块及后续块的变化属于整库prequential报告，维护决定属于库版本报告；三者以技能ID和库哈希关联，但不把库级变化倒签成某个技能的独立因果效果。

每块教师最多处理3个不同fingerprint的证据簇；通用与领域证据同时存在时至少各占1席，其余席位优先新的行为机制和法域。领域技能只对其声明法域负责，不因无法改善无关法域而判为无效。

## Prequential曲线与库级维护

第\(b\)块的正常16×K4轨迹使用块首库\(L_{b-1}\)，在从该块学习之前即构成未见顺序经验。每块预声明8案增加匹配的空库影子，比较整个\(L_{b-1}\)与空库，记录：

- 每次提问获得的唯一新事实数（主机制曲线）、唯一新事实总数、F/G有效回合和总提问回合；
- Fact Coverage、Inquiry、Elicitation、Resolution、Fidelity；
- 重复、过早结束、unsupported、关键事实召回与fallback；
- 技能文档暴露率、当块新增技能数和工作库规模。当前文档式干预不声称能从模型文本中
  无歧义识别某一技能被“调用”；单技能使用率不作为主指标。

空库影子不进入TF-GRPO分组、教师证据、候选硬门或最终显著性检验。prequential曲线反映随顺序积累的整体库表现；由于不同块案件不同，论文同时报告平衡设计、案件聚类区间和最终同案配对外测，不把单调曲线包装成单技能因果效应。

第2、4、6、8块后运行库级维护：重新检查静态合法性、精确文档重复、领域覆盖和联合提示容量，绑定截至该块的prequential证据并留下可追溯报告。由于累计库轨迹不能无歧义归因到单个文档，主流程不据此自动删除某一技能；需要合并或移除时必须形成独立版本化维护实验。维护不恢复逐候选下一块准入，也不读取官方30案结果。

## 最终测试与主张边界

主外测在最终库冻结后使用官方中文30案×4人格×seed42，对相同冻结Qwen的`control_no_library`与`legal_skill_evolve`做共同随机数配对。训练不声称学到人格专用策略；四人格外测衡量合作环境所得技能能否迁移到依赖、回避和对抗披露压力。

主终点是由实际披露事实ID和律师提问回合确定性计算的“每次提问取得的唯一新事实数”。唯一事实总数、Fact Coverage和Resolution防止一问即停伪装成高效率；Elicitation、Fidelity、重复、unsupported、belief-as-fact、过早结束、关键事实召回和运行fallback共同构成配套效果与安全指标。停止机制在这里承担安全与完整性约束，不取代事实获取效率主问题。

预声明6案seed43/44用于复核主终点与DLawBench兼容指标方向稳定性。客户路由和语义评审复用同一gpt-oss-20b权重，但提示、可见字段、schema和缓存隔离；主要行为主张以确定性披露ID为准，judge-heavy的Resolution不单独承担全部效果归因。

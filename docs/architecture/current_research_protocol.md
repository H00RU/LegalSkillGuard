# LegalSkillGuard 当前研究协议（128案）

修订日期：2026-09-08。本文是现行协议；60案、42+18、固定18案验收池、运行时技能触发器与动作改写器均已退役。历史运行只可用于诊断，不得恢复或计入现行实验。

## 研究问题与唯一学习干预

在冻结Qwen3-8B上，能否从共享可见状态下的结构化反事实轨迹差异中归纳结构化法律咨询技能文档，并让同一冻结模型在后续未见案件与最终官方DLawBench中文30案上以更少的无效提问取得更多关键事实、识别必要证据缺口并形成更好的问题解决结果，同时不增加幻觉、重复追问或过早结束？

LegalSkillGuard不微调权重。会话开始时，程序只按公开法域选择当前正式库中适用的`general + domain`技能文档，形成排序固定的会话技能包；该技能包从首个律师决策起在每轮提示中保持不变。Qwen自主决定如何运用。模型提交动作后，系统不会再按技能规则触发、替换目标或改写动作。控制臂与完整系统之间唯一的学习干预就是技能文档包。

## 顺序数据流

1. 自建128案全部属于顺序训练过程，冻结为8个块，每块16案。每案只属于一个块并使用一个预声明人格；每批四人格各4案。
2. 第一批从空库生成16×K4轨迹。每案共享一份只见开场的调查计划；K=4形成受控首问/第二问分叉，之后由冻结律师自主交互。离线评分形成组内优势，并确定性区分F（新客户事实）、G（外部证据缺口）和safe-stop三类可归因证据。
3. Luna只从合格证据簇提出候选或`NOOP`。候选须通过静态合法性、安全检查和来源见证；来源见证只确认文档来自合格的同状态正负分叉、建议方向与证据方向一致，不要求文档精确复制某个来源动作，也不参与在线律师推理。通过者成为`provisional`。
4. 从第二批起，把上一批`provisional`预先分配到适用的未见案件。候选治疗轨迹从首轮起看到“当前正式库 + 该候选”，共享对照只看到当前正式库；二者共享案件、人格、调查计划、模型revision和随机流。因技能提示在第一次策略调用前已经不同，允许对话从首轮开始分叉。
5. 同一批正常K=4产物同时用于本批TF-GRPO证据和上一批候选前瞻验证，不另跑逐候选验收集。候选按实际配对奖励、F/G/提问效率机制方向、有害尾和安全非退化决定`ACCEPT/DEFER/REJECT`。正式接收的技能从下一批进入活动库。
6. 安全正向但独立案件/法域覆盖不足的候选最多跨3个连续未见块累计；负收益、安全回归、重复实质负尾或到期不足则回滚。第八批只验证已有候选，不生成无法再被未见块验证的新候选。
7. 每批结果未知前固定8个哨兵案，形成“当前正式库－空库”的前瞻开发曲线。该曲线不进入教师、候选准入或最终显著性检验。
8. 技能库冻结后，官方DLawBench中文30案×4人格×seed42只用于现行协议的最终外测，不进入运行调试、模型/提示/门槛选择、教师上下文、候选选择或后续调参。当前冻结30案由另一工作窗口重新整备，此前未执行；运行产物扫描也未发现其case ID。由于它是公开基准，论文主张严格的held-out执行边界，不把它夸大为研究者不可见的私有盲测。

## 唯一干预与健康边界

- 候选对必须在第一轮策略调用前保持案件、身份、模型、随机流、调查计划和其他基础设施一致；技能文档包及其哈希必须是唯一差异。
- 每条现行轨迹记录`skill_delivery_mode`、`exposed_skill_ids`和`skill_memory_sha256`；每个决策回合记录同一暴露ID集合。任何旧`activated_skill_ids`或带`skill_id`的动作改写都会使轨迹失败关闭。
- 客户模拟器只理解律师问题、从有限client_belief中选择匹配事实并按人格披露；它不评价律师质量。语义裁判只评分已完成轨迹，不参与客户回答或技能生成。
- fallback、泄漏、哈希漂移、非法状态转换和不完整矩阵不能贡献训练收益。单个措辞不佳或候选被拒是正常实验结果，不自动改协议。

## 模型与统计角色

- `Qwen/Qwen3-8B`：冻结律师策略；同一快照的独立调用还承担只见opening的共享咨询规划、抗拒人格下四个披露信号分类和只见可见对话的memo。后三者均为各臂共享基础设施，不读取隐藏rubric，也不替律师评分。
- `openai/gpt-oss-20b`：权限隔离的客户闭集路由与离线语义评审；两种调用不共享提示或输入，但论文披露复用同一权重可能带来的相关偏差。
- `gpt-5.6-luna`：只生成候选，不评分、不验收、不接收技能。
- 确定性代码：状态机、客户回答渲染、来源见证、奖励公式、组内优势、前瞻门禁、哈希和案件聚类统计；奖励中的部分语义标签由冻结评审模型产生。

论文报告每批候选、`ACCEPT/DEFER/REJECT`、正式库规模、文档暴露覆盖、事实/证据缺口增量、每次提问事实收益、重复/过早结束/unsupported主张、DLawBench兼容指标和案件聚类区间。确定性的“唯一新事实/提问”是主终点，唯一事实总数、Fact Coverage和Resolution共同约束少问早停投机；最终效果结论只来自冻结库后的held-out官方30案外测。

批次唯一真源为`configs/data/main_training_batches.yaml`；实验与角色配置分别为`configs/experiments/main_experiment.yaml`和`configs/models/roles.yaml`。

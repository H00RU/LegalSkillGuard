# 主实验LLM角色决定

正式实验运行链只有三个唯一模型，但按输入权限拆成七种功能调用。状态、奖励公式、优势、技能文档渲染、来源见证、门禁、哈希和统计由确定性代码完成；Inquiry、Resolution与Fidelity等语义标签仍来自冻结评审模型，不能把“公式确定性”写成“全部评价无模型参与”。

| 位置 | 模型或服务身份 | 隐藏信息边界 | 作用 |
|---|---|---|---|
| 律师策略 | Qwen3-8B | 不看belief、court record、rubric | 追问、澄清、停止 |
| 咨询规划 | 同一Qwen3-8B的独立调用 | 只看opening | 生成组内共享可见调查图谱，不接受技能 |
| 客户事实路由 | gpt-oss-20b | 只看本轮问题和有限候选belief | 闭集选择至多一个可回答事实 |
| 披露信号分类 | Qwen3-8B | 只看已匹配belief、问法和人格 | 输出四个原子信号；确定性控制器决定答复 |
| 最终memo | Qwen3-8B | 只看可见对话 | 各实验臂共享写作器 |
| 离线语义评审 | gpt-oss-20b | 可看冻结rubric与完整轨迹 | 结构化事实、问题、解决与grounding标签 |
| 技能教师 | gpt-5.6-luna | 只看合格训练证据簇 | 每簇提出一个最小结构化文档候选或NOOP |
| 语料构建 | 当前gpt-5.6-sol high会话 | 只看最高法训练来源 | 逐案重建、核源和语义复核 |

技能教师不是TF-GRPO律师，也不修改Qwen权重。它不能看下一未见验证块、官方30案或实验臂结论，
不能直接写活动技能库。候选先由确定性静态门与来源见证确认其确实来自合格因果对照，再由后续连续未见块的配对效果与安全门决定是否正式接收；来源见证不要求技能精确复制某个旧动作。在线律师只读取固定会话技能文档，系统不作答后改写。每批最多新处理
两个行为机制不同的合格证据簇，因此第1—7批理论新增教师调用上限为14次；延期候选另占最多6个并发provisional容量，不得挤占每批两个新提名；第8批不调用教师。用户已于
2026-09-06把项目级累计硬上限授权为200次；全部调用仍受跨进程共享硬账本约束，预检以实际保留量核算余量，
不在文档中硬写易漂移的历史计数。失败调用计入账本，缓存命中不重复计数，禁止fallback教师；正式预检按尚未
完成的候选来源轮计算最坏新增调用，而全新运行最多需要14次，避免恢复运行把已完成轮重复计入预算。

客户路由与离线评审复用同一冻结gpt-oss-20b权重和服务，但不是同一个决策：二者使用隔离提示、
输入权限、结构schema及运行缓存。客户路由看不到评分rubric、法院记录、技能和实验臂，不能评价
律师表现；离线评审不参与客户答复。这样不增加外部供应商，同时避免被研究Qwen既提问又解释客户
有限认知。

同权重复用仍可能产生相关模型偏差，隔离接口不能把它证明为统计独立。论文因此以实际披露fact ID计算的
“唯一新事实/提问”作为主终点，以唯一事实总数、Fact Coverage和Resolution约束少问早停投机；
judge-heavy指标用于兼容比较和配套解释，不单独承担全部效果归因。

Qwen3-8B固定revision为`b968826d9c46dd6066d109eabc6255188de91218`；实际本地快照、权重清单、
提示、schema、解码参数和服务身份必须进入run绑定。gpt-oss-20b只在结构完整性、单调性、法律方向、
事实反转和unsupported主张资格均通过后评分；失败关闭，不换规则假分。

本地单裁判不等于DLawBench官方多供应商面板。论文必须披露模型revision、资格结果、确定性安全指标、
配对效应与95%区间；当前没有法律专家标注资源，研究者能做的盲化事实核对只能作为误差分析，不能冒充
法律专家一致性。未经官方评审面板也不能声称直接复现官方排行榜。

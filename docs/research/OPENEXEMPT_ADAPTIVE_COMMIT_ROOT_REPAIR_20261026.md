## Revised learning rule

Keep exactly the existing complete current/prior native EC/EV, complete-output
F1, negative/unscored-claim and invalid-count gates. No tolerance is relaxed.
Construct the same public-dependency components and exact-wire mixed library.

For each teacher proposal, evaluate these existing alternatives:
1. The complete proposed bank, if the full gate admits it.
2. The dependency-composed bank, if its component and full gates admit it.

Use all paired seen TRAIN sources, weighting sources equally within EC and EV.
For each feasible bank compute native-F1 improvements over the same actual parent.
Choose lexicographically by the smaller of the two task gains, then their mean.
An exact tie selects the complete proposal. This is a TRAIN selection objective,
not a new TEST endpoint or a claim of improved legal correctness. The alternatives
reuse already recorded native answers; selection adds zero generations and no
semantic judge. Record both alternatives, the objective, chosen mode and genuine
local decisions; joint admission never relabels failed local gates as passed.

A completely admitted proposal ends unresolved-edit refinement. Compare actual
task projections to avoid a library-list-order difference masquerading as an
uncommitted edit. The existing limit remains at most two proposals per batch,
not a requirement to spend two calls or to force library growth.

Every source named in any bounded feedback-witness list is mandatory in the
next teacher packet. Keep all current sources. Fill a16-source historical
background budget with context witnesses, actual harms and parent failures.
If the mandatory union is larger, expand only to that union; never silently
filter a declared witness. All sources remain already-seen TRAIN, with both
original task views and unmodified released targets. Replay still covers ALL
seen sources. Validate actual packet size against the existing hard transport
limit; never clip a record or silently revert to an old packet.

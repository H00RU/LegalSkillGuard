## Reason and unchanged comparison

The declared text-analysis experience control uses the same direct actor as
the main method. Its first complete learning run should inform method
development before investing in all remaining independent repeats. Native ACE
retains its own generation prompt and outer response wrapper, whose cold-start
difference is already observable without memory. Completing a common-actor
adaptive control earlier strengthens the comparison without selecting TEST
outcomes or changing any method's budget, feedback, actor or scoring policy.

All16 final arms, three learning seeds per main/ACE/text method, two single-seed
learning ablations, ten primary EC/EV comparisons and four secondary comparisons
remain planned. No early text result replaces its complete128-source run or
permits choosing a favourable learned bank. Method optimization is still
TRAIN-only. A changed main method requires its corresponding independent
repeats and ablations; completing an older run does not lock the main method.

## Minimal implementation change

The text learner previously required at least eight completed learners as
operational predecessors. Its algorithm neither reads their banks nor uses
their predictions or feedback. The unnecessary count-only dependency is reduced
to the two current completed learners, with the existing uniqueness, natural-
completion, no-failure, terminal-preservation and canonical exclusive-lock
checks retained. The coordinator still waits for the queued static evaluation
before starting the first text profile; the text learner does not consume
static evaluation results. Later text repeats also retain all actually preceding
learning run IDs, but do not import their artifacts into skill construction.

The analyst, file edits, ordered merges, final translation, capacities, source
first-forecast timing, teacher model, decoding, final report-only TRAIN replay
and TEST entry are byte-unchanged. This is not an algorithm variant or a stronger
claim of author-code replication. A targeted read-only validation of the
amended predecessor declaration suffices; no model or broad qualification run
is needed.

Every new profile has a new Run ID dated20261023 and a new immutable source
manifest that binds this amendment. Superseded, never-started profiles and their
source archives remain intact. No currently bound training dependency is edited
and no extra model, queue layer or fallback is introduced.

# EV定向优化：目的、预算、停止条件与成果保护

## 目的

在保留v16完整论文与实证成果的前提下，解决EV在B3–B6候选无法产生可提交收益的问题。
研究对象继续为OpenExempt EC/EV、固定Qwen3-8B、128个TRAIN来源及八批在线技能学习。
本轮不更换法律任务，不重做路由，不增加fallback、数值求解器或冗余中间架构。

既有事实：B3–B6四个EV提案的当前原生F1均低于各自父库；B3历史EV从90.84%降至82.92%。
这些是已遇TRAIN重放分数，不是论文TEST成绩。它们提示应优先区分内容、执行与干扰，
不能把未准入简单归因于阈值过严。

## 原版保留

v16的源稿、四份Word/PDF、完整补充包、B1/B8库和原预测均保持原版本。
GitHub备份分支最终收据提交b1e0ba0d8fa363e379f2c3ee4ea7f46284f5b98b保留；
旧两文件系统交付归档继续保留。生产代码如需改变，先额外保存相关源文件与配置快照。
新分析、验证、训练各使用新路径/Run ID。当前论文主表不提前改写。

## 第一步：已有TRAIN记录的内容与执行归因

仅读取TRAIN源案例、标签、现有父答/提案输出、编辑和教师请求。检查：

1. 原先正确的金额/条款在哪些情境被新文本破坏。
2. 父技能已写对而执行器未执行，还是规则/前提本身确有缺口。
3. 适用范围、共有/债务人数、整项资产金额、分类及法定上限之间是否混用。
4. 格式无效、输出长度上限是否主导均值下降，不能把这类情况伪装成纯金额错误。
5. 教师是否实际看到相应错误及已有失败反例，是否误把执行失误当成规则缺陷而重写过广。

直接生成逐案错误迁移与少量可追溯实例，不重复跑全量资格测试或重算已经核验的整张TEST表。

## 第二步：有界TRAIN验证

只有已有材料无法判定候选可执行效果时才调用模型。验证前固定假设、父库、案例列表、
评分、模型与停止条件。32个来源均为已经释放标签的TRAIN，不新设验证集，也不读取TEST
进行候选设计或挑选。使用公开法域/来源顺序固定覆盖，不按测试错误选择案件。

- 最多两个EV内容/教学假设。
- 最多两次教师调用，使用现有教师及推理配置，不另购API或引入新模型。
- 父库/候选配对，最多128次新增EV生成；完整请求相同的父答可按现有身份规则复用。
- 累计最多一小时GPU执行。上限是资源预算，不是证明统计显著所需样本量。
- 原生F1、完整输出F1、金额错误、漏列、额外预测及格式失败共同报告。
- EC投影必须保持完全相同，公开接口、解码、评分器与既有训练准入均不变。
- 不靠减少申报掩盖错金额，不以人工填写答案、来源ID或测试实例建立技能。

若两候选均未形成可解释收益、明显牺牲覆盖/其他适用情境，或资源上限到达，则停止本轮
候选扩展，不自动启动整轮训练。若发现协议或实现错误，停止对应验证并保存，不补造输出。

## 第三步：条件性完整训练与冻结评价

训练侧有实质收益且代码/信息流符合预定方法后，用户已授权启动一次新Run ID的完整训练：
空库起步、128来源、八批，每批EC/EV原定机会，保存真实首答、技能变化和准入原因。
不从旧B8续学后当成新八批，不把旧EC终库拼接到新方法，也不要求不同来源批次严格单调。
发生明显协议错误或系统性负迁移时及时停止分析，不盲拖完再检查。

完成后冻结实际B8及该次自身B1，在不变的共同条件下评测，保留全部输出。新方案是否进入
论文依据方法与证据完整性，不能通过反复看TEST选择最好种子或早期库。既有TEST已被观察，
后续不冒称全新盲确认。

## 既有实验如何复用

| 材料 | 处理 |
|---|---|
| 空库、静态库、已验证外部库的预测 | 共同数据、评分、执行器、接口、解码不变时复用 |
| 新主方法B8 | 必须新训练后冻结评测 |
| 新主方法自身B1 | 必须用该次真实B1重新评测，不能借用旧版B1 |
| 配对差值和统计区间 | 使用新主方法逐案分数重新计算，旧主表/区间保留 |
| 消融/策略控制 | 修改影响其共享教学或对应组件时需新版重做；未重做的只能是旧版参照 |
| SkillCommit | 先判清TRAIN侧检索及适配一致性，确有错误则修正并重评受影响部分 |
| 独立构建重复 | 先固定目的、次数与预算；超出本轮授权时集中询问，不无限追加 |

本协议不预先承诺EV必须全面超过控制或保证期刊录用。成功标准是有真实可解释的EV改进，
保留EC学习路线及已有成果，且主张、原始记录、比较条件和论文表格一致。

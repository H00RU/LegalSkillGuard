## 共同输入契约，所有臂一致

- 原始 Task.prompt 及7个组件完整保存在输入packet，不更改法律标签或数值。
- 实际推理保留原文 instruction/meta_instruction/statutes/solved_steps/facts，
  每一法律/事实组件字节不变。仅移除格式专用 response_format/format_reminder。
  读过其全文：只是FINAL ANSWER包装、字典结构和虚构汽车示例，没有另一个法律条件。
  类型结构由实际API schema及不含实体/数字示例的通用输出契约给出。
- 历史技能先作为背景，当前案件最后；原本的“先问案件，最后一条user再贴技能”
  容易让弱模型偏离当前案情。法律资料在事实之前，实际Facts靠近最终输出契约。
- actor input 同时记原始prompt SHA和实际active input SHA。教师同样只接通用
  实质任务说明及真实API schema，不再投递格式例子的假案情。
- 没有按DeLorean名字写过滤器，没有事实提取中间模型、硬路由、输入补全、答案修复、
  格式失败fallback或新模型。当前案若真的包含同名车，Facts完整保留，照常作答。

这是统一提示渲染协议，不是新法律任务；benchmark原指标和完整输出补充指标不变。
不得把新数字直接和别人原始prompt配置的SOTA声称同协议胜出；强空库、冻结库、
在线库及后续成熟经验方法都用同一渲染。也不把本修正包装成论文核心创新。

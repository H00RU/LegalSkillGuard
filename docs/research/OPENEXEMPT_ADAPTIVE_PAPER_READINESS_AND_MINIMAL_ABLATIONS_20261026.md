# 新版论文主张、测试优先级与最小消融

2026-10-26。研究决策记录，不改写v0.23结果，不改变正在运行的380项科学绑定。

## 判断

已有工作量足以组织完整的应用研究论文。面向SCI三区及以上的投稿具有现实基础，
但期刊分区不是某个F1分数对应的录用线。当前最需要补强的是新版机制的独立价值及最终
效果，而不是继续增加模块、法律任务或消融数量。不能以一次运行或一批好成绩承诺录用。

## 论文问题与贡献边界

问题：参数冻结的小模型如何把分批法律经验转化为可复用程序，同时保持法条适用EC和金额
估值EV的质量。当前研究对象是OpenExempt法律规则适用，不泛称覆盖所有法律推理。

新版核心候选贡献是**证据驱动的技能修订提交粒度选择**：在保持原准入约束时，用相同
已见TRAIN重放比较可行的完整提案与依赖分量组合，按较小任务收益、再平均收益选择。
选择复用已经产生的请求与回答，不增加律师生成。整段训练仍有真实重放成本，不能把
选择步骤零新增调用写成整个学习零成本。

教师反馈见证完整送达是这一机制可靠运行的支持条件，不单独包装为重大理论创新。
标签教师、技能文本、冻结模型和重放本身都不是本文原创。

最近邻核查：

- [ACE v3](https://arxiv.org/abs/2510.04618v3)研究不断积累和修订的上下文playbook。
- [Trace2Skill作者仓库](https://github.com/Qwen-Applications/Trace2Skill)通过并行轨迹分析和分层整合形成可迁移技能文件。
- [SkillCommit v2，2026-10-14](https://arxiv.org/html/2608.15165v2)已经研究冻结执行器、OpenExempt和重放验证的技能提交与拆分。
  因此不能把这些组合当作本文独有；需要证明本方法的多任务收益选择及修订分量控制为何有用。

SkillCommit为每种任务类型构建独立库；本项目同一库的任务投影与公开法律情境依赖决定
修订分量。这个设计区别是可检验的贡献候选，不等于已证明更好。也不声称技能组合存在
尚未验证的非加性交互；现有组合校验要求每个实际请求精确对应已观察过的完整请求。

## 已有实证与剩余证据

原正式研究已完成128 TRAIN来源、八批学习和128 TEST来源的共同八条件评价。
EC/EV是同一来源的两种相关任务视图，不是两个独立法律数据集。

原TEST：主方法EC/EV87.43/86.18%，强空库64.08/61.88%；Whole93.03/81.32%，
Task-local93.25/83.35%。这些数据已证明学习库有实际效用，也明确指出新的机制应当
解决什么：不能以赢空库代替对简单强控制的比较。所有原行保留，不因更换贡献定位删去。

原正式构建及共同TEST合计7610次真实8B生成，808次成功教师响应、809次教师尝试。
该总数不包括其他历史探索、退役串行控制或当前新版运行；成本本身不是科学贡献。

新版B1：五条1551-token技能，完整提案已发布；同批重放EC/EV86.11/71.41%。
同一原始请求重建的合法分量备选为86.11/68.98%。这解释一次实际选择，不代替泛化实验。

新版B2新来源首答：技能EC/EV86.75/75.22%，同案空库63.53/61.67%，分别+23.22/+13.55pp。
教师实际收到此前32条已发表重放回答、本批32条首答及全部64份原训练目标。
因为B2使用的就是B1库，超过固定B1的持续进化证据从B3开始。
见[原始送达核验](../../artifacts/research/openexempt_legal_scope_20261020/Adaptive45_B2_new_source_firsts_and_actual_teacher_prior32_current32_gold64_20261026.json)。

## 主测试与复用

先完成当前完整八批及其真实发布，冻结唯一末库，再补原128案固定基准上的新版预测。
同时评价新版自身B1，以区分“学会第一份知识”和“后续经验继续带来增益”。
空库、静态、ACE、Text和旧控制的原预测在模型、接口、解码、评分及来源均相同时直接复用。
不重新构建这些库，不混用不同案的主方法与对照均值。沿用
[固定基准补充方案](OPENEXEMPT_FIXED_BENCHMARK_SUPPLEMENT_AMENDMENT_20261026.md)。

最终看EC/EV原端点、完整输出质量、同来源差值及其不确定性；保留无效输出和全部案件。
无需每个训练批次单调上升，也不以技能条数增长替代效用。新比较的统计族须在新评价前绑定，
不把旧表的多重比较校正直接当成新行的统计检验。来源重采样不冒充独立学习重复。

## 哪些消融需要补跑

| 内容 | 处理 | 论证职责 |
|---|---|---|
| 强空库、静态、ACE、Text | 复用已有库及相同协议测试预测 | 实际效用与外部经验方法比较 |
| 旧Whole、Task-local | 保留已有成绩 | 与原简单强控制比较，不改称新版单因素消融 |
| 新版自身B1 | 不再训练，只补冻结测试 | 后续经验是否超出初始技能 |
| 新版固定整库提交 | 必要的新匹配控制之一 | 动态选择是否优于一律提交整库 |
| 新版固定依赖分量提交 | 必要的新匹配控制之二 | 动态选择是否优于一律提交分量 |
| 其他学习种子或重复 | 仍按用户决定暂缓 | 后续再补跨学习运行稳定性 |

两个新控制应保留新版完整见证反馈、原任务与训练顺序、教师、同一四工作线程执行条件、
4096-token库上限、最多两次提案和全部原准入约束，只固定提交策略。
旧Task-local按EC/EV整体拆分，不等于按公开法律依赖分量拆分，不能直接更名复用。
旧控制的教师见证送达缺陷也说明其不构成新版严格匹配的单因素消融。

完整接纳后的停止条件须对所有新控制使用相同的任务投影语义，不能因为库列表顺序差异
多花一次教师调用。当前训练绑定源码不热改；未来控制在各自启动前冻结修正与配置。
固定的是最大提案预算，不强制每批花满两次，也不声称实际生成次数相等。

同时统计两种实际提交的次数、收益和后续表现。如果八批实质上总是选择同一种策略，
则不能仅凭存在两段代码就宣称动态选择产生了优势，需据匹配控制判断其实际贡献。

相同候选及其原始回答可用于零生成的选择机制分析。但不同策略会改变后续父库和教师，
因此离线重选不能冒充完整控制策略的最终学习结果。

## 执行顺序

1. 当前完整八批继续，优先看B3以后的新案首答、相对自身B1的增益和真实技能更新。
2. 新版末库及自身B1冻结补测，复用原比较行，判断核心效果是否值得进入定稿阶段。
3. 用两个新匹配控制补足提交策略的因果证据；不因当前论证记录提前并发启动额外学习。
4. 据实际最强证据修改论文主张与主表。最终投稿再处理此前暂缓的重复和其他增补。

的贡献推进，不堆额外模块；必要比较、准确数字和借鉴来源保持完整。

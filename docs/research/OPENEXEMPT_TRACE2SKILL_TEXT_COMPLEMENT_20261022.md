# 补充外部对比：Trace2Skill法律文本任务适配

2026-10-22，TEST仍未暴露。本文档固定补充方法及实现边界，不修改正在运行ACE的
377文件或既定六次后续学习。此前已观察主方法TRAIN和旧ACE开发结果；不冒称整个
研究事前注册。选择此方法不是基于其在本项目的实测输赢，目前没有该方法成绩。

## 为什么选，以及论文可称什么

[Trace2Skill v5原文](https://arxiv.org/html/2603.25158v5)以逐轨迹提出修改、对共同
初始技能分层合并、统一应用为核心，补充ACE在线playbook路线。原文数学任务的
creation包含No Skill初始化。作者仓库固定提交为
`3d0b52a140f002a512930252b613c49048f7d5ac`，已经实际读取combined入口、
`parallel_evolving_agent.py`的原始状态/MAP/分组/REDUCE/应用流程、success混合
结构和LLM错误分析提示；不是只看README。原作者更强的ReAct分析能检查文件及
验证修复，不能把它和单次日志总结说成一样强。

当前共同法律接口是无工具的直接EC/EV回答，没有表格工作区。补充方法明确命名为
**Trace2Skill（文本分析、OpenExempt适配）**，不是完整工具式作者实现的原样复现。
采用逐轨迹文本分析并给原TRAIN verifier及正确目标，避免仅凭日志猜错误；教师
仍为既有gpt-5.6-sol/high。方法差异和额外监督在主表/附录明确列出，不把这一
变体的输赢扩展为原生ReAct版或全部技能方法的输赢。

实现是依据论文独立编写的`trace2skill_text.py`与`openexempt_trace2skill.py`，没有
复制未核实整体许可的作者runtime或原提示，也不调用我们主方法的更新/准入函数。
借鉴和原始机制继续明确引用，不将它们记作本项目创新。

## 完整构建协议

1. 同固定128 TRAIN来源181–308、256个独立EC/EV任务，原8批顺序不改。每个学习
   seed45/145/245从空库生成自己的完整256条原生轨迹，不导入主方法/ACE回答、
   技能或教师响应。全部源首答保存后才释放这些标签供分析。
2. 一份只有metadata和空标题的SKILL.md作为不变的修改坐标，不含法律先验。
   每条自己的实际轨迹独立提出修改或明确空修改；成功和失败均保留。所有分析
   面向共同初始文件，不把前一分析结果变成下一分析的父技能。给完整本案公开
   消息/schema、自己的原始响应、原评分和TRAIN目标，没有未来案或TEST反馈。
3. 采用作者实际的有序平衡分组，名义merge batch size5；小尾组并入先前组，
   因而个别组可为6，而非声称每组硬上限5。256条修改经过51、10、2、1次合并，
   最多四层64次。每个输入修改都进入相应组，不按得分挑选或因并行返回顺序换组。
4. 一次计划内translation将最终合并修改定位为准确的初始文件编辑，再一起应用。
   保留8种文件/段落操作、独立原始目标及reference/link原子性。允许SKILL.md和
   最多5个纯文本reference，根文件至多500行，完整序列化库上限8192 Qwen tokens。
   文件全部原样预载到共同actor接口，不只给文件名，不进行答案路由或语义检索，
   不允许脚本、隐藏数值执行、第二模型或额外嵌入服务。
5. 修改结构、位置、容量失败就保留并停止；没有静默丢冲突、选第一修改、改格式
   重抽、回到旧好库或答案修复。原作者实现存在的某些输运/格式恢复路径不照搬，
   因此不声称作者默认失败处理完全相同。计划内translation不是失败后的重试。
6. 完成库发布后，在同256 TRAIN任务上完整重答一次，仅报告拟合和损害，不准入、
   不再修改库、不选最好seed，也不把这些重答计为新案或TEST。采用全部三次独立
   构建库而不是作者README所述的按TRAIN选择最佳seed，差异如实披露。

每次至多512个实际8B请求，完全同请求的运行内复用另列；256次分析、64次合并、
1次translation至多321个教师响应。保留既有一次capacity无结果重试，最坏642
输运尝试。不是等实际训练计算或等库容量比较，原始请求、失败、token和墙钟齐报。
不把构建中的并行归纳硬改成八次在线更新曲线；其最终库才进入正式末库对比。

## 执行顺序与隔离TEST修订

当前ACE45继续自然运行；whole_bank、first_commit、主145、ACE145、主245、ACE245
六个已冻结任务不改、不抢占。补充方法三次构建在其真实完成和双盘保全之后，仍
用canonical训练锁顺序运行。配置的未来累计上限以既定6581为起点，加642得到
7223、7865、8507；这是尚未应用的预约天花板，不是当前3349账本的用量或扩额。
不提前启动、不部署新模型、不做一轮全量性能资格测试。

实现与正式三份配置通过最小结构检查并冻结后，本补充方法进入最终比较矩阵。
最终分析的主要比较族须相应包含EC/EV对该三组库的配对差，共从8项扩大至10项；
四项机制消融次要比较不变。保留旧分析计划，另存修订，不改活跃学习绑定。
所有必要构建、真实末库、最终方法矩阵及隔离评测器仍须首次TEST预测前齐备。
如最终无法忠实完成或运行失败，不把缺失填零或挑最好成功库，也不能悄悄从矩阵
消失后声称胜全部对照；先明确保留失败和缩窄实际支持的结论。

本补充不替代最近邻SkillCommit的引用/机制比较，不据其他模型、官方Advanced
分数与本自定义TRAIN横比SOTA。原EC/EV、原标签、源案集合与共享推理预算不变。
师兄paper-ideation用于补足机制覆盖，paper-experiments-appendix用于公平对照、
实际成本、重复和不超过证据的归因；不是为了凑方法名单或预定胜出。

# Fixed-content source-bound skill-delivery intervention

This is a retrospective TRAIN mechanism experiment, not a validation split,
unseen TEST, final-method result, or independent learning repeat. The existing
third formal B8 candidate 1 was rejected under its original replay gate. Its
complete unchanged legal skill content is held fixed here; it is not substituted
for that run's actual published final bank. Both unsuccessful outcomes remain.

## Question and fixed contrast

Does loading existing legal procedures as source-bound default guidance improve
the frozen 8B executor's use of exactly the same learned content? The old condition
is the actual saved passive user-message JSON response. The new condition places
all unchanged applicable skill IDs, public scopes, applicability, procedure and
exclusion/pitfall text in the system message. Facts, supplied statutes and public
solved steps remain authoritative. It does not inject case answers, new legal
rules, a solver, model weights, extra routing, retries or fallback. Role, headings
and applicability instructions form one declared delivery-contract intervention;
this is not a role-only ablation.

The same public task/jurisdiction filter, case input, citation/asset-reference
catalogues, answer schema, model process, seed45, 8192 output limit and four-worker
dispatch remain fixed. Empty-library messages/schema are byte-identical. The new
teacher feedback implementation is present but unused: zero teachers in this probe.

## Source selection and cost

Use the original 128 TRAIN sources, without inspecting new outcomes. Group by
public allowable namespaces, order each group by source ID, and take indices 0,
(n-1)//3, 2*(n-1)//3 and n-1. The bound config records all five groups and 20 IDs.
Evaluate independent EC and EV for each: 40 new native requests. This bank was
developed on all128, including this panel; do not claim unseen-case generalization.
Old responses are verified exact historical wires; none is regenerated or selected
by quality. Zero new baseline generations, zero teacher calls. All80 old/new
responses are saved before any new grading. Recomputed old scores must exactly
reproduce their original stored scores. Length/invalid responses are retained.

## Predeclared adoption and follow-up

Use the unchanged native EC/EV scorer plus complete-output F1. Both families must
be nondecreasing on native and complete-output F1; invalid-format and negative or
unscored-asset claim counts must not increase. The equal-family native F1 gain
must be at least0.02 (2 percentage points). Report five public strata, all paired
gains/harms and actual tokens; do not require every case or stratum to improve.
Do not loosen this rule after seeing outcomes or search multiple new formats.

If and only if this gate passes, the prebound fourth optimization config can be
frozen and started on all128 TRAIN sources/eight chronological16-source batches.
That learner starts with empty bank and empty request cache, importing no probe
responses, bank or teacher proposals. It combines outcome-feedback repair and
the delivery change, so it is not an independent repeat or single-factor ablation.
On failure, preserve the result and do not start that long run blindly.
No TEST, matched-control build or user-deferred extra repetition is launched here.
Freeze actual code/config/provenance before generation; dual-preserve source and
terminal outputs. A process exit with success is terminal, not a restart trigger.

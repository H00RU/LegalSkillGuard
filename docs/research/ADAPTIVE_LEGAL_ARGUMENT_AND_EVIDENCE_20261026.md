# Current argument and evidence focus

26 October 2026. This is the working research argument, not a replacement result table.

## Main question

How can a frozen small language model accumulate reusable legal procedures that
improve both statutory selection and valuation as it encounters new source cases?

## Mechanism to establish

A legal skill revision can have useful joint effects across tasks and legal
contexts. Adaptive commitment compares the admissible full proposal with the
admissible dependency-composed proposal on the same seen-source observations.
It chooses balanced EC/EV improvement under the existing retention checks.
Witness-complete teacher packets keep the selected replay feedback connected to
its original source facts, targets and actual parent answers.

## Evidence chain

1. **Practical value of learned legal procedures.** The completed original study
   provides the fixed-benchmark comparison: native EC/EV F1 is87.43/86.18% with the
   learned final library and64.08/61.88% with the strong empty reference.
2. **Reason for adaptive commitment.** On the original B2 proposal, saved paired
   TRAIN outcomes give minimum-task gain4.39pp for the admissible complete proposal
   and0pp for the actual component publication. This identifies a recoverable
   update restriction without requiring additional answer generation.
3. **An actual adaptive publication.** The new B1 request delivered16 sources and
   both task views to gpt-5.6-sol. One fresh teacher response produced five EC/EV
   records covering Federal, Pennsylvania, Oregon, Illinois and Arizona. The full
   proposal was published at1551 tokens. Seen-source replay EC/EV F1 is86.11/71.41%,
   versus59.31/63.86% in the original empty first forecasts. Reconstructing the
   admissible component alternative from the exact original responses gives
   EC86.11% and EV68.98%. The actual selection retained2.43pp of native EV F1 at
   equal native EC F1. Both options passed the same global retention checks;
   their complete-output audits are preserved in the linked B1 record. Selection
   required no additional answer generation. B2 first forecasts now measure the
   published library's utility on new source cases.
4. **Continued evolution.** The current full eight-batch run supplies same-case
   empty and fixed-own-B1 contrasts alongside evolving first forecasts. B3 onward
   is the informative stage for change beyond the first learned library.

## Experiments and their argumentative role

- Full-stream first forecasts: show utility while experience accumulates.
- Same-source empty comparison: isolate the contribution of supplied learned guidance.
- The new learner's fixed B1 comparison: distinguish continued evolution from acquiring an initial prior.
- Logged joint/component decisions: explain which feasible updates the selection rule preserves.
- Delivered witness and skill records: connect the implementation to the actor/teacher behaviour.
- Fixed-benchmark supplement after method/bank freeze: compare the final library against the preserved common-case references.

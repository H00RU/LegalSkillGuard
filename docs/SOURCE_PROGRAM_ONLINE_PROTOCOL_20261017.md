## Learned artifact and actual execution

One differential editor maintains records by CREATE/UPDATE/DELETE/MERGE/NOOP.
Named inspection fields stay readable; source_queries use the EXISTING attributed
ScienceClaw-derived literal all/any/none phrase and explicit-neighbour API.
Each skill has1..8 queries because its function is executable acquisition, not
a silent prose-only record. There is no prescribed skill count/topic quota.
relation_if_established is null: the artifact does not encode conditional
E/C/NM verdicts. Descriptive instruction truth/usefulness is not host-certified.

Every published program runs on original source text/spans without case routing.
Actual query arguments, all direct/context indices and literal returned clauses
are supplied beside the original public question, together with full named
inspection guidance. Repeated literal hits are quoted once per question, but
individual query receipts remain. Empty results stay empty; no replacement
query or unseen fallback is executed. The full contract remains present.
Source locations are fallible leads; the frozen lawyer can reject all hits and
cite any other original span. The host never selects legal evidence or labels.

All arms share the same4 already-fitted past-prefix ordinary evidence tools,
identical source-membership models/parameters. No new CPU fit/query coefficient
or calibration, no learned semantic router, critic, eligibility gate or graph.

serving-tokenizer tokens; every full request must leave8192 within32768. Never

## Evaluation, stopping and unachieved paper requirements

Report complete-batch matched fixes/damage, NN/NM labels/joint, true evidence
gained/lost, misses inside/outside ordinary candidates, source-query coverage
and actual use, CRUD/NOOP, token/time costs and retained failures. After-fit
also updates the ordinary tool; it is not a pure skill or transfer effect.
Different source difficulties need not yield mechanically monotone raw scores.

An operator may stop the WHOLE development trial at an artifact-safe boundary
after complete B2/B3 matched comparisons show no positive target effect or
clear systematic damage; save in-flight calls and mark incomplete. This is not
per-skill admission, best-bank deployment or a replacement for final reporting.
No scoring selected contract subsets, endpoint peeking, or retrying failed runs
under the same ID. Independent learning repeats, mechanism ablations, equal-call
review and fair mature experience-learning comparisons, untuned formal TEST
and reproducible model access remain unachieved Goal requirements.

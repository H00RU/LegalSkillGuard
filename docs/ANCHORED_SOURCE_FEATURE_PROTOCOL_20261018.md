## 唯一修正：普通最终分数上的源条件log-odds校正

普通词模型/校准器仍按原全部TRAIN数据拟合，程序不进入它的训练矩阵。
同一调用的最终成员分数为：

`p_skill = sigmoid(logit(p_ordinary) + source_features @ beta_h)`。

每个原命题有由训练学习的beta，无新增全局截距。使用当前全部程序及公共scope，
不使用效果准入、删除失败或选择最好库。没有另一语义模型、路由、规划器或LLM调用；
运行时是原scorer加一次点积，不是推理出错后的替代路径。
程序执行失败、非法值或非法概率都停止，不用普通结果替代。
零校正的数值分支只保持上述恒等式的浮点精确性，不读取效果、正确性或不确定度。

若某位置所有适用特征为0，则校正项严格为0、分数等于原普通分数。
保证仅限该辅助工具的分数，不保证命中特征区域不退化，更不保证后续整段律师回答不变。

beta以原TRAIN全部成员目标和真实合同外折普通**最终概率**的Bernoulli负对数似然
加L2项拟合，C沿用10，原.5阈值不调。不是对近99%拟合分数再次拟合残差，也不是
先改first-stage logits再交给从未见过这种输入的旧校准器。
在训练18内，固定原5折按完整合同排除，每折拟合既有普通scorer并预测排除来源，
再以这些训练用预测拟合beta。完整普通模型用全部18。没有新验证集或官方DEV/TEST，
不拿外折成绩选库/超参。程序先由全部18归纳，外折只让普通基分数不看对应来源，
**不是整个程序归纳算法的独立验证或无泄漏确认性估计**。

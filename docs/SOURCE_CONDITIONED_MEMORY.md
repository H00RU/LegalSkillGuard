## 技能内容、实际交付和原文操作

每条技能保留`when / inspection / relation_if_established / evidence_requirement`，
增加两个字段。`source_triggers`是正向事实短语的OR-of-AND组：同组短语都须出现在
完整合同中、不同组任一匹配即可；不要求同一条款。沿用现有小写连续word-token及轻后缀匹配，
不是语义推理，对同义词和部分词形并不等价。教师须学习宽而可复用的事实资格条件，
不能把旧证据成员查询或完整Gold原句直接当适用条件。不得空组、缺失分支补偿或故障fallback。

主库完整保留，只交付匹配技能的四个语义字段、ID和公开命题绑定。匹配仅控制交付，
不建立法律条件；不匹配不等于NM，`null relation`也不是NM。律师始终读完整原文，
自行判断17个关系和最终原SPAN集合，无主机法律裁决、强制引用、答案修补或额外推理轮。
主库hash/数量、逐条真实触发、交付投影hash/ID/token和实际操作分别记录，
不能把“库里存在”或律师自报ID当作真实使用或因果效用。

`source_operations`允许空列表或`list_preamble`。它从该技能公开命题的同一普通工具候选出发，
只对括号/字母右括号列表标记逐条向前查找：遇完整句末停止，跳过前面的列表项，
最近未完整句末的非列表片段作为**可能**引导语。规则与已完成的来源结构审计一致，
不按合同ID、命题、Gold或当前答案特调。不要求冒号，不把数字章节全当列表，不自动并集。
错误链接如实交律师选择，完整源保留，提示定位不是依赖证明或引用命令。

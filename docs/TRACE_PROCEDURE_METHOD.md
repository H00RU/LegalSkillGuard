# 实际执行轨迹辅助的法律程序记忆

2026-10-15，在本Run生成前固定。研究候选，不是已证明的修复、论文主成绩或已有方法复现。

## 动机与不重复的边界

查询记忆B2/B3没有整体胜同标签普通工具；改为最终概率损失亦无净F1收益。
法律步骤交付诊断只在已见来源部分改善，相对教师新2合同依据F1下降；不能直接认定有效。
历史逐命题、原句回执、Gold片段和成功示例已有完整负结果，本Run不重复那些表示干预。

当前教师观察只有实际最终答案、短理由、原Gold和工具记录，没有本地8B实际reasoning_content。
ReasoningBank作者实现会从执行器think/action轨迹提炼成功/失败记忆：
[固定归纳代码](https://github.com/google-research/reasoning-bank/blob/ed80611788292ea739f1effd31f16c53823b8a0d/WebArena/induce_memory.py)，
[固定记忆提示](https://github.com/google-research/reasoning-bank/blob/ed80611788292ea739f1effd31f16c53823b8a0d/WebArena/prompts/memory_instruction.py)。
本Run借鉴“让教师观察实际执行过程”这一机制，不复制作者环境、检索、模型或宣称canonical复现，
也不把这条已知机制算原创。本地模型自述不保证忠实，新增信息是否有价值需实测。

## 主链路

1. 同一冻结Qwen3-8B、thinking、T.6/p.95/k20/seed45，单次8192输出/32768上下文。
   每合同仍共同作17个原命题的三分类和完整原SPAN成员选择。不换任务、律师权重或模型。
2. 律师收到完整原文、完整已发布程序技能，以及普通外部监督工具的p>.5成员候选/原分数。
   所有工具条件共享同一份同标签TF-IDF/LR/LightGBM模型，包含NM负例；不再拟合技能查询附加权重。
   此工具是有监督参数学习，律师仍冻结，不冒称纯文字或纯轨迹无标签学习。
3. 完整技能在system中实际交付，公开hypothesis_ids仅解释适用范围，所有指导同时可见。
   无固定技能主题/数量、强制核查输出、初答复核或宿主法律结论。律师可拒绝候选或引用任意原SPAN。
   不从思考或工具结果补、清空、合并、选择终答；技能ID自报不是因果执行证据。
4. 每批首遇后，教师见累计原TRAIN完整原文/原Gold、自己所有已保存首遇和此前批后重答、真实库版本，
   外加这些同一8B原生回答的完整reasoning_content。该文本按raw_id/content精确绑定，视为不可信训练数据；
   不向教师传其他学习者、未来/保持结果、教师自身隐藏推理，也不把模型计划当实际执行证明。
5. 教师按同一批末编辑维护完整父库：保留、CREATE、UPDATE、MERGE、DELETE或NOOP。
   新增说明缺失边界；修订不只是堆同义词；合并不抹平主体/动作/对象/触发/例外。
   无硬数量、删除配额、按效果准入、回滚或第二管理器。所有结构有效编辑原子发布。
   每批记录真实管理操作、保留/修订/移除ID、文字token/字符及修正/损害，不以增长证明学习。
6. 发布后在本批重答并提供给以后教师；普通监督模型也累计本批原标签。
   这些是已见拟合，不拿前后差值冒称纯技能因果效应。真正重点是B2—B4首遇对照与末库不同合同迁移。

本Run所有条件共同移除提示中“所有允许SPAN索引”的长数字数组；原生Schema仍严格限制原坐标。
这是共同输入规范，不声称其独自解决此前长合同过选，历史答案和惩罚不改。

## 数据、调用与控制

原24 TRAIN沿用已固定元数据顺序，四批每批6；不重构案件或原标签。
后续8合同同此前已暴露开发组，来源独立但不是开发者新盲测；保护24与官方DEV/TEST不读。
新库、工具和回答均从头生成，不继承前Run库或答复。B1仅确切同消息/Schema的冷输入可明确共享。

首遇三条件：强空库、同标签普通工具、普通工具＋在线程序库。
四次批后技能重答、末次对首批6合同保持；保持不送教师或作为发布门槛。
最终8合同五条件：上述三者、普通工具＋公共任务静态库、普通工具＋最后一次公共观察教师编辑库。
静态教师只见17公共任务/接口，永不见原合同/标签/输出，工具仍使用共同24案原标签。

最后一个控制的精确定义：B4的两次教师从完全相同M3父库、相同24案原文/Gold及相同已保存公开观察出发，
唯一输入区别是local_executor_trace非空或null；先生成公共观察控制，再生成带轨迹主库。
两次均发生在任何M4重答/迁移成绩之前，主库预先指定，绝不按结果选库。
控制此前父库已经由带轨迹学习得到，所以它只检验“最后一次编辑的额外信息”，
不是完整无轨迹独立训练消融；也不是独立学习重复，不能过度归因。

计划130个新物理律师：60首遇（另12显式冷共享）、24批后、6保持、40末库开发；
6新教师：1公共静态、4在线、1最后更新输入对照。不做额外全量资格训练。
所有40个末库回答保存并独立核对后，才读本Run该组评分Gold。

## 判读、失败和论文边界

仍报告原17类命题的原三类准确率、Gold非NM依据TP/FP/FN/P/R/微F1、逐题F1、联合exact/soft、
类别分解、真实成本、编辑操作及旧案保持。同案修正/损害和跨合同对照分开；批次难度不同不要求裸分单调。
按合同成对bootstrap只描述当前产物条件下8来源的不确定性，不冒称独立训练稳定性或显著性。

无查询特征收益不等于此程序技能已有效；若B2/B3仍系统性损害，操作者可在工件安全边界停止并保留，
不等满跑、不回滚挑库或隐藏失败成本。结构/来源/身份/容量不满足就停止，不重试或fallback。
运行中的绑定源码/配置/协议不改，下一改动必须新Run。0新模型下载/切换/付费API。

约90%分类和相应高依据/联合分是研究目标，不是发表硬阈值或保证。
独立学习重复、必要消融、公平ACE/ExpeL/其他成熟方法、原官方确认、可归因创新与成本优势仍须另行完成。
单次130调用开发学习即使正向，也不能直接称Goal完成或可发表。

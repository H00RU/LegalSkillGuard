## A simpler own path, not another runtime layer

The old method combined a12-source trained ordinary candidate package with
teacher-generated literal queries and a short criterion. Its editor still
framed learning mainly as source acquisition and required at least one query
for every skill. The revision removes these coupled restrictions:

1. The actual own solver uses complete original text, the current external
   skills and their literal source locations, but NO ordinary candidate list or
   membership scores. Do not run M2 to construct own inputs. The separately
   declared ordinary control still uses its unchanged actualM2.
2. A skill has id, public hypothesis_ids and guidance with source_queries and
   evidence_criterion. Queries may be empty; the procedure may be null when a
   genuine query action exists. At least one action must exist, without fixed
   types, counts, topics, growth or a requirement for a skill per hypothesis.
   Permit concise source-conditional legal inspection and evidence selection,
   rather than restricting every learned procedure to search vocabulary.
3. Retain the existing literal executor and matched/neighbour/preamble facts.
   It searches current id/text/spans only and cannot decide legal relations.
   No learned score, semantic router, second critic, generated paraphrase,
   citation union, forced read mask, native answer repair or fallback is added.
4. Keep one unchanged native choice/spans/reason decision per document. Original
   full source and every legal label/index remain available, even outside all
   returned locations. Guidance is fallible advice, not a mandatory verdict.

The implementation must rebuild teaching visibility from actual own payloads,
not self.proposals from the control arm. Current own ordinary-candidate fields
must therefore be empty in both runtime and teacher feedback. The teacher sees
only original seen-prefix labels and own behavior, not predictions from strong
empty or ordinary controls. A compact hypothesis-level error profile is derived
from those SAME actual original member sets to expose unaddressed acquisition,
selection and relation errors; it is not a new judge or additional supervision.
Full seen source, Gold, actual latest same-parent answers and all member contrasts
remain recoverable. Actual old edits/observations stay archived with their real
versions; never describe earlier behavior as current-parent execution.
Two redundant per-case derived error tables are replaced by the complete member
contrasts and compact profiles; original text, annotations, native public answers,
all visible candidate/read lists, access receipts and edit history remain.
This removes duplicate serialization, not difficult cases or original supervision.
The common reading notice is updated equally in all three arms; original task
instructions and native output schema remain. No old answers are reused as
controls under that changed notice.

The writer keeps atomic CREATE/UPDATE/DELETE/MERGE/NOOP and publishes every valid
edit without gain admission, checkpoint selection, rollback, retry or forced
growth. All master/scope/criterion projections remain within4096 actual8B tokens;
never clip knowledge to fit. Case IDs, parties, dates, original indices and
answer tables stay out of runtime procedures. Do not alter original Gold to
make a learned rule look correct. The conditional legal procedure is not itself
an authoritative legal rule or expert-reviewed legal advice.

Removing ordinary cues, relaxing the query requirement and reframing the writer
are a joint method revision. A gain would not isolate one change causally.
Mechanism-removal learning/inference ablations remain required later, not an
excuse to add a new fixed-bank qualification grid before actual learning.

# 当前主方法修订：面向实际答案的技能复核

2026-10-15。用户要求立即实施根因级优化，暂停的Goal不恢复。
Run ID：`legal_contractnli_answer_review_learning_20261015_run01`。
这是开发性方法修订，不是已经有效、正式盲测试或已具备论文创新的声明。

## 为什么改这个执行点

已完成九条件后续八来源：强空库分类84.56%、依据F1 70.97%、联合61.76%；
逐项反馈技能82.35%/64.11%/61.76%；ACE法律适配80.88%/70.00%/57.35%；
ExpeL法律适配80.15%/61.54%/56.62%。没有成熟适配整体胜过强空库的证据。
ACE四批同案F1都提高，但B4分类27→24/34、联合17→14；B1保持F1 70.13%→54.21%。
因此不把ACE整套替换成“我们的方法”，也不继续扩张复现。

当前真实失效包括：压低误选却漏证、已返回依据仍遗漏、补证时混入同主题条款、
更新后破坏原本正确的关系。旧方案让整库指导参与从头生成，没有一个实际初答可供条件性检查。
本次可证伪假设是：把学习对象从广泛解题原则改为针对已有回答的源文检查程序，
将关系修正与证据增删区分，可能使弱律师更可靠执行边界。不能保证它会有效。

## 实际链路

完整原NDA和17公开命题 → 同一8B独立初答 → 当前技能指导的一次复核 → 完整原生最终答案。

- 每份合同的初答不含技能；它是共同起点，不是方法的最终答案。
- 每批首遇最终回答都使用上一批当前库，之后教师看到该批Gold及自己的真实轨迹并更新技能。
- 教师每批一次，兼做失败归因和CREATE/UPDATE/DELETE/MERGE/NOOP；没有新增反思模型、规划器或客户。
- 技能只有`id/hypothesis_ids/guidance`。写成可检查的条件和纠错步骤，不存原案答案、实体、日期或SPAN号。
- 公开命题ID仅将现有技能列到相应题下，没有语义路由或隐藏的当前案判定。
- 去掉本修订中的字面查询配方与检索成功示例，不是把它们叠加在旧链上。
- 复核始终保留完整原文，最后仍由律师自己决定关系与所有原SPAN。代码不拼接初答、不自动扩证。
- 没有按效果准入、择库、回退、置信度门控或重试。所有合法发布均执行，包括无效益编辑。
- 技能作用于复核过程，不承诺同一17题调用内文字隔离。自报技能ID不当作因果使用证明。

## 对照与反证

三个终点条件共享实际同一次初答：

1. 强空库直接回答，一次调用。
2. 无技能复核，同样两次调用、同样检查指令，只缺学习技能。
3. 技能复核，同样两次调用，使用固定末次库。

如果只胜一次调用、不能胜无技能复核，不能把收益归于技能学习。
如果F1提高但分类或联合明显恶化，也不称整体修复成功。
保留每批首遇、教师后同案拟合、B1末库保持；新案评价是主要开发决策证据。
不从不同批裸分下降直接推断遗忘，也不删除不利结果。

## 借鉴和创新边界

本次借鉴已发表工作中的“以实际初答为对象做复核”和经验差量更新思想，没有复制上游实现，
不宣称是Self-Refine、ACE或ExpeL的canonical复现。沿用项目已归属的原子编辑和审计代码。

- [Self-Refine原论文](https://arxiv.org/abs/2303.17651)，[作者代码](https://github.com/madaan/self-refine)：
  原方法有Init/Feedback/Iterate。本修订不另加Feedback调用，历史Gold辅助检查程序承担外部经验。
- [ICLR 2024自纠错局限](https://proceedings.iclr.cc/paper_files/paper/2024/hash/8b4add8b0aa8749d80a34ca5d941c355-Abstract-Conference.html)：
  内生自纠错可能无效或退步，因此必须有等调用无技能复核，而不能预设多一步就有收益。
- [ACE](https://arxiv.org/abs/2510.04618)：保留有用经验、增量编辑；不照搬ADD-only和整库堆积。

机制分析仅用于接缝测试，evidence-reporting用于证据和对照边界。
不使用固定创新点数量、热点包装或隐藏借鉴归属。方法创新及收益仍待本轮实际结果证明。

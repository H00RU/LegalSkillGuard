# 纯源可执行特征：一次有界学习对象检验

这是同法律任务、原指标、冻结8B及既有教师内的开发候选，不是已确定的新论文方法。
**不实施待用户确认的最终证据结果复用，不改变律师对最终E/C/NM和原SPAN集合的决定权。**
本项0新律师生成、1既有gpt-5.6-sol/high教师、2 CPU fit，不启动长训练或参数网格。

## 实际依据和接缝

历史字面查询程序训练18的Gold成员覆盖284/416，新16为80/287。
v2校准修正后，48个原普通工具真成员丢失，其中40在全部query特征未命中的位置。
不能据训练拟合99%宣布技能有效，不能认为正确校准接法足以使字面程序迁移。

采用师兄paper-ideation第3节的接缝检查，限定已有方法而非重开选题/热点雷达：
旧方法把可复用动作限制成连续短语和固定邻居窗口，不能一般地计算源结构与跨句关系；
当前数据明确出现覆盖下降。候选只扩大特征程序的表达能力，不增加规划、路由或判官。
代码表达力更强不等于迁移更好，必须实测普通同数据控制，负结果完整保留。

参考当前公开ScienceClaw的Skill/typed Operator区分，不把当前版等同于用户参与的历史
TF-GRPO版本。实际复用已有MIT归属的contracts scorer与OOF hook；纯特征执行器为本项目
实现，不冒称复制其进化代码，不引入其validation gate。
来源：https://arxiv.org/html/2610.08691 ，https://github.com/beita6969/ScienceClaw 。

## 学习与执行边界

教师只见原18已见TRAIN完整text/spans/原Gold、原学习器可用真实公开轨迹及原查询库。
所有历史轨迹保留实际旧版本身份，不伪造为新代码库的rollout；新库从空父库开始。
不传新16源/Gold/成绩、私人思考、其他对照律师答案或官方DEV/TEST。
TRAIN原文件被主进程解析，不能声称整个进程从未解析新16标签；严格限制的是教师和
当前源预测/特征函数的输入。当前16已开发暴露，不是独立held-out确认。

技能仍为原子CRUD/NOOP、任意数量/公共hypothesis_ids范围，全部结构合法修改发布，
无效果准入、最好库回滚、删除失败或强制增量。总库仍4096服务token上限，无截断。
唯一guidance为feature_names与python_source。函数span_features(text, spans)返回
原n_spans行、已声明固定特征列，值为[0,1]有限数或布尔。不是证据概率/标签/最终集合。
代码不接收ID或Gold。禁止案件答表、指纹、实体、日期、固定来源长度/索引硬编码。
结构检查不能证明所有语义过拟合已排除，完整代码须审计，不作绝无记忆的空泛保证。

允许纯文本/容器/正则计算以表达可观察跨句、条件、列表、模态等关系，不固定技能类别。
AST限制能力，独立CPU子进程2秒CPU/192MiB内存/5秒墙钟/无文件输出额度；这不是面向
任意敌对代码的安全沙箱。仅既有可信教师代码可运行。无导入、外部模型、文件/网络、
动态执行或反射，re预提供。执行失败保留原始输出并停止，无修补、替代函数或重试。

同一特征设计进入final LR、每个合同训练折及对应OOF校准；原单个既有scorer的训练
算法/参数和树维度不变，普通控制为空程序独立同数据拟合。8B权重不变。
只增加数据派生特征，不把命中自动并入证据或以空命中裁成NM。未来若采用该表示，
律师仍读全原文并独立输出原标签和原SPAN索引，本项不修改其接口。

## 固定检验与完整目标

同实际历史最后M3的18来源及固定已暴露16，不择库/案件/阈值。原.5阈值，全部16两臂
预测保存后统一计算原Gold-NN硬micro-F1及TP/FP/FN，保留全部程序与真实成本。
普通监督工具收益不算技能收益，本项目辅助scorer实际是监督训练，必须如实说明。
不把CPU结果拼接成原生律师指标，不宣称新的在线学习完成、算法稳定或显著性。

若无额外收益，不扩大为同配置长训练；这不是学习中选择或回滚已发布库。
若有正向证据，仍须新Run从空库的完整在线批次、同数据普通/强空库/等调用review/
公平成熟经验方法、独立重复、机制消融、真实成本和未调优正式TEST。
完整Goal仍未完成，不因本项可执行或单个开发正差宣布论文目标达成。

## 确切训练与推理

1. 用累积原TRAIN拟合相同普通模型：原字词TF-IDF/邻居稀疏LR、合同OOF堆叠与LightGBM成员评分。
   两阶段均包括原NM全负例。C10、原全部参数/叶最小20不改变。
2. 对有可拟合二类字词头的公共命题，用其完整已见训练字词logit作固定offset，
   只优化实际查询的L2附加系数。目标是带原类别平衡权重的逻辑损失加||gamma||²/(2C)，
   无新增截距；字词系数、截距与第二阶段树参数原样保留。凸优化失败停止，不替代。
   无对应二类头时仍用作者原先已定义的共享学习头，查询不强行代替未知类别知识。
3. 运行时是同一个线性点积：原字词块＋查询块，再走同一个普通评分器。
   不增加LLM调用、推理中间层、fallback、案件答案表或原生答案修补。
   整个命题无查询匹配时其输入logit等于普通模型；这是一条公式，不是答错后选择回退。
4. 每查询仍为机械字面/显式邻居两个特征，不自动成为依据。
   p>.5候选按原索引顺序传律师。完整原文始终可见，律师独立作原关系与依据决定。
5. 另外计算同一固定普通模型去掉查询项的候选，仅用于日志和教师信用分析。
   不传给律师、不中途择优、不作为发布准入、不额外生成律师答案。
   原始分数和实际查询命中均保留；教师只看其自身真实训练轨迹与两套工具候选、原Gold、
   所有父库及已学习查询权重，不见另一学习器答案、保持或后续评价。
6. 教师被明确告知普通监督收益不是查询收益。学习短而可组合的事实条件，
   不以长原句摘录唯一匹配训练例取代抽象。所有CRUD/NOOP无条件原子发布，不强制增长。

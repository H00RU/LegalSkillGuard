## Evidence motivating this particular change

The complete task-local B2/B3/B4 first encounters have modest classification and
joint gains but no consistent extra original evidence over the matched ordinary
tool. B3 has74 true span members in both arms; B4 has47 versus57, with12 versus5
false NM answers. B4 main accuracy/F1/joint is80.39/65.73/60.78%, compared with
same-tool78.43/69.51/56.86%. The higher main joint includes37 correct NM answers
versus31, while evidence-bearing exact joint is25 versus27. These are observed
matched effects, not individual-skill causal credits or general legal judgments.

Original raw cases show both incorrect relation decisions despite a relevant
guide/candidate and incomplete citation sets despite correct labels. For example,
some answers omit an operative predicate between selected original fragments,
or omit the governing introduction or an independently operative second clause.
The full NDA has always been available: the failure is not absent source text.
The current local candidate table supplies numeric indices/scores, requiring
binding back into that remote source. The teacher's indexed success/error view
likewise resolves evidence text indirectly through its complete case records.

M3 also broadens a return-trigger condition to admit a supplied NM negative
witness while its rationale claims to distinguish that witness. M4 retains this
record verbatim; its bounded window does not include that earlier case. This is
an observable inconsistency in supplied TRAIN feedback, not grounds to relabel
Gold, manually edit the bank, force a verdict or invoke an admission judge.

## The intervention: two views at existing interfaces

1. Lawyer view: keep exactly the ordinary tool's candidate IDs, scores and order;
   attach `literal_original_text = original_text[start:end]` to each candidate.
   No new candidates, query programs, retrieved cases or original-Gold access.
   Full marked original NDA and all17 questions remain present together.
2. Teacher view: keep all original cases, labels, complete public answers and
   candidate observations in the same current-before/previous-after window.
   Beside each hypothesis's existing original feedback, quote the union of
   original-Gold and actual cited spans. Mark whether each already belonged to
   Gold and/or the actual answer. Include successes as well as missing/extra
   citations; do not select only errors or favourable examples. An empty union
   is not an independently proved NM answer. An incomplete fragment must be
   interpreted in its complete original contract.

The editor is explicitly asked to compare supplied different-label witnesses
before broadening a conditional relation. Unsupported implications may become
null-relation inspection procedures. There is no mandatory nulling, skill growth,
topic count, deletion, relation coverage, efficacy gate or host semantic test.
This is still one existing teacher edit per batch, not a new verifier role.

Both views are deterministic re-presentations of already permitted inputs, not
new supervision. Only the training teacher sees Gold; no teacher Gold quotation
enters inference. Every original label and final span set remains the frozen
lawyer's own native output. No union, completion, branch-forced verdict, repair,
retry, fallback or best-bank substitution is performed after the answer.

The two changes form one development candidate. A successful complete run would
not identify which change caused a gain; separate learning ablations would be
required. Adding literal text may overload the lawyer or worsen results. This
protocol does not assert that the observed root mechanisms are thereby fixed.

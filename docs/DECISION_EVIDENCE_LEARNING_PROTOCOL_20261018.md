# Same-lawyer two-target skills: prospective development protocol

2026-10-18. Not an independent repeat, complete online experiment or TEST result.

## Evidence and intervention

The completed seven-block four-arm test was negative: original joint empty/skill
classification72.06/76.84%, hard original-member F1 61.98/57.71%; grouped
empty/skill F1 57.86/25.50%. Skill-induced false members remain even with correct
relations (joint44→98; grouped87→728). Thus do not expand that rollout. This
identifies target-specific damage, not a proven sole attention mechanism.

This experiment changes both teacher output and native execution. A frozen8B
relation action sees only relation guidance; its evidence action sees only
member guidance and its actual native choices. Two channels follow the existing
two benchmark targets, not a fixed number of skills or imposed legal topics.
No new model, planner, judge, customer, label space or task is introduced.

Both actions see the complete original contract and the same ordinary evidence
tool fitted on42 past original TRAIN sources. Ordinary and learned procedures
are fallible; the lawyer freely chooses every original index, including any
outside tool proposals. The evidence action cannot revise its own prior native
labels. The host copies native choice/reason and native evidence verbatim, not
tool-confirmed proposals, expanded windows, deduplication or corrected answers.
An incomplete/malformed action fails the complete original17-answer denominator.

## Source and supervision matching

Past42 is the fixed union of actual R3-seen24 and prior ordinary-feature-seen18.
The ordinary model uses exactly these sources with unchanged supervised model
and parameters; it was fitted before this experiment's16-source prediction.
The teacher gets all42 complete original sources and unmodified annotations,
actual historical own public observations with their old stages/bank identities,
the exact last R3 parent and the two future native system contracts. No16-source
text, answers, annotation, selection by outcome or private reasoning is taught.
Source URL and NFKC components must be disjoint. Official DEV/TEST stay unopened.

R3 conversion renames the existing full evidence_criterion text to
relation_criterion and sets evidence_criterion=null; no word, ID or scope is
silently deleted. One actual existing gpt-5.6-sol/high call may CRUD/MERGE/NOOP.
All structurally valid within4096-token publications execute, without admission,
best-bank selection, rollback, forced growth or a prescribed skill count. The
teacher learns source-observable annotation-member boundaries, not runtime Gold
predicates, selected16 repairs or case lookup tables.

## Four arms and real cost

Same fixed, previously developer-exposed16 TRAIN contracts, all original17 tasks:

- joint_empty: single native action, full source and common ordinary proposals.
- factored_empty: two native actions without skills.
- relation_only: learned relation guidance, no member guidance.
- dual_skills: same learned relations, learned member guidance.

Relation-only and dual share their IDENTICAL first-action native response; each
second action is new and distinct. This gives96 physical native calls and112
logical endpoint call-uses when all prerequisites succeed, plus1 new teacher.
Deployment of either full factored method costs2 native calls, not1. Shared
prefix cost is explicitly recorded, not a response-cache or free-call claim.
Per-source branch order alternates without inspecting quality. An invalid first
action skips only its impossible dependent action, retains the whole contract
failure and reports the actual lower call count; no retries/substitute answers.

All64 complete logical answers precede opening scoring-only annotations and
unified original scoring, checked against the independent audit implementation.
Report all four arms, invalids, TP/FP/FN, paired source differences and descriptive
uncertainty. Relation-only and dual must have identical native relation choices;
their evidence difference measures member guidance conditional on those choices.
No efficacy gate is applied to individual records or publications. Comparing
both strong joint ordinary and equal-two-call empty controls prevents attributing
ordinary supervised learning or generic extra compute to skill evolution.

Positive results would only justify subsequent actual online updates/later new
contracts, independent repeats, fair ACE/ExpeL-style comparisons and untouched
official TEST. A completed pilot is not Goal achievement or publication evidence.

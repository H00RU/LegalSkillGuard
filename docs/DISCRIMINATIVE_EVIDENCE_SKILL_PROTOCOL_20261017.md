## Annotation target, not a new scoring rule

The [original paper, section2.1 and Appendix A.1](https://aclanthology.org/2021.findings-emnlp.164.pdf)
requires concise but self-contained evidence, including redundant support. Its
annotation account distinguishes TRAIN review of annotated spans from whole-
contract review for most TEST documents. This supports caution about coverage,
not a license to treat every unannotated span as a mistake in Gold or every
nonGold citation as semantically irrelevant. The observed source501 survival
clauses are a possible coverage inconsistency, not an estimated dataset error
rate. The mask also cites plainly unrelated obligations and markup; incomplete
annotations cannot explain away its failure. Do not open DEV/TEST for tuning,
alter Gold, replace strict F1 with a model judge or manufacture corrected labels.

## One existing teacher; a more relevant learning unit

Current acquisition records can only say where to read. They cannot store a
learned boundary distinguishing an evidence member from a nearby distractor.
The proposed artifact adds one concise optional evidence-selection criterion
beside the same source queries. It is NOT an E/C/NM verdict or a sufficient-
condition label rule. No mandatory topics, skill families, record count or growth.

Use the current same-parent canonical R3 answers on ALL32 seen TRAIN sources,
all original Gold, query receipts/roles, visible scores and publication history.
No mask-condition answers, other-arm predictions, private reasoning or invented
successes. Earlier96 observations have already taught R3 and remain archived;
this update's response window is the actual32 current-parent answers, selected
by version and complete source coverage, not correctness or reward. Explicitly
disclose this change from resending heterogeneous old versions.

For each original hypothesis, expose all current Gold omissions and all actual
nonGold citations with their original text and actual acquisition roles. Supply
the full source too. A nonGold mark means absent from original annotation, not
an independent semantic negative. Learn transferable member-level contrasts:
what source function warrants citing it, what superficially related text does
not establish that function, and when governing text is needed for a selected
clause to be self-contained. Do not simply list every possible legal premise.

The first source-only teacher compilation exceeded the actual1,048,576-character
entry limit at1,160,768 characters, before any teacher/native call or Run directory.
Its original config/source and capacity finding remain archived. The run02
preparation shares identical original member text once in a source/index catalogue
and member-column names once. Every original member, case, choice, access role and
actual citation remains reversible to the full uncompressed contrast table;
complete source texts remain verbatim. This is teacher-only lossless serialization,
not evidence pruning, a new actor layer, an output fallback or a shorter learning
window. Do not count the zero-call preparation as an executed learning experiment.

The existing differential editor publishes every structurally valid CREATE/

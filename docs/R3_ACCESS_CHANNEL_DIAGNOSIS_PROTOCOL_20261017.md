## Motivation and fixed boundary

The complete eight-source B4 encounter improved labels but sharply damaged
original hard Gold-NN micro-F1: empty 73.5294/51.4851/47.0588%, ordinary M2
70.5882/60.2871/50.0000%, R3 80.1471/28.0788/52.9412% (accuracy/F1/joint).
R3 produced 218 false-positive evidence members, of which source624 produced196.
Continuous ranges also occurred on hypotheses with no scoped literal leads.
Therefore exact copying of the entire retrieved set is not the sole explanation.
Public explanations on source604 also suggest confusion of printed clause numbers
with original SPAN pointers. These are observations, not a unique causal proof.

Keep the actual 15-record R3 library verbatim, original full documents and offsets,
all17 original hypotheses, identical native output schema/system/decoding, current
RAM-resident frozen Qwen3-8B, and original hard scoring. No current answers or Gold
enter the new actor requests. Do not change the original list preamble parser:
its bullet-list recall gap does not explain this false-positive collapse.

## Two prospective interventions, eight sources each

Source order is the original preselected entire B4:362,472,234,430,604,246,559,624.
Rotate the two arm orders between sources. Generate all16 answers before unified
grading. No teacher, no mid-phase tuning, no answer repair, no output union,
no evidence cap, no rejection/retry or outcome-based bank selection.

1. `compact_full_R3`: replay exactly the original R3 source-access facts and all
   criteria once; losslessly replace verbose per-index three-boolean records
   with three named index lists. Verify the complete original records roundtrip
   exactly, including all overlaps/order. Preserve the complete candidate text
   and source. Supply an explicit decoding legend. This changes representation
   and explanation, so it is NOT a pure prompt-length-only causal experiment.
2. `ordinary_plus_same_R3_criteria`: reuse the exact deterministic ordinary M2
   candidate payload already served on that same source, append the same15
   verbatim one-copy R3 criteria, and do not execute/deliver the stored queries.
   This evaluates an existing calibrated source aid with the same procedures,
   not newly learned retrieval or an isolated removal of one query family.
   The full R3 bank remains archived; served projection is explicitly recorded.

Reuse the24 original B4 empty/ordinary/fullR3 responses as named historical
references, not sixteen new baselines or new calls. Total analysis40 actual

Gold-NN micro-F1 and member TP/FP/FN, alongside accuracy and strict joint. Report
source-wise results and paired descriptive source-bootstrap uncertainty; do not

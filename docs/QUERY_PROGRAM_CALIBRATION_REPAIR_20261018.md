## 实际代码不一致及单一路径修正

v1先训练普通词模型和其合同OOF二阶段校准器，再用完整训练word logits作offset
拟合query系数；推理把改变过的first-stage logits交给未见过这种信号的原校准器。
这是一条可直接从fit/predict源码核查的接法，不等于已经证明负收益由它唯一导致。

v2在既有`_hypothesis_design` hook中统一词与query设计：final LR拟合、每个原合同
训练折及实际推理都使用同一套特征，校准器以相应OOF logits训练。
不再无依据地要求辅助词权重和校准器保持不变；始终冻结的是律师8B权重。
不把query列直接加入树；树维度、叶参数、C、seed与原有训练方法保持不变。
没有新增验证集；合同fold是已有stacking训练内部步骤，不用于外部择库或阈值选择。
教师发布规则、律师原始输出权、数据和原SPAN评分没有因此改变。

只改既有source/design路径、teacher说明、归属NOTICE及一个既有测试。
删除旧offset优化训练函数，不新增旁路、模型切换开关、裁判或fallback。
旧`SourceQueryLinear`仅为读取真实历史pickle保留，不能再生成新的v1训练模型。
新工件使用`joint_word_query_contract_oof_calibration_v2`明确版本，
不把历史工件改名或热改为v2。旧冻结源码仍在其终态archive和Git历史。

## 当前决策和需要明确的下一边界

不启动相同文字库+thinking的长训练，也不启动这个v2查询库的长训练。
已证的是“普通工具有部分可用能力，现有技能没有提供可靠增量”，不是解决了论文目标。

下一候选是让律师**显式调用并确认**可执行选证技能的结果，而不要求它自由重造
每一个索引；仍由律师判断原E/C/NM，完整原文保持可读，原SPAN指标与全部失败分母不变。
空命中不是NM。任何引用复用必须由原生动作明确选择、完整审计，不能后台偷偷替换，
不能把普通监督学习收益冒充技能的额外收益，仍须同数据普通工具及成熟方法对照。

这改变了此前最终证据的产出契约，**仅是待用户决定的方案，未实施、未新起Run**。

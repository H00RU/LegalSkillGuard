# Figure 1. Evidence-guided skill evolution

Execution evidence guides task-protected legal procedure revision. All new-source forecasts are saved before training targets are released. The middle and right stages run sequentially for EC and EV: each selected step result becomes the next step's actual parent, and the batch library is published after both tasks. Whole proposals and dependency-consistent compositions are assessed on all encountered training sources under native and complete-output utility. Identical requests reuse the same physical response. Bounded failed-proposal evidence informs subsequent teaching, while the published library serves the next batch. The fixed B1 reference is evaluation-only. At stream completion, the actual final library is frozen for separate evaluation without learning feedback.

# 图1. 执行证据驱动技能进化

执行证据指导受任务保护的法律程序修订。保存全部新来源预测后才释放训练目标。中间与右侧阶段依次用于EC和EV：每步选择结果成为下一步的真实父库，两项任务完成后发布批次技能库。整包提案与依赖一致组合在全部已遇到训练来源上按原生及完整输出效用检验。相同请求复用同一次真实回答。有界失败提案证据用于后续教学，已发布技能库服务下一批。固定B1参照仅用于评价。学习流结束后固定实际末库，单独评价，不向学习回传反馈。

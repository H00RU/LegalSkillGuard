Figure. Raw first forecasts and same-case own-B1 contrasts need not give the same ranking. Panels a–b show original EC and EV macro-F1 on each batch's 16 source cases, with 128 sources shared across the three policies. Panels c–d subtract each run's own frozen-B1 score on those same cases. B1 has no learned frozen-B1 control, and B2 has zero difference by construction. Task-local's B1 library contains EV guidance but no EC guidance, so its later EC contrast includes initial acquisition, not solely refinement. Lines connect exact batch means without smoothing; one learned trajectory per policy does not estimate independent-learning uncertainty. Main learning was serial, while both replacement controls used the same four-worker execution profile. The recorded whole-bank B1 feedback defect and known resource costs are disclosed in Appendix D. These descriptive traces neither isolate a causal granularity effect nor establish held-out superiority. At rendering on 25 October 2026 at 14:16 UTC, all first forecasts were complete; Task-local's final B8 skill update and the common frozen TEST remained pending. No post-update fitting scores or TEST outcomes are plotted.

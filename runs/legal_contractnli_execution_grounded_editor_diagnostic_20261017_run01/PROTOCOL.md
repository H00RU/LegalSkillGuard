## Question and limited borrowed mechanism

Concrete inspection prose improved some labels but not true evidence members;
literal delivery of all program hits then harmed classification and SPAN F1.
The observed program has substantial task-scope contamination and weak precision,
so another display change is not the next intervention. Test whether observing
the draft's own real query behavior helps the SAME editor produce useful,
appropriately scoped retrieval skills beyond a more concrete blind revision.

Code reviewed: Voyager's [ActionAgent observation construction](https://github.com/MineDojo/Voyager/blob/main/voyager/agents/action.py)
and [execution/update loop](https://github.com/MineDojo/Voyager/blob/main/voyager/voyager.py).

that execution-to-revision principle is adapted; no Voyager source is copied,
and its critic, success admission, curriculum, retries and environment rollback
are NOT imported. This is not a Voyager reproduction or a ContractNLI SOTA claim.

tokens and those costs are reported. Calls are separate/ephemeral with no result
reuse, and neither arm receives the other arm's output.

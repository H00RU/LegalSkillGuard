# Evidence-anchored legal inspection skills: finite mechanism study

Prospective development study, 2026-10-17, motivated by the completed fixed-tool
native-feedback study, not by partial scores from the live support/refute run.
The full ContractNLI task, original three labels and complete original-SPAN sets
remain unchanged. This is NOT formal training or an independent learner repeat.

## Root-level intervention and known limits

Earlier writers had original Gold and actual public failures, but current runtime
memory contains only abstract inspection and lexical queries. Earlier complete
Gold-member explanations were deliberately removed as training metadata. Query
coverage improvements failed to become native evidence gains. Repeating abstract
reminders or presuming a correct teacher guarantees a successful executor is not
an adequate next learning design.

Test a simpler runtime representation: a teacher-written reusable inspection
with references to actual past annotated evidence examples. Drop the learned
lexical-query DSL in this NEW representation; keep the same ordinaryM2 candidate
tool, full source and frozen lawyer. There is no new retriever, embedder, router,
planner, critic, semantic evaluator or answer repair. This representation change
is not a pure ablation of the previous source-program bank.

One existing gpt-5.6-sol/high teacher sees all18 already-seen original TRAIN
sources/Gold, the latest source-program bank, and18 actual own public observations:
the historical first12 and the latest final B3 six. Their different historical
banks/tool states/formats are explicit. Earlier draft experiments remain archived
but are not all repeated in this deliberately redesigned packet; no lossless
encoding or independent fresh learning is claimed. No B4 source/Gold, other-method
answer or private reasoning is supplied to this teacher.

The teacher creates a new-format library with the existing atomic publication
API, parent initially empty for this representation translation. CREATE/NOOP are
legitimate, no fixed record/topic count or growth. Each guidance has inspection
and historical_example_refs. A reference resolves ONLY to a supplied past
(source,hypothesis) with non-NM original label. The renderer deterministically
includes that original label and ALL its original Gold evidence texts, without
past case IDs or original indices in runtime. These quoted TRAIN snippets are
not a complete historical document/trajectory and are not current-case evidence.
Do not claim that a local excerpt proves whole-document NM; such exemplars are
not admitted by this representation. Teacher text is not semantically certified.

The source IDs/references remain in training publication/provenance artifacts;
they are not used to look up a current answer. Structural reference integrity
and materializing past Gold are label-assisted learning, NOT Gold-based repair
of a generated inference. No future Gold is used. Quoted source names remain
verbatim rather than being silently rewritten; the lawyer is warned not to
transfer historical entities/facts/citations to the current NDA.

## Four same-interface conditions

All six exposed B4 development sources [430,290,622,613,383,92], rotated arms:

1. empty: same ordinaryM2 tool, no skill library;
2. procedures_only: same new record IDs/scopes and inspection, examples removed;
3. examples_only: same new record IDs/scopes and full selected examples, inspection
   removed (not another teacher-selected example bank);
4. joint: exact complete new publication.

All records are delivered once with public-scope ID references. No hidden
task isolation. Every condition has the same common system and original
four-field choice/spans/reason/used_skill_ids ABI, including coherent E/C vs NM
branches and all-class availability. This deliberately uses the old standard
ABI, not the live support/refute intervention; the studies are separate.
Fields/order in body/system/schema must agree before calls. Every original
hypothesis, source byte, candidate, score and index domain is preserved from the
completed ordinaryM2 actual request; only actual memory/IDs and common memory
explanation change. No learned source-query hits are inserted in any arm.

The entire actual joint runtime memory, including resolved evidence texts, and
every scoped one-copy rendering must fit4096 same-server tokens. The teacher
gets measured per-example costs and is asked to target2500 total, not merely
count cheap reference strings. An oversized/invalid publication fails and is
retained; never clip examples, prune records, substitute a bank or retry a writer.
There is no performance-based admission or rollback.

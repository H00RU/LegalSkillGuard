## 2. 逐篇结构、实验惯例与接缝

### OpenExempt

引言由静态评测不足转入法律诊断需求。方法先交代法律对象，再组织知识表示、
任务生成及参考求解；实验分任务和复杂度研究。本文继承其数据与原评分，不把
符号生成器、求解器或EC/EV当创新。自定义配置不等于官方Advanced，不能横排SOTA。

### ACE

引言把上下文适应的两种内容丢失问题接到增量记忆。方法按生成、反思、策展和
局部更新展开；实验另列组件与成本。本文的批后教师和文本库不新颖；实际区别
须落在提交及反馈策略上。其原生角色包装与我们的直接回答不同，必须披露适配。

### SkillCommit

引言从表面相似与行为不兼容的矛盾展开。方法把局部修复、兼容分组、保持合并
逐层接起来；实验覆盖构建、测试和迁移。它是作用域/重放最近邻。我们依据公开
共同呈现关系组合编辑，不等于首次行为保持；有限TRAIN均值检查也不更强于逐源保持。

### Trace2Skill

引言从手工技能和顺序编辑的不足进入跨轨迹归纳。方法按轨迹、独立修改、分层
合并展开；组件分析保持相同轨迹池并另报效率。我们的文本分析适配不具备原作
工具式错误验证；需保持适配标识，离线末库不能伪装八次在线技能进化。

### ExpeL

引言把闭源权重及调参成本转为外部经验学习。方法分别说明经验收集、成功/失败
对照、见解提取与历史召回；实验拆分见解和召回。自然语言经验及对比轨迹不是
本项目原创；本文当前也没有复现它的完整检索与示例条件，不能写成已超过ExpeL。

### Agent Workflow Memory

引言从长轨迹的泛化困难引出复用子程序。方法先定义工作流，再说明诱导和使用；
实验检查表示、上下文使用与跨环境泛化。不能把“生成程序性文字”本身当贡献，
也不能将网站操作工作流与当前单次法律判断当同一个任务。

### ReasoningBank

引言由重复犯错引出从成功和失败蒸馏策略。方法区分记忆的存取及额外经验扩展，
实验也分别报告。本文不能将对比经验当TFGRPO独占的学习信号；其在线测试适应
与我们的TRAIN学习后冻结TEST属于不同协议，不直接比较跨任务分数。

### 金融自进化审计

引言区分能力、行为损害与接口兼容。协议先锁端点和分析单位，结果分开呈现
纠正与退化、独立学习和接口敏感性。本文可借其配对转换和计数边界，不能从
平均上涨推出逐案无损，也不能从改格式后的差异断言某个学习器本质无效。

### WikiSkill

引言把迭代经验散失接到持久知识。方法区分原始经历、积累知识和执行技能，
实验含知识层消融和跨模型结果。其独立验证准入及回滚与本项目约定不同；借鉴
历史证据组织不等于应恢复一套wiki系统，也不能宣称我们首次保留失败历史。

### TALA

引言从法律情境差异与角色依赖形成两个问题。方法分别设计经验适应和角色复核，
实验使用多轮、多阶段法律环境及共享工具。它证明法律经验研究已有近邻，不
证明当前应改回多轮咨询；其额外交互、检索和评价与我们的EC/EV原F1不能直接横比。

## 3. 术语碰撞与首次出现时的消歧

| 容易混淆的说法 | 本文统一写法 |
|---|---|
| training-free、label-free | 冻结执行器权重；标签辅助的外部技能学习。不能写无监督TFGRPO |
| online、test-time | TRAIN流按批更新；正式TEST期间技能冻结，不混用两种适应场景 |
| scope | 公开情境的编辑依赖分量；区别于语义检索范围和实例支持集合 |
| skill use | 实际投递可核实；投递、模型自报与忠实执行/因果收益分开 |
| retention | 已见TRAIN上的既定保持检查；不写逐案无损或未来单调保证 |
| replay、rollout | 精确请求复用与新原生生成分账；逻辑记录不增加独立样本量 |
| three runs | 三次独立学习，非同一末库三次解码，亦非384个独立测试来源 |
| fair budget | 同单答设置与工具权限；如实另报总训练计算和库容量差异 |
| reproduction | ACE/文本归纳任务适配；不冒称作者默认完整系统原样复现 |

## 5. 落稿建议与优先级

- ★ 先完成已挂上的静态/Text、独立学习及两项消融，再以全部真实末库冻结测试。
  先不按有利TRAIN成绩选择是否保留某个对照，TEST不能承担调参作用。
- ★ 贡献聚焦“公开上下文依赖下的可组合技能更新”及实际证据，不写首次法律
  技能进化、首次反例学习、已经超过未复现SkillCommit或所有经验方法。
- ★ 在首次TEST预测前解决细法域贡献范围：若不独立训练task_local，只陈述
  已记录的提交差异与联合机制效果，不单独宣称细法域的泛化优势。
- ★ 保留EC与EV的差异化结果。已有单次TRAIN流中，继续学习相对自身B1的EC
  增量较小，EV增量更明显；不能用新案裸分起伏或只挑改变请求替代完整分母。
- ☆ 相关工作分经验记忆与程序归纳/法律评价两条线。WikiSkill和TALA可用于
  补足历史积累及近期法律背景，不自动增加两个量化实验或扩展模型部署。
- ☆ 结果段按“观察、对应机制、控制证据”组织。保持正面、简洁表达，边界集中
  在设置、图注与讨论；不能用重复免责声明替代解释为什么有效。
- ○ 跨模型和新法域是可选扩展，不因同行模板出现就加入当前实验。没有做就
  收窄泛化主张。原始数据、源码、许可证和最终投稿元数据另按实际完成情况交付。

可借的结构而非原句：ACE适合“总体收益接机制和成本”；Trace2Skill适合
“主结果接同条件组件替代”；金融审计适合“净收益接纠正与损害”；SkillCommit
适合“每一步可复用范围对应一份行为证据”。正文最终使用本文自己的表、日志
及实际统计，不挪用这些论文的数字、定理或能力范围。
